## 摘要
线性注意力保持固定大小的状态。在长上下文中，许多存储项共享该状态，它们之间的干扰会降低检索性能。Gated DeltaNet-2（GDN-2）与此前的所有delta规则模型一样，其擦除向量源自当前令牌的键。然而，其读取中的干扰是通过查询来度量的，而擦除步骤无法触及查询。我们引入了查询派生的擦除方向（QED）。QED添加了源自查询且与键正交的第二个擦除方向。在快速权重视角下，键导向的delta编辑无法改变读取的键正交部分。它利用可编辑部分来抵消沿查询度量的旧状态内容。它还能在超过训练窗口的每个长度上改善检索，并在S-NIAH-1上将可用上下文长度约增加了一倍。

## Abstract
Linear attention keeps a state of fixed size. At long context, many stored items share this state, and interference between them degrades retrieval. Gated DeltaNet-2 (GDN-2), like every delta-rule model before it, derives its erase vector from the key of the current token. However, the interference in its reads is measured through the query, and the erase step cannot reach it. We introduce the Query-derived Erase Direction (QED). QED adds a second erase direction derived from the query and orthogonal to the key. In the fast-weight view, a key-directed delta edit cannot change the key-orthogonal part of a read. It uses the editable part to cancel old-state content measured along the query. It also improves retrieval at every length past the training window, and it about doubles the usable context length on S-NIAH-1.

# 论文详细中文总结

## 1. 核心问题与研究动机

**背景：** 线性注意力（Linear Attention）通过引入固定大小的循环状态矩阵 \(S_t\) 替代了标准 softmax 注意力中随序列长度增长的缓存，使推理时的内存和序列混合计算量保持恒定。这一效率优势的代价是：所有存储的关联信息必须共享同一个有界状态。

**核心问题：** 随着上下文不断增长，大量存储的键值对在固定大小的状态中相互干扰，导致检索性能严重退化。现有 delta 规则家族模型（DeltaNet、GDN、KDA、GDN-2）虽然层层递进地增强了状态更新的选择性（纠错、衰减、通道级门控、分离擦除与写入门），但存在一个**结构性错配**：

- **读取路径**通过 query（查询）度量状态中的干扰，即 \(q_t^\top \tilde{k}_j \neq 0\) 的部分构成干扰；
- **擦除路径**却始终由 key（键）派生擦除向量（如 \(a_t = b_t \odot k_t\)），无法触及 query 方向上的干扰。

**关键洞见：** 在快速权重视角下，key 导向的 delta 编辑只能修正沿 key 方向的读取响应，对 key 正交方向（即 query 分解后无法被 delta 编辑触及的分量）无能为力。论文将这一点视为线性注意力长上下文检索退化的根本原因之一，并提出了解决方案。

## 2. 方法论

### 2.1 核心思想

论文提出 **查询派生擦除方向（Query-derived Erase Direction, QED）**——在 GDN-2 的擦除向量上增加一个**源自 query 且与 key 正交**的第二擦除方向。直觉上：既然干扰是通过 query 读取出来的，就应当允许模型用 query 来定义应该擦除什么。

### 2.2 技术细节

**GDN-2 基线更新公式：**
\[
S_t = (I - k_t a_t^\top)\text{Diag}(\exp g_t)S_{t-1} + k_t(w_t \odot v_t)^\top,\quad o_t = S_t^\top q_t
\]
其中擦除向量 \(a_t = b_t \odot k_t\)，\(b_t\) 为通道级擦除门控，\(g_t\) 为对数衰减。

**QED 修改后的擦除向量：**
\[
a_t = b_t \odot k_t + \lambda_h P^\perp_{k_t}(b_t \odot q_t),
\quad P^\perp_k(x) = x - k(k^\top x)
\]
其中：
- \(\lambda_h = \lambda_{\max} \cdot \text{sigmoid}(\theta_h)\) 是每头学习的强度参数，\(\lambda_{\max} = 0.25\)，\(\theta_h\) 初始化为 -2（即初始强度约为 0.03）；
- 投影 \(P^\perp_{k_t}\) 去除沿 \(k_t\) 的分量，保持键正交性，不改变 \(I - k_t a_t^\top\) 的非平凡特征值（稳定性条件不变）；
- 门控 \(b_t\) 缩放修正量，防止每次读取都无条件地擦除旧内容。

### 2.3 理论分析（在线学习视角）

给定衰减后的状态 \(\bar{S}_t = \text{Diag}(\exp g_t)S_{t-1}\)，GDN-2 的更新可写为：
\[
S_t^{\text{GDN2}} = \bar{S}_t + k_t\left[w_t \odot v_t - \bar{S}_t^\top(b_t \odot k_t)\right]^\top
\]

关键推导结果：

- 对任意与 \(k_t\) 正交的探测向量 \(x\)，key 导向的 delta 编辑**无法改变**该方向的读取响应；
- 将 query 分解为 \(q_t = \rho_t k_t + q_t^\perp\)（其中 \(\rho_t = q_t^\top k_t\)，\(q_t^\perp \perp k_t\)），则读取可分解为：
\[
o_t^{\text{GDN2}} = \rho_t\left[w_t \odot v_t + \bar{S}_t^\top((1 - b_t) \odot k_t)\right] + \bar{S}_t^\top q_t^\perp
\]
- 最后一项 \(\bar{S}_t^\top q_t^\perp\) 是旧状态中 delta 编辑无法触及的部分——这正是 QED 要消除的。

**QED 的精确作用：**
\[
o_t^{\text{QED}} = o_t^{\text{GDN2}} - \lambda_h \rho_t \bar{S}_t^\top d_t, \quad d_t = P^\perp_{k_t}(b_t \odot q_t)
\]
即：沿着 gated query 方向采样旧状态内容，将负采样沿 key 方向写回，通过 key-query 重叠 \(\rho_t\) 作用于当前读取。整个过程保持 rank-one 更新结构，额外计算仅为一个点积和一次减法，**不破坏 GDN-2 的核函数结构**。

## 6. 主要结论与发现

1. **长上下文检索显著改善**：QED 在两个种子的**每个**超过训练长度的评测长度上，S-NIAH-1 准确率均高于 GDN-2 基线。在 8K 长度处，QED 比基线高 27.2 个点（种子 0：91.6% vs 64.4%）和 33.6 个点（种子 1：84.2% vs 50.6%）；在训练窗口外提高最多达 39 个百分点。

2. **可用上下文长度约翻倍**：在相同检索准确率下，QED 将可用上下文从约 8K tokens 扩展到约 16K tokens。

3. **FDA 文档回忆稳定提升**：FDA 分别提高 3.4（种子 0：7.80 vs 4.45）和 3.7 点（种子 1：7.99 vs 4.26），两个种子下所有带投影的臂均高于基线。

4. **语言建模质量不受影响**：验证损失的完整跨度为 0.0034 nats，QED 不改变困惑度（机制针对检索而非语言建模）。

5. **方向源是真正有效的成分**：QED 在**每个外推长度**上都优于随机方向对照（QED-rand），说明 query 派生的方向本身是关键；而 gate 和 projection 的单独贡献在两个种子上符号不一致，结论尚不明确。

6. **投影约束在实测中实际处于非激活状态**：对未投影模型的 118 万 token-head 样本分析显示，经验特征值始终落在 [-0.011, 0.985]（安全区间）内，反事实投影仅改变特征值 <10⁻³。投影仍作为安全守护存在，但在当前规模下约束并未被激活。

7. **推理时强度测试结果不一致**：一个 checkpoint 随强度增加准确率持续上升（16K 处：44.8% → 73.0%），另一个几乎不变（≤2.4 点波动）。说明训练好的模型可以利用该修正，但并非所有 checkpoint 都一致依赖。

## 7. 主要优点

- **问题定位精准**：巧妙地指出现有 delta 规则模型的一个结构性错配——读取由 query 度量，擦除却由 key 驱动。这一分析角度新颖且直击要害。
- **方法极简、优雅**：仅修改擦除向量，增加一个 gated + key 正交的 query 派生修正项，不改变 rank-one 更新结构，不破坏稳定性条件，不引入新的核函数复杂度。额外开销近乎为零（一次点积 + 一次减法）。
- **理论推导扎实**：用快速权重视角给出了精确的数学分解，清晰展示了 GDN-2 无法触及的 \(S_t^\top q_t^\perp\) 项，以及 QED 如何通过 \(\rho_t \bar{S}_t^\top d_t\) 消除该部分。式 (11) 和 (12) 的精确等式非常有说服力。
- **实验控制较为严谨**：随机方向对照（QED-rand）的引入有效排除了"增加一个方向本身"而非"query 方向"的混淆解释；双种子设计暴露了消融不稳定问题，体现了学术诚实。
- **诚实报告**：作者明确承认 gate 和 projection 两个组件的消融效果尚不明确，没有过度宣称。
- **推断时间的强度扫描设计巧妙**：固定权重、改变有效 \(\lambda_{\max}\) 的方法干净地隔离了 QED 循环的贡献。

## 8. 不足与局限

- **实验覆盖面有限**：仅验证了 340M 这一单一模型规模、15B tokens 单一训练数据量。QED 的收益是否在更大模型（如 1B、7B 甚至更大）、更长训练和更丰富的任务上成立，尚未说明。
- **结论不一致性**：gate 和 projection 的消融结果在两个种子间不一致，作者无法确定这两个组件是否有独立贡献，削弱了"每个设计选择都必要"的论证强度。QED-nogate-noproj 在种子 1 上出现了极端性能崩塌（4K 处仅 42.2%，8K 处 17.2%，但 16K/32K 异常反弹至 44.2%/29.8%），说明缺少 gate 时训练对随机种子极为敏感。
- **推理时强度测试的局限**：两个 checkpoint 给出截然不同的结论，作者也承认该测试"不能说明训练过程中 \(\lambda_{\max}\) 的约束效果"。需要一个训练时 \(\lambda_{\max}\) 扫描才能回答这一问题。
- **任务覆盖的局限**：S-NIAH-2/3 在正文中仅提及其被评估，但没有报告具体结果；SQuAD-completion 无显著变化、SWDE 仅在种子 0 有微弱提升——目前收益主要集中在一类合成检索任务（S-NIAH-1 和 FDA）上，对真实世界长上下文任务的泛化效果尚不明朗。
- **计算资源信息不透明**：未报告 GPU 型号、数量和训练耗时，无法评估方法的计算性价比与结果的可复现成本。
- **仅两个种子说服力有限**：在观察到消融结果不一致的情况下，增加种子数量（3-5 个）会对核心结论的稳健性有更大帮助。
- **训练长度与外推范围差距大**：训练长度 2048，评测从 4K 到 32K，虽然展示了外推能力，但 32K 对于当前实际应用中的长上下文场景（100K+）仍较有限。
