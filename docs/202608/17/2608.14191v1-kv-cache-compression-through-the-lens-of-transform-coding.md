## 摘要
键值（KV）缓存存储来自过去token的信息，是长上下文推理中的主要内存瓶颈。现有的量化方法通过用较低精度的数据类型统一表示KV缓存，并设计量化方案来最小化缓存本身的重构误差，以此解决这一瓶颈，但并未考虑该误差如何通过注意力机制传播。我们证明，在白噪声量化模型下，期望的注意力感知失真可分解为键和值的加性贡献，这些贡献在token与通道维度上可因式分解。基于变换编码和逆向注水（信号处理与率失真理论中的经典工具），我们提出了注意力感知变换编码（AATC），它在校准集上分配比特以最小化注意力感知失真。在Llama-3.1-8B-Instruct和Qwen-2.5-7B-Instruct上，以及LongBench、RULER、GSM8K、MMLU-Pro和MATH-500数据集上的评估显示，我们的方法在约5.8倍压缩下实现了近无损精度，而每个基线至少在某些设置中性能有所下降。

## Abstract
The key-value (KV) cache stores information from past tokens and is a major memory bottleneck in long-context inference. Existing quantization methods address this bottleneck by representing the KV cache uniformly with lower-precision data types and designing quantization schemes to minimize reconstruction error in the cache itself, without accounting for how that error propagates through attention mechanisms. We prove that, under a white-noise quantization model, the expected attention-aware distortion decomposes into additive key and value contributions that factor across tokens and channels. Building on transform coding and reverse water-filling, which are classical tools from signal processing and rate-distortion theory, we introduce Attention-Aware Transform Coding (AATC), which allocates bits over a calibration set to minimize attention-aware distortion. On Llama-3.1-8B-Instruct and Qwen-2.5-7B-Instruct, evaluated across LongBench, RULER, GSM8K, MMLU-Pro, and MATH-500, our method achieves near-lossless accuracy at approximately $5.8\times$ compression, whereas each baseline degrades in at least some settings.

## 2. 方法论

### 2.1 核心思想

AATC的核心思想包含两个层面：

1. **理论层面**：推导一个注意力感知的失真度量（Theorem 1），将KV量化误差对注意力输出的影响分解为可计算的解析形式，替代传统的原始重构误差代理指标。
2. **算法层面**：在变换域中（而非原始特征空间）进行比特分配——先通过白化变换去相关、再通过逆向注水（reverse water-filling）在通道间分配比特。

### 2.2 关键技术细节

**(1) 注意力感知失真分解（Theorem 1）**

在单步解码注意力模型下，假设量化噪声满足白噪声假设（零均值、独立、对称），则注意力输出的期望平方失真分解为：

\[
D = D_K + D_V + R
\]

其中：

\[
D_K = \sum_{i,c} a_i^2 \|v_i W_O - o\|^2 q_c^2 \, \mathbb{E}[(\delta k_{ic})^2]
\]

\[
D_V = \sum_{i,c} a_i^2 \, \mathbb{E}[(\delta v_{ic})^2] \|W_{O_c}\|_F^2
\]

- \(D_K\)（键失真）：每个键通道的权重由三部分决定——注意力权重\(a_i^2\)、该token值对输出的残差贡献\(\|v_i W_O - o\|^2\)、查询分量\(q_c^2\)；
- \(D_V\)（值失真）：每个值通道的权重由注意力权重\(a_i^2\)和输出投影矩阵的通道范数\(\|W_{O_c}\|_F^2\)决定；
- \(R\)为高阶余项，在量化噪声较小时可忽略。

**(2) 白化变换（Whitening-based Decorrelation）**

由于KV向量在维度间高度相关，直接逐通道量化效率低下。AATC通过对投影权重矩阵\(W_K\)和\(W_V\)做基于白化的SVD分解，将原始投影分解为\(W = A B\)，从而在推理时缓存变换后的表示\(H = XA\)，并通过\(B\)无损恢复原始键值。该变换与KVTC/PALU的PCA变换等价，但AATC在分配比特时使用注意力感知的失真准则而非重构误差。

**(3) 逆向注水比特分配（Reverse Water-filling）**

在变换域中，AATC对每层每个通道分配比特数\(\{b_{\ell,c}\}\)，使得全局加权失真最小：

\[
\min \sum_{\ell,c} w_{\ell,c} (\sigma_{\ell,c})^2 2^{-2b_{\ell,c}} \quad \text{s.t.} \quad \sum_{\ell,c} b_{\ell,c} \le B
\]

- 键的权重：\(w^{(K)}_{\ell,c} = \frac{1}{T}\sum_i ((B^K_{\ell,c})^\top q_i)^2\)（查询对齐项）；
- 值的权重：\(w^{(V)}_{\ell,c} = \|(B^V W_O)^\top_{\ell,c}\|_F^2\)（输出投影项）；
- 该问题的连续松弛具有闭式逆向注水解：方差权重超过水位\(\lambda\)的通道获得更多比特，低于水位的通道分配0比特（即被丢弃），这等价于自适应秩截断。

**(4) 推理时量化**

- 使用通道级99百分位缩放与token级缩放相结合，避免outlier导致的量化溢出；
- 前4个token和最近128个token窗口保留全精度，窗口按16个token为单位滑动量化；
- 键与值分别设置独立的比特预算。

### 2.3 算法流程

AATC分为两个阶段：

- **离线校准阶段**：在校准数据集上，逐层计算输入协方差的Cholesky分解、投影权重的SVD，收集变换后各通道的方差和注意力感知权重，通过全局逆向注水确定所有层的键/值通道比特分配方案。
- **在线推理阶段**：对新token，将其投影到变换域并按预分配的比特数进行量化，缓存量化后的表示；在读取时通过B矩阵重建原始键值用于注意力计算。

## 6. 主要结论与发现

- **注意力感知失真分解定理**：在白噪声量化假设下，注意力输出失真可精确分解为键项与值项之和，两者均可在通道维度上进一步分解，且键/值量化可独立优化；
- **AATC实现近无损压缩**：在约5.8倍压缩下（约2.5-bit平均），AATC在所有基准上均与FP16基线统计不可区分，而KIVI在Qwen上显著退化（LongBench均值降至0.351，RULER-32k降至0.233）、KVQuant在Llama的RULER上大幅下降（4k达到0.715 vs 基线0.859）；
- **注意力感知权重在高压缩比下至关重要**：在2-bit激进压缩下，完整AATC在长上下文RULER上保持近基线精度，而var-only变体随上下文增长急剧退化（Llama RULER-32k：0.735 vs 0.851），说明\(q_c^2\)和\(W_O\)权重在低比特预算下是决定性的；
- **AATC在极端1-bit设置下仍具鲁棒性**：在Llama上LongBench均值0.325 vs KIVI的0.202，GSM8K 0.497 vs KIVI的0.026，表明变换+注意力感知分配的设计在预算极度紧张时退化更平缓；
- **统一了现有方法的视角**：已有的token驱逐、查询感知量化、低秩压缩等方法可被映射到失真分解中的不同因子，本文提供了一个统一的分析框架。
