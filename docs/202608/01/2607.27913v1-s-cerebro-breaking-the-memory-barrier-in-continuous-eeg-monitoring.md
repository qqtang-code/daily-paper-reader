## 摘要
基础模型为脑电图（EEG）分析提供了一种有前景的范式，利用大量未标记数据集的通用表征。然而，基于Transformer的架构面临一个关键瓶颈：全局注意力机制将注意力内存状态与信号持续时间耦合，导致连续监测期间内存溢出。为解决这一问题，我们提出了S-CEReBrO（流式CEReBrO），这是为连续监测设计的CEReBrO架构的演进。我们新颖的窗口交替注意力机制将注意力计算分解为固定大小的时空窗口，保证恒定KV缓存内存，因为只有活动窗口需要驻留注意力图。经验缩放分析证实，窗口交替注意力可以处理比全自注意力长100倍、比低秩线性注意力长3倍的信号。在长上下文下，与低秩线性注意力相比，窗口交替注意力仅需55%的内存，同时推理吞吐量提高2.1倍。S-CEReBrO在超过25,000小时、超过12,000名受试者的记录上预训练，在11个下游任务中的7个上达到最先进性能，参数减少高达60%。这项工作向着实现高效、通用、连续的EEG监测迈出了重要一步。附带代码仓库已提供。

## Abstract
Foundation models offer a promising paradigm for Electroencephalography (EEG) analysis, leveraging generalizable representations from vast unlabeled datasets. Yet, Transformer-based architectures face a critical bottleneck: global attention mechanisms couple the attention memory state to the signal duration, causing memory overflow during continuous monitoring. To address this, we introduce S-CEReBrO (Streaming CEReBrO), an evolution of the CEReBrO architecture designed for continuous monitoring. Our novel Windowed Alternating Attention mechanism factorizes attention computation into fixed-size spatiotemporal windows, guaranteeing constant KV cache memory as only the active window requires resident attention maps. Empirical scaling analysis confirms that windowed alternating attention can process signals 100X longer than full self-attention and 3X longer than low-rank linear attention. Compared to low-rank linear attention on long contexts, windowed alternating attention requires 55% of the memory while increasing inference throughput by 2.1X. Pre-trained on >25,000 hours of recordings from >12,000 subjects, S-CEReBrO achieves state-of-the-art performance on 7 of 11 downstream tasks, with up to 60% fewer parameters. This work represents a significant step toward the realization of efficient, generalizable, and continuous EEG monitoring. An accompanying code repository is available.

## 2. 论文提出的方法论：核心思想与关键技术细节

### 核心思想

- 提出 **S-CEReBrO（Streaming CEReBrO）**，核心创新是一种名为 **窗口化交替注意力（Windowed Alternating Attention）** 的机制。
- 该机制将注意力计算分解为**固定大小的时空窗口**（空间窗口和时间窗口），只有当前活跃窗口需要驻留注意力图，从而保证 KV 缓存内存**恒定（O(1)）**，与信号总时长 T 无关。

### 关键技术细节

1. **时空 Token 化（Spatiotemporal Tokenization）**
   - 对原始 EEG 信号 X ∈ R^(C×T) 使用滑窗（窗口长度 L、步长 S）进行分块，得到 patch 张量 P ∈ R^(C×Np×L)，其中 Np = ⌊(T−L)/S⌋ + 1。
   - 用共享卷积编码器将每个 patch 投影为潜在嵌入 E_(c,i) ∈ R^de。
   - 加入两个可学习嵌入：基于索引的时间位置嵌入 W_pos 和基于 3D 电极坐标（通过共享 MLP 映射）的连续空间嵌入 W_chan。
   - 最终输入张量 H^(0)_(c,i) = E_(c,i) + W_pos,i + W_chan,c。

2. **窗口化时间注意力（WTA, Windowed Temporal Attention）**
   - 对每个通道独立建模时间依赖。每个查询 q_(c,i) 只关注时间上局部邻域 N_t（窗口大小 w_t）内的键值对。
   - 引入**层间扩张因子（dilation d_l）和移位因子（shift s_l）**，在不增加内存的前提下扩大模型的感受野：
     - N_t(i, l) = {k ∈ [0, T−1] | k = i + (j·d_l + s_l)}，其中 j 范围由窗口大小决定。

3. **窗口化空间注意力（WSA, Windowed Spatial Attention）**
   - 在固定时间点 i 上促进跨通道信息交换，注意力限制在通道维度上大小为 w_s 的局部邻域 N_s 内。
   - 同样使用层间扩张和移位因子来交错感受野，使远处但生理相关的通道能在模型深度中交互。

4. **算法区别与复杂度**
   - 标准交替注意力（CEReBrO）需要保留所有时间位置和空间位置的 KV 状态，内存 O(T)，总复杂度 O(CT(C+T))。
   - 窗口化交替注意力通过"逐出（evict）"固定邻域之外的旧 token，使驻留内存保持恒定，总复杂度为 O(CNp(w_t+w_s)) ∝ O(CT)——严格的线性复杂度。
   - 采用 **FIFO 流式处理**而非固定窗口分块，保持连续有状态的感受野，避免分段批处理丢失长程依赖。

5. **预训练策略**
   - 使用**掩码自编码（MAE）**：将 token 中固定比例替换为共享可学习的 [MASK] token，训练目标为最小化掩码和可见位置的 patch 重建损失加权和：
     - L = L_m + αL_v，其中 L_(m,v) = (1/|K|) Σ ||P_(c,i) − P̂_(c,i)||²₂。

### 模型规格

- 参数约 2.4M，N=3 对注意力块，嵌入维度 d_e=180，注意力头数 h=5。
- 空间窗口大小 w_s = min(C, 7)，时间窗口大小 w_t = min(T, 5)。
- 扩张因子序列 {1,2,4}，移位因子序列 {0,1,−1,2,−2}。

## 6. 论文的主要结论与发现

1. **内存恒定**：窗口化交替注意力在总计算复杂度 O(CT) 线性扩展的同时，将 KV 缓存内存保持为与信号时长 T 无关的常量 O(1)。
2. **处理长信号能力**：可处理长达 50,000 秒（约 14 小时）的信号，比全自注意力长 100 倍、比低秩线性注意力长 3 倍。
3. **资源效率优势**：与低秩线性注意力相比，仅需 55% 的内存，推理吞吐量提高 2.1 倍。
4. **跨任务性能**：在 11 个下游基准中 7 个达到最先进水平，参数比现有基础模型减少最多 60%；特别在认知监测（STEW、SEED-VIG）和癫痫检测（CHB-MIT、Neonate）上优势明显。
5. **局部归纳偏置有效**：全局注意力对 EEG 分析往往冗余，局部时空窗口先验在多个任务上转化为更优性能。
6. **流式处理**：FIFO 有状态流式处理相比固定窗口分块，能更好地保持长程依赖，适合连续监测。

## 7. 优点

- **方法论亮点**：
  - 将窗口化注意力从 NLP 引入神经信号领域，考虑到 EEG 是 2D 非线性时空结构而非 1D 线性文本，设计合理。
  - 通过扩张/移位因子的层间交替，在不增加内存的前提下扩大了有效感受野，设计巧妙。
  - FIFO 流式处理保证了连续监测的"有状态"推理，避免了分段处理的上下文断裂。
  - 从算法层面保证内存恒定，而非依赖硬件优化或近似技巧，理论上限清晰。

- **实验设计亮点**：
  - 预训练数据规模大（25,000+ 小时，12,000+ 受试者），异质性高（多种 montage、参考方案、采样率）。
  - 严格排除 TUAB 受试者避免数据泄漏，受试者分层划分保证泛化评估可靠。
  - 限制基础模型基线在 <10M 参数，与部署场景相关性更强，对比公平性较好。
  - 同时报告多个指标（内存、吞吐量、参数数、任务性能），综合评估角度全面。
  - 认知监测任务（STEW、SEED-VIG）上的性能显著优于全局注意力基线（包括 CEReBrO 本身），有力验证了局部归纳偏置的价值。

## 总结

S-CEReBrO 是 CEReBrO 架构向连续 EEG 监测方向的重要演进。其窗口化交替注意力机制在理论上解决了 Transformer 系基础模型在长序列处理中的内存瓶颈问题，以恒定的 KV 缓存内存实现了线性复杂度的注意力计算，并在短片段下游任务中展现出优秀的性能-参数比。这项工作在方法论上有实质创新，实验覆盖较广，但缺乏小时级长序列的直接验证和必要的消融研究，资源投入的透明度也有待提高。总体而言，它为高效、连续的 EEG 基础模型提供了一条有前景的技术路径，但仍需更多实证工作来充分确立其在真实连续监测场景中的有效性。
