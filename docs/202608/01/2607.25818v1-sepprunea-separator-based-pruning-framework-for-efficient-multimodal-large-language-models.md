## 摘要
近年来，诸如Qwen2.5-VL和InternVL3等多模态大语言模型（MLLMs）为高分辨率输入生成了大量视觉令牌，导致巨大的计算成本。现有的视觉令牌剪枝方法要么依赖跨模态注意力，无法在预填充阶段之前进行剪枝，要么依赖高计算开销的多样性估计。我们观察到，来自视觉和文本令牌的注意力分数在模态分隔符令牌处达到峰值，这表明这些分隔符连接了两种模态。基于这一观察，我们提出了SepPrune，一种高效、无需训练、即插即用的剪枝方法，它使用分隔符令牌作为统一查询来对信息丰富的视觉令牌进行排序和选择。SepPrune重用了LLM内置的投影参数，无需修改架构。在Qwen2.5-VL-7B上的实验表明，SepPrune达到了最先进的性能，在去除80.2%的视觉令牌的同时保留了96.3%的原始准确率。

## Abstract
Recent multimodal large language models (MLLMs), such as Qwen2.5-VL and InternVL3, generate large numbers of vision tokens for high-resolution inputs, leading to substantial computational cost. Existing vision token pruning methods either depend on cross-modal attention and cannot prune before the prefill stage, or rely on diversity estimation with high computational overhead. We observe that attention scores from both vision and text tokens peak at modality separator tokens, suggesting that these separators bridge the two modalities. Based on this observation, we propose SepPrune, an efficient, training-free, plug-and-play pruning method that uses the separator token as a unified query to rank and select informative vision tokens. SepPrune reuses the LLM's built-in projection parameters and requires no architectural changes. Experiments on Qwen2.5-VL-7B show that SepPrune achieves state-of-the-art performance, retaining 96.3% of the original accuracy while removing 80.2% of vision tokens.

# SepPrune：一种基于分隔符的高效多模态大语言模型剪枝框架

## 1. 核心问题与研究动机

**背景：**
- 新一代多模态大语言模型（如 Qwen2.5-VL、InternVL3）采用任意分辨率视觉编码器，处理高分辨率图像/视频时产生**海量视觉令牌**（远超文本令牌数量），导致推理计算开销巨大、延迟显著。
- 先前研究已表明视觉令牌中存在高度冗余，因此**视觉令牌剪枝**成为提升 MLLM 推理效率的关键方向。

**现有方法的局限性：**
- **基于注意力（attention-based）** 的方法（如 FastV、FitPrune、SparseVLM）：依赖文本-视觉跨模态注意力，需要打断计算流，**无法兼容 FlashAttention 等高效算子**；部分方法依赖 [CLS] token，而现代视觉骨干中常不存在该设计。
- **基于多样性（diversity-based）** 的方法（如 DivPrune、CDPruner）：通过令牌间相似度矩阵识别冗余，但引入 **O(N²) 的额外计算开销**，反而可能增加延迟。

**本文的观察与关键洞见：**
- 通过可视化 Qwen2.5-VL-7B 的注意力分布，作者发现**浅层 LLM 中注意力峰值出现在模态分隔符（modality separator）位置**，而非语义丰富的视觉内容令牌上；随着网络加深，该峰值逐渐减弱（图 1）。
- 消融实验表明：删除等量分隔符令牌造成的性能下降**显著大于**删除视觉或文本令牌（图 2）。
- 由此提出假设：**模态分隔符不仅是边界标记，更是跨模态融合的“桥梁”**，在早期层中负责对齐和整合视觉与语言表征。

## 2. 方法论：SepPrune

**核心思想：**
- 利用模态分隔符作为**统一查询（unified query）**，对所有视觉令牌进行全局重要性评估，再保留 top-k 信息量最高的令牌，从而实现剪枝。

**输入序列结构：**
```
X_input = [T_sys, S_left, V, S_right, T_usr]
```
其中 T_sys 为系统提示词令牌，S_left 和 S_right 分别为视觉令牌前后的分隔符，V 为视觉令牌序列，T_usr 为用户文本令牌。

**关键技术细节：**

1. **分隔符作为统一查询：**
   - 由于因果注意力掩码的限制，只有位于视觉令牌**之后**的分隔符 S_right 能访问全部图像信息，故将其作为查询向量 Q_sep。
   - Q_sep 仅与所有视觉令牌的键矩阵 K_visual 计算注意力分数，将复杂度从 **O(N²) 降至 O(N)**。

2. **去除位置编码（RoPE）以消除位置偏置：**
   - RoPE 在评估令牌内在重要性时会引入位置偏置，导致查询向量偏好相邻令牌（例如偏向保留图像底部的令牌、过度剪除上部令牌）。
   - 计算剪枝分数时**省略 RoPE 操作**，得到纯粹基于语义内容的、位置无关的重要性评估。

3. **剪枝评分公式：**
   ```
   Score_prune = softmax( Q_sep · K_visual^T / √d_k )
   ```
   其中 Score_prune 为 1×N 的注意力分数向量，按分数高低保留 top-k 视觉令牌，形成剪枝后的序列 V′，再与分隔符和文本令牌拼接送入 LLM。

**方法特性：**
- **无需训练**，即插即用，不改变 LLM 架构
- **复用 LLM 内置投影参数（q_proj、k_proj）**，无需额外参数
- 在进入 LLM 之前完成剪枝，**兼容 FlashAttention**，无需复杂 KV-cache 管理

## 6. 主要结论与发现

1. **模态分隔符是跨模态桥梁：** 首次通过注意力分析揭示了分隔符在 MLLM 浅层中的跨模态对齐与融合作用，删去分隔符比删去视觉或文本令牌造成更大的性能损伤。
2. **SepPrune 有效且高效：**
   - 在 Qwen2.5-VL-7B 上，剪除 80.2% 视觉令牌时仍保留 **96.3%** 的原始性能，显著优于 FastV（93.2%）、DivPrune（91.2%）、CDPruner（93.6%）。
   - 剪除 60.5% 时保留 **99.0%** 性能。
   - 在极端剪枝（90.1%）下仍保持最优鲁棒性（87.2%）。
3. **跨架构泛化：** 在 InternVL3-8B 上，80% 剪枝比例下达到 93.1% 的相对性能，优于所有基线。
4. **计算优势：** 线性复杂度 O(N·D²) 显著优于多样性方法的 O(N²·D)，且端到端延迟最低。

## 7. 优点

- **新颖的视角：** 发现分隔符作为跨模态桥梁的关键角色，为 MLLM 多模态融合机制研究提供了深入见解。
- **简洁高效的设计：** 仅需一次分隔符向量与视觉键向量的矩阵乘法，线性复杂度，理论优雅。
- **即插即用、无需训练：** 可直接应用于现有 MLLM，无需微调或架构修改，实际部署友好。
- **兼容现有加速生态：** 在 LLM 之前完成剪枝，不与 FlashAttention 等高效算子冲突。
- **消除位置偏置是亮点：** 有意识地移除 RoPE 以避免定位偏好，且消融实验证实该设计有效。
- **实验较全面：** 12 个基准、2 种模型架构、多个剪枝比例，且包含视频任务和效率测序。
