## 摘要
键值（KV）缓存已成为长上下文大型语言模型推理中的主要内存和带宽瓶颈，使得超低位量化变得越来越重要。然而，现有的基于旋转的INT2方法在完整注意力读出之前优化缓存统计量或代理误差，尽管模型最终受到通过注意力和输出投影$W_O$传播的误差的影响。为了解决这一不匹配，我们提出了OptR，一种输出感知的旋转方法，最小化$W_O$之后的注意力输出误差。OptR将$W_O$之后的注意力输出误差分解为键诱导和值诱导项，并通过完整的INT2量化和注意力路径学习每头正交校正。OptR进一步应用注意力等效键重参数化来减少大的通道偏移，而不改变softmax分布。在三个模型和五个推理与编码基准上，OptR持续改进了QuaRot和OSCAR，并增强了长上下文检索，同时保持了分页KV缓存格式，推理开销可忽略不计。

## Abstract
The key-value (KV) cache has become a major memory and bandwidth bottleneck in long-context large language model inference, making ultra-low-bit quantization increasingly important. However, existing rotation-based INT2 methods optimize cache statistics or proxy errors before the complete attention readout, even though the model is ultimately affected by the error propagated through attention and the output projection $W_O$. To address this mismatch, we propose \textit{OptR}, an output-aware rotation method that minimizes post-$W_O$ attention-output error. OptR decomposes the post-$W_O$ attention-output error into key- and value-induced terms and learns per-head orthogonal corrections through the full INT2 quantization and attention path. OptR further applies an attention-equivalent key reparameterization to reduce large channel-wise offsets without changing the softmax distribution. Across three models and five reasoning and coding benchmarks, OptR consistently improves both QuaRot and OSCAR and strengthens long-context retrieval, while preserving the paged KV-cache format with negligible inference overhead.

- **现有方法的局限**：已有的旋转式 INT2 KV-Cache 量化方法（如 QuaRot、OSCAR、RotateKV）往往采用固定变换、缓存统计量或**完整注意力读出前的代理误差**（如缓存重建误差）作为旋转矩阵的优化目标。但模型最终受影响的是经**注意力加权**并经投影矩阵 $W_O$ 映射回隐藏空间后的**输出误差**——即代理目标与实际影响对象之间存在**目标失配（objective mismatch）**。
- **核心问题**：最小化缓存重建误差的旋转矩阵，并不一定是最能保持 post-$W_O$ 注意力输出精度的旋转矩阵。这一差异在仅有 4 个量化电平的 INT2 场景下尤为严重。
- **论文定位**：提出 **OptR**（Output-aware Rotation），一种直接以 post-$W_O$ 注意力输出误差为优化目标的输出感知旋转方法，作为对现有旋转基线的通用增强模块。

## 二、方法论

### 1. 核心思想
OptR 将 post-$W_O$ 注意力输出误差严格分解为**键诱导误差**与**值诱导误差**两部分，并通过完整的 INT2 量化与注意力路径，以端到端方式学习每个 KV 头的正交旋转校正。

### 2. 关键技术细节
- **输出误差分解**（式 8）：量化后的注意力输出与 BF16 输出之差可精确写为：
  - 键诱导项：$\delta y_{K} = (\Delta p)^{\top}V \cdot W_O^{\top}$，由键量化经 softmax 注意力的改变间接造成；
  - 值诱导项：$\delta y_{V} = (\hat{p}_K)^{\top}\Delta V \cdot W_O^{\top}$，由量化后的值向量经注意力加权聚合直接造成。
  - 这解释了为何原始缓存重建误差（式 9）只是代理目标，与实际输出误差（式 10）可能偏好不同的旋转方向。
- **注意力等价的键重参数化**：在旋转前对每个键减去校准集上获得的通道均值 $\mu$。由于对同一查询的所有 logits 施加相同的常数偏移，softmax 分布保持不变。将减法并入旋转域后，预计算 $\mu R_K$ 并在旋转后执行减法，避免额外的推理内核。
- **逐头正交校正的学习**：对每个 KV 头分别学习非约束矩阵 $A$，构造斜对称生成器 $S = A - A^{\top}$，通过矩阵指数 $\exp(S)$ 生成正交校正，乘以基础旋转：$R = R^0 \exp(S)$。该参数化保证整个校准过程中旋转始终保持正交性。
- **键旋转先于值旋转的序列优化**：先优化键旋转（KL 散度 + post-$W_O$ 输出误差），再在选定键旋转的量化注意力分布下优化值旋转，这样值旋转的优化考虑到了最终注意力权重。
- **INT2 感知校准**：校准全程经过完整的量化路径（旋转→裁剪→分组→舍入→反量化→逆旋转），对不可微的 INT2 舍入使用直通估计器（STE）计算梯度。模型权重冻结，仅优化每头旋转生成器。
- **损失函数**：
  - 键旋转损失：$L_K = D_{KL}(p_t \| p^K_t) + \lambda_K \cdot \frac{\|e_K\|^2_2}{d_{model}}$，兼顾注意力分布保持与输出误差最小化；
  - 值旋转损失：$L_V = \mathbb{E}\left[\frac{\|e_V\|^2_2}{d_{model}}\right]$，直接最小化值诱导输出误差。
- **推理实现**：键旋转直接应用到 query 上、值旋转及逆旋转吸收到 $W_V$ 和 $W_O$ 中，因此无需额外的旋转内核；与分页 KV-Cache（paged KV-cache）和融合解码内核保持兼容。

## 八、不足与局限

- **校准数据依赖**：校准与验证数据来自 GPQA-Diamond 解码轨迹，且部分消融的校准 token 虽与评测集不重叠，但仍源自同一评估池，存在一定的任务分布相关性和潜在的评估偏差风险。
- **超参数敏感性**：λK 的最优值随基础旋转而异（Qwen3-4B 上 OSCAR 偏好 λK=1，QuaRot 偏好 λK=10），论文虽统一取 1.0 以避免逐基座调参，但这也意味着并非对所有基座都是最优配置。
- **STE 近似的固有限制**：INT2 舍入的梯度通过 STE 近似获得，可能引入梯度偏差，论文未对此进行深入的理论分析。
- **长上下文仍有明显退化**：在 64K 和 128K 上下文下，OptR 相比 BF16 仍有显著掉点（如 Qwen3-8B 128K 下约 41.87% vs BF16 80.89%），说明极端长上下文下的 INT2 量化误差尚未完全解决。
- **对比基线覆盖有限**：TurboQuant 仅单次运行（因其 vLLM 实现 32K 评估慢）；未与 KIVI、Kitty、NSNQuant 等其他量化方法直接对比；RotateKV 也仅在相关工作提及而未纳入实验。
- **推理效率评估场景有限**：仅报告了单卡 A100、Qwen3-4B 上的效率，未覆盖多卡并行或更大模型的服务场景，也未深入分析 GQA 下每头旋转对 query 侧内核的具体开销。

## 总结

OptR 提出了一种以 post-$W_O$ 输出误差为目标的输出感知旋转校准框架，通过键重参数化与逐头正交校正，在几乎不增加推理开销的前提下显著改善了 INT2 KV-Cache 量化的精度与长上下文检索能力，具有较高的实用价值，但其校准数据依赖、超参数敏感性与极端长上下文下的剩余退化仍需后续研究解决。
