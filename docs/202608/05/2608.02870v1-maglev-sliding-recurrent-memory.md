## 摘要
我们提出了一种名为\ours{}的循环Transformer架构，具有固定大小的记忆，它推广了滑动窗口注意力，同时在训练期间保持可并行化。\ours{}由两个耦合模型组成：预填充器$Q$，利用全注意力（在实践中，我们对$Q$使用交织的全注意力和滑动窗口注意力，因为这会带来更强的性能。基本要求是$Q$比$P$更具表现力，并能访问完整历史）来生成记忆目标$m'_t$；以及解码器$P$，仅使用滑动窗口注意力和循环K/V注入来生成用于下一个词元预测的解码器记忆$m_t$。我们使用记忆一致性损失训练\ours{}，使$m_t$与$m'_t$对齐，从而允许推断时仅使用$P$。实验上，\ours{}在验证损失和下游预训练基准上优于滑动窗口和潜在循环Transformer基线。此外，在$P$和$Q$之间共享参数减少参数内存，同时保留了大部分收益。

## Abstract
We introduce \ours{}, a recurrent Transformer architecture with fixed-size memory that generalizes sliding-window attention while remaining parallelizable during training. \ours{} consists of two coupled models: a prefiller $Q$, which leverages full attention\footnote{In practice, we use interleaved full and sliding-window attention for $Q$, as this yields stronger performance. The essential requirement is that $Q$ be more expressive than $P$, with access to the full history.} to produce memory targets $m'_t$, and a decoder $P$, which uses only sliding-window attention and recurrent K/V injection to produce decoder memories $m_t$ for next-token prediction. We train \ours{} with a memory consistency loss that aligns $m_t$ with $m'_t$, allowing inference to use $P$ alone. Empirically, \ours{} improves validation loss and downstream pretraining benchmarks over sliding-window and latent recurrent transformer baselines. Moreover, sharing parameters between $P$ and $Q$ reduces parameter memory while preserving most of the gains.

# Maglev：滑动循环记忆（Sliding Recurrent Memory）——论文总结

## 1. 核心问题与整体含义（研究动机与背景）

- **背景矛盾**：标准 Transformer 依赖全因果自注意力，性能强但随上下文长度线性增长；滑动窗口注意力（SWA）虽能限制计算与 KV 缓存，却无法保留窗口外信息；传统 RNN/LSTM 具有固定状态和循环结构，但状态容量小、难以序列并行训练；线性注意力/状态空间模型虽可并行，但更新规则多为线性或结构化仿射，表达能力受限。
- **核心目标**：设计一种**词元级（token-wise）非线性循环记忆**语言模型，使记忆在每一词元后更新，推理时保持固定大小的窗口与缓存，同时训练时仍可并行化，兼容大规模预训练。
- **关键难点**：若训练时直接按循环方式展开记忆轨迹，则必须顺序生成 $m_1, m_2, \dots, m_T$，无法并行；需要一种机制在训练时绕过顺序依赖，同时保证推理时能独立循环运行。

## 2. 方法论：核心思想、技术细节与算法流程

### 整体框架：预填充器（Prefiller）+ 解码器（Decoder）双模型耦合

- **预填充器 Q**：使用更强的因果注意力（实践中为 SLSL 交错模式，含滑动窗口与全注意力），在**并行**条件下从完整输入序列 $x_{1:T}$ 生成目标记忆轨迹 $m'_{1:T}$。Q 仅用于训练，推理时丢弃。
- **解码器 P**：只使用纯滑动窗口注意力（全部层为 SSSS），接收输入 $x_{1:T}$ 和**移位后的目标记忆** $m'_{0:T-1}$（其中 $m'_0=0$），通过**循环 K/V 注入**混合局部与循环信息，预测下一词元并产生自己的记忆 $m_{1:T}$。

### 训练流程（两次序列并行前向传播）

1. **预填充器前向**：$m'_{1:T} = Q_\phi(x_{1:T})$
2. **解码器前向**：$m_{1:T} = P_\theta(x_{1:T}, m'_{0:T-1})$
3. **损失函数**：
   \[
   L(\Theta)=\frac{1}{|I|}\sum_{t\in I}\left[\mathrm{CE}(p_\Theta(\cdot|x_{\le t}), x_{t+1})+\lambda \frac{\|m_t-m'_t\|_2}{\sqrt{d}}\right]
   \]
   - 第一项为语言建模交叉熵；
   - 第二项为**记忆一致性损失**，迫使解码器记忆与预填充器目标记忆对齐；
   - $\lambda$ 为一致性权重。

### 推理阶段

- 丢弃 Q，仅用解码器 P 循环运行：$m_t = P_\theta(x_{t-W+1:t}, M_{t-1})$
- 将自身上一时刻记忆 $m_{t-1}$ 注入当前时刻 K/V 路径，保持固定窗口 $W=512$，缓存大小与注意力代价均与普通 SWA 相同，不随序列增长。

### 关键技术细节

- **循环 K/V 注入**：用共享投影将移位记忆映射为循环 K/V 特征：
  \[
  k^\text{rec}_t = \mathrm{RMSNorm}(W_k^\text{rec} m'_{t-1}), \quad v^\text{rec}_t = W_v^\text{rec} m'_{t-1}
  \]
- **门控混合**：层级门控加权局部与循环 K/V：
  \[
  \bar{k}_t = g^\text{loc}_t \odot k_t + g^\text{rec}_t \odot k^\text{rec}_t, \quad \bar{v}_t = g^\text{loc}_t \odot v_t + g^\text{rec}_t \odot v^\text{rec}_t
  \]
  门控由残差流产生，因子 2 保证零预激活时门控为中性值 1。
- **记忆与预测共享状态**：解码器最终归一化状态 $m_t$ 既作为记忆写入循环窗口，也作为语言模型头的输入。
- **参数共享**：默认 Q 与 P 共享 Transformer blocks，仅保留解码器路径独立的残差缩放参数；也可使用完全独立的 Q 堆栈。

## 6. 主要结论与发现

- **性能提升**：最好的独立参数 Maglev（$\lambda=1$）将 FineWeb-Edu 验证 BPB 从 SWA 的 0.7413 降至 0.7251，平均下游准确率从 54.1 提升至 56.4；共享参数 Maglev（$\lambda=0.1$）也优于所有基线。
- **超过 LRT 基线**：在相同注意力模式下，Maglev 优于对应的 LRT 模型。
- **参数共享可行**：共享 Q/P 的参数可保留大部分收益，仅损失少量性能，显著降低参数内存。
- **一致性权重非单调**：对独立 Q，较大 $\lambda$ 有益；对共享 Q，过大 $\lambda$ 会约束解码器表示并损伤下游性能。

## 7. 优点

- **方法创新**：利用“预填充器生成目标 + 一致性蒸馏”的思想，将循环记忆训练转化为两次并行前向，既保留非线性循环表达能力，又获得训练并行性。
- **工程实用**：推理时只使用纯 SWA 解码器，缓存与注意力代价与 SWA 完全一致，无需额外记忆 token 或分段边界。
- **架构统一**：记忆复用解码器最终状态，无需专用记忆载体；共享参数设计进一步提升参数效率。
