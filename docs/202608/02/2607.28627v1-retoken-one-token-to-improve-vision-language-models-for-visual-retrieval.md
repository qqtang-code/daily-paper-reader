## 摘要
长视觉上下文对视觉语言模型构成挑战：随着干扰项数量的增加，性能下降，并且在GPU内存限制下，一次性处理所有token在计算上不可行。我们提出了ReToken，一个可学习的嵌入，作为显式检索目标进行训练，从预填充的视觉KV缓存中选择一组与查询相关的稀疏视觉token。仅在小型图像问答数据集上训练，ReToken在图像和视频基准上均带来一致提升：在Visual Haystacks上，Qwen3VL-8B提升13.4个百分点，InternVL3.5提升12.4个百分点（相对提升>20%）；在LVBench上，零样本迁移到长视频，Qwen3VL-8B提升8.0个百分点。由于其轻量设计，训练和长视频推理均可在单个H100上完成。代码可在https://github.com/avaxiao/ReToken获取。

## Abstract
Long visual context poses a challenge for vision-language models: performance degrades as the number of distractors grows, and processing all tokens at once is computationally infeasible under GPU memory constraints. We present ReToken, a single learnable embedding trained as an explicit retrieval target that selects a sparse set of query-relevant visual tokens from a pre-filled visual KV cache. Trained on only a small image-QA dataset, ReToken yields consistent gains across image and video benchmarks: on Visual Haystacks it improves Qwen3VL-8B by 13.4 points and InternVL3.5 by 12.4 points (>20% relative), and on LVBench it transfers zero-shot to long video for an 8.0-point gain with Qwen3VL-8B. Thanks to its lightweight design, both training and long-video inference fit on a single H100. Code is available at: https://github.com/avaxiao/ReToken

## 2. 论文提出的方法论

### 2.1 核心思想

- 在一个可学习嵌入 token \( X_r \)（ReToken）被附加到问题 token 之后，随输入一起送入 VLM。
- 在最终层，ReToken 的输出经一个轻量投影矩阵 \( W_r \) 映射为检索查询向量 \( Z_r \)。
- 每一帧（Frame）用一个平均 value 向量 \( \bar{v}_f^{(N)} \)（该帧所有视觉 token 在最终层的 value 投影均值）表示。
- 检索分数定义为：  
  \[
  s_f^{(N)} = \cos(Z_r, \bar{v}_f^{(N)})
  \]
- 取分数最高的 \( K \) 帧作为与问题最相关的帧，用于后续答案生成。

### 2.2 关键技术细节

- **训练阶段**：
  - 默认冻结 VLM，仅训练 ReToken 嵌入 \( X_r \) 和投影矩阵 \( W_r \)（以及可学习的 logit 缩放参数 \( \tau \)）。
  - 损失函数为**类别平衡二元交叉熵**（Class-Balanced BCE），正负样本（相关/无关帧）分别求平均再合并，避免大量负样本主导训练：
    \[
    \mathcal{L}_{\text{ret}} = -\frac{1}{|F^+|}\sum_{f \in F^+} \log \sigma(\tau s_f^{(N)}) - \frac{1}{|F^-|}\sum_{f \in F^-} \log \sigma(-\tau s_f^{(N)})
    \]
  - 变体设置（部分微调）：放开 VLM 前 3 层进行微调时，额外加入生成损失 \( \mathcal{L}_{\text{gen}} \)（标准 next-token prediction），总损失为 \( \mathcal{L} = \mathcal{L}_{\text{ret}} + \lambda \mathcal{L}_{\text{gen}} \)。

- **推理阶段（两遍检索-生成流程）**：
  1. **编码缓存**：视频以分块滑窗方式编码一次，KV 缓存持久化存储；多问题共享同一缓存。
  2. **第一遍（检索）**：ReToken 与问题一起前向传播，在早期层通过自身的 value 投影对各帧打分并限制注意力范围（top-\( K_1 \)=256 帧）；最终在最后一层计算检索分数并选出 top-\( K \) 帧。
  3. **第二遍（生成）**：仅加载所选 \( K \) 帧的 KV 缓存，进行标准答案生成。

- **训练数据**：默认使用 MIRAGE 多图 QA 训练集，经三重过滤（记忆化过滤、难度过滤、多图过滤）得到约 70,686 个样本。

## 6. 论文的主要结论与发现

1. **注意力（query-key）分数在 VLM 中不适合作为视觉检索信号**；而**value 空间**在具有精确检索目标时携带更强的文本对齐语义。
2. **ReToken 作为显式学习检索目标**，在冻结 VLM 的情况下，大幅提升检索精度与下游 QA 准确率：
   - Visual Haystacks C=50：Qwen3VL-8B 从 58.6 → 72.0（+13.4）；InternVL3.5 从 57.3 → 69.7（+12.4）。
   - LVBench：零样本迁移，40.6 → 48.6（+8.0）。
   - QAEgo4D：K=16 时 53.6 → 60.0。
3. **只训练 ReToken 就能有效工作**；部分微调前 3 层在图像任务上略有提升，但会损害视频任务的零样本迁移表现（域偏移）。
4. **ReToken 在最需要精确检索的任务上增益最大**：键信息检索（+15.4）、实体识别（+10.5）；在证据分散的任务（如摘要）上反而有损（-5.2）。
5. **推理成本增加很小**：每问题约增加 0.4 秒检索开销，但显著提升召回与准确率。

## 7. 优点

### 7.1 方法设计层面

- **极简且高效**：仅增加一个 embedding 和一个投影矩阵，冻结 VLM，训练代价极小（4 小时内完成）。
- **即插即用**：不修改 VLM 结构，可直接应用于不同主干模型（Qwen3VL、InternVL3.5），且代码开源。
- **可扩展的推理管线**：两遍 retrieve-then-answer 流程支持“一次编码、多问题复用”，适合实际多轮交互场景。
- **理论洞察有价值**：明确指出 value 空间比 key 空间更适合检索，并给出充分证据，为后续工作提供重要方向。

### 7.2 实验设计层面

- **诊断先行**：先用控制实验（两图检索、层间 Recall、注意力可视化）建立“注意力不可靠→value 空间更优”的论点，再提出方法，逻辑链条清晰。
- **零样本迁移验证有力**：图像训练 → 长视频测试的零样本结果说明 ReToken 学到的是通用的“检索能力”而非数据集的表面模式。
- **多维度评估**：覆盖准确率、召回率、运行延迟、峰值显存、问题类型分解等角度，评估立体。

## 8. 不足与局限

### 8.1 方法论局限

- **帧级独立打分假设过强**：ReToken 逐帧独立计算检索分数（基于帧内 value 均值），无法捕获跨帧时序组合信息。作者在 Future Work 中也承认，时间偏移类问题（如“在我进房间之前发生了什么”）无法通过内容匹配解决。
- **帧级平均池化会稀释细微证据**：若答案只存在于个别 token 上，帧级平均会使该信号被大量无关 token 淹没，作者将此列为未来工作方向。
- **需要两遍前向传播**：相比单遍推理，检索阶段增加约 0.4 秒/问题；对极端短时延场景不友好。
- **早期层检索预算 \( K_1=256 \) 帧仍是超参数**：论文未对该值做充分敏感性分析。

### 8.2 实验覆盖局限

- **训练数据单一**：仅使用多图 QA（MIRAGE 过滤集），未探索视频数据训练是否能进一步提升视频任务性能。
- **InternVL3.5 训练不充分**：1 epoch 导致大上下文（C=100）下的增益显著低于 Qwen3VL，削弱了跨主干模型结论的强度。
- **视频基准的采样率局限**：默认 0.5 FPS，可能遗漏快速变化的关键帧；更高的采样率下 ReToken 的表现未评估。
- **缺少与其他视频检索方案（SeViLA、VideoAgent、VideoTree）的端到端对比**：ReToken 主要与 ReKV 和 Uniform 基线对比，未与更广泛的检索-问答流水线同台竞技。

### 8.3 偏差与风险

- **训练数据过滤引入了选择偏差**：论文剔除了“模型已记忆答案”的样本，这使 ReToken 在“真正需要检索”的样本上学得更强，但也意味着在真实世界中模型已记忆的内容上，ReToken 的增益可能被高估。
- **标签依赖**：训练需要每张图/帧的相关性标注（相关/不相关二值标签），在真实大规模数据集中获取此类监督信号成本较高。
- **领域泛化风险**：图像域训练的 ReToken 虽然零样本迁移到视频有效，但 LVBench 的问题类型分析显示其在时间定位、事件理解上增益有限，在摘要任务上反而有害——说明其适用场景（证据局部化、可命名）存在边界。
