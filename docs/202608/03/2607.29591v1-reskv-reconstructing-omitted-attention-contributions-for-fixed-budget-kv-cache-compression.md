## 摘要
KV缓存压缩对于高效的长上下文推理至关重要。现有的驱逐方法会永久丢弃未选中的token，从而移除它们对注意力的总体贡献。基于合并的替代方案保留了更多信息，但可能扰动本应保持精确的保留键和值。我们观察到，缓存驱逐所省略的信息可以表述为softmax注意力分子和分母中的残差统计量。基于这一观察，我们提出了ResKV，它将固定的KV预算划分为精确的主缓存和紧凑的残差缓存，以重建被省略token的贡献。ResKV让主缓存token和残差条目参与相同的softmax归一化，因此残差条目能够恢复注意力分子和分母的量，而不是作为事后修正。构建时的验证代理决定每个层和KV头的残差分配，而解码时的动态门控针对单个查询调整残差贡献。在LongBench和RULER上的综合评估，涵盖了查询感知和查询无关设置、多种骨干网络、缓存预算和代表性压缩基线，证明了在相同保留KV预算下的广泛改进，同时保持了压缩解码的实际效率，包括峰值内存使用和长上下文解码吞吐量。

## Abstract
KV cache compression is essential for efficient long-context inference. Existing eviction methods permanently discard unselected tokens and consequently remove their aggregate contribution to attention. Merging-based alternatives preserve more information but can perturb retained keys and values that should remain exact. We observe that the information omitted by cache eviction can be formulated as residual statistics in both the numerator and denominator of softmax attention. Based on this observation, we propose ResKV, which divides a fixed KV budget into an exact main cache and a compact residual cache that reconstructs the contribution of omitted tokens. ResKV lets main-cache tokens and residual entries participate in the same softmax normalization, so residual entries restore both attention numerator and denominator mass rather than acting as a post-hoc correction. A construction-time validation proxy determines residual allocation for each layer and KV head, while a decode-time dynamic gate adjusts residual contributions for individual queries. Comprehensive evaluations on LongBench and RULER, covering query-aware and query-agnostic settings, multiple backbones, cache budgets, and representative compression baselines, demonstrate broad improvements under the same retained KV budget while preserving the practical efficiency of compressed decoding, including peak memory usage and long-context decode throughput.

## 1. 论文的核心问题与整体含义（研究动机与背景）

长上下文大语言模型在自回归生成中依赖 KV 缓存避免重复计算，但 KV 缓存随上下文长度线性增长，成为推理阶段的主要内存与带宽瓶颈。KV 缓存压缩因此成为长上下文高效推理的关键手段，但现有方法存在两难：

- **驱逐类方法**（如 H2O、SnapKV、AdaKV、TOVA）将缓存压缩视为二值决策：保留高分 token、永久丢弃其余 token。这会导致被丢弃 token 的注意力贡献（softmax 分子中的数值贡献和分母中的归一化质量）被彻底移除，尤其在注意力分布分散、或未来查询可能重新关注这些 token 时风险很大。
- **合并类方法**（如 CaM、KVMerger、KeepKV、SemantiCache）将逐出 token 的信息折叠进保留条目中，虽然减少了信息丢失，但会扰动原本应保持精确的键值对，对尖锐检索场景有害。

论文的核心洞察是：**驱逐所省略的信息可以精确地表述为 softmax 注意力分子与分母中的一组残差统计量**。基于此，ResKV 在固定 KV 预算下将缓存划分为“精确主缓存 + 紧凑残差缓存”，让残差条目以共享 softmax 的方式参与解码，在不增加总缓存槽位的前提下重建被省略的注意力贡献。

## 2. 论文提出的方法论

### 2.1 核心思想

- 将固定预算拆分为 `b = m + r`：主缓存 M 保留 m 个精确 KV 槽位，残差缓存 R 用 r 个槽位近似被省略 token 集合 E = S \ M 的注意力贡献。
- 关键公式推导如下：

  \[
  o(q) = \frac{\sum_{p \in M} e^{a_p(q)} v_p + \sum_{p \in E} e^{a_p(q)} v_p}{\sum_{p' \in M} e^{a_{p'}(q)} + \sum_{p' \in E} e^{a_{p'}(q)}}
  \]

  驱逐丢掉的是 E 的分子与分母和；ResKV 的目标是用残差条目重建这两项。

### 2.2 残差条目构造

- 将 E 划分为 r 个组，每个组存储三个量：**均值键** k̄ⱼ、**均值值** v̄ⱼ、**组大小** cⱼ。
- 利用 Lloyd 迭代（约 4 次）在键空间聚类，最小化组内键平方距离；初始化选取 E 中主缓存得分最高的 token。
- 理论上，当组内 key 对查询产生相似 logit 时，组贡献可由 `cⱼ · exp(k̄ⱼ·q/√d)` 近似重建。当 cⱼ=1 时退化为精确 token。

### 2.3 共享 softmax 解码

- 残差条目不是事后修正，而是与主缓存参与同一个 softmax 归一化。
- 主缓存 logit：\(a_p = \langle q, k_p\rangle/\sqrt{d}\)
- 残差 logit：\(\tilde{a}_j = \langle q, \bar{k}_j\rangle/\sqrt{d} + \log c_j + \log g(q)\)
- 分子分母同时加上残差项，恢复全缓存的注意力量；R=∅ 时退化为硬驱逐。

### 2.4 自适应残差控制

- **构建时验证代理**：将观测窗口划分为 fit 集和 validation 集；对候选残差预算比例 {0, 0.05, 0.10, 0.15, 0.20}，计算残差增强输出与全缓存输出的重建误差，仅当残差优于纯主缓存且相对提升超过 δ=0.01 时启用，实现逐层、逐 KV 头的自适应分配。
- **解码时动态门控**：用主缓存最大注意力权重衡量注意力尖锐度，sigmoid((τ − p_max)/Tg) 调节残差 logit 幅度，τ=0.25、Tg=1/12、gmin=0。主缓存注意尖锐时压低残差以保护检索峰值，分散时保留残差以恢复聚合贡献。

## 7. 优点

- **理论动机清晰**：从 softmax 分子分母分解出发，将信息丢失精确定义为可重建的残差统计量，推导（附录 A）包含残差近似的误差上界，方法论有坚实的理论支撑。
- **主缓存保持精确**：不修改保留 token 的键值，避免合并方法对精确记忆的扰动，保留尖锐检索能力。
- **共享 softmax 设计新颖**：残差条目同时恢复分子与分母质量，且是注意力参与方而非外部输出修正，消融证实该设计带来明显增益（RepoBench-P +3.00 分）。
- **两级自适应机制完善**：构建时验证代理实现逐层、逐头预算分配；解码时动态门控按查询调节残差，兼顾恢复聚合贡献与保护检索峰值。
- **兼容主流推理框架**：通过 log-sum-exp 统计量与 FlashAttention-2 融合，不破坏主分支的融合注意力路径。
- **部署场景覆盖全面**：同时评估 query-aware 与 query-agnostic，后者更贴近前缀缓存复用的实际服务场景。

## 8. 不足与局限

- **模型与架构覆盖有限**：仅评估两个 7–8B GQA 指令微调模型，未验证更大的模型、非 GQA 架构、多批次服务场景等；论文附录 E 也承认这一局限。
- **统计显著性不足**：每个配置单次运行，固定随机种子，未提供多次运行的均值方差或显著性检验，任务级差异可能受噪声影响。
- **残差近似敏感性**：均值键/均值值表示假设组内 token 对查询有相似 logit，组内异质性较大时误差会扩大（附录 A.2 的理论界）；门控超参数（τ、Tg）对不同模型和任务的泛化性尚未充分探索。
- **构建后不更新**：压缩仅在 prefill 后一次性完成，长生成过程中不刷新残差条目，对生成主导的工作负载可能不够理想。
- **解码吞吐量有一定代价**：残差分支和动态门控引入中等开销，文中仅与 SnapKV 对比，缺乏与合并类方法的效率对比。
- **部分任务增益有限**：有些任务（如部分合成检索 CWE 类）在特定预算下提升甚微，q-agnostic 设置下部分任务得分绝对值仍较低。
