## 摘要
大型语言模型（LLM）在各种应用中取得了显著突破。然而，它们的架构在预训练中仍然效率低下，原因有二：（i）自注意力缺乏明确的局部性归纳偏置，导致对序列内部局部信息的冗余建模；（ii）混合专家（MoE）隐式地将知识存储与计算路径耦合，阻碍了对序列外部全局知识的灵活访问。为了克服这些限制，我们提出了LoKiFormer，一种新颖的LLM架构，它通过两个专用模块增强了标准解码器：1）局部融合注意力（LFA），将卷积融合引入注意力，显式捕获局部模式，使注意力能够在更有信息量的表示上操作；2）知识记忆模块（KMM），引入参数化键值记忆，将全局知识显式存储在可寻址的槽中，将存储与计算解耦，实现直接知识检索。这些模块共同使LoKiFormer能够在两个层面上实现更高效、更有效的信息整合。实验结果表明，LoKiFormer在预训练中的收敛速度比基线模型快1.33倍，凸显了其相对于现有LLM架构的优越性。

## Abstract
Large language models (LLMs) have achieved remarkable breakthroughs across various applications. However, their architectures remain inefficient in pretraining due to two main limitations: (i) self-attention lacks an explicit inductive bias for locality, leading to redundant modeling of sequence-internal local information; (ii) mixture-of-experts (MoE) implicitly couples knowledge storage with computational pathways, hindering flexible access to sequence-external global knowledge. To overcome these limitations, we propose LoKiFormer, a novel LLM architecture that augments the standard decoder with two dedicated modules: 1) Local Fusion Attention (LFA), which incorporates a convolutional fusion to attention, explicitly capturing local patterns and allowing the attention to operate on more informative representations; 2) Knowledge Memory Module (KMM), which introduces a parametric key-value memory that explicitly stores global knowledge in addressable slots, decoupling storage from computation and enabling direct knowledge retrieval. Together, these modules enable LoKiFormer to achieve more efficient and effective integration of information at both levels. Experimental results show that LoKiFormer converges 1.33x faster in pre-training than baseline models, underscoring its superiority over existing LLM architectures.

## 论文提出的方法论

### 架构总体设计

LoKiFormer 在标准解码器块（Decoder Block）基础上扩展了两个互补模块：

- **Local Fusion Attention（LFA，局部融合注意力）**：处理序列内部局部信息。
- **Knowledge Memory Module（KMM，知识记忆模块）**：处理序列外部全局知识。

算法总体流程如下（对应论文 Algorithm 1）：

1. 输入表示 U ∈ R^(L×d) 先经过 LFA 的卷积融合，得到局部增强表示 Û。
2. 将 Û 投影为 MLA 所需的潜在表征 c_Q 和 c_KV。
3. 通过多头潜在注意力（MLA）计算得到注意力输出 O_A。
4. 将 c_KV 投影为查询特征 H，经 KMM 检索得到知识增强输出 O_K。
5. 将 O_A 与 O_K 相加后送入 MoE 层，得到最终输出 O = MoE(O_A + O_K)。

### 局部融合注意力（LFA）

- **设计动机**：自然语言存在强局部性（相邻 token 语义高度相关），但 MLA 和标准自注意力对短程与长程依赖不加区分地进行建模，预训练时捕获局部细粒度关系效率低下。
- **核心思想**：在注意力之前引入**因果 1D 分组卷积**，显式融合相邻 token 的特征，为模型注入显式局部归纳偏置。
- **技术细节**：
  - 将输入 U 按特征维度拆分为 h 组（h 等于注意力头数），每组独立进行卷积，使每个头学习不同的局部融合模式。
  - 对第 g 组，使用卷积核 Θ^(g) ∈ R^(k×d_h×d_h)，沿序列维度聚合前 k 个邻居的信息。位置 t 的输出仅依赖区间 [t−k+1, t]，保证因果性。聚合公式为：
    - Û_t^(g) = Σ_{s=0}^{k−1} U_{t−s}^(g) · Θ^(g)[s]
  - 使用步长为 1 和适当填充保持序列长度不变。
- **参数开销**：LFA 仅在 7B 模型中引入约 0.41% 的额外参数，非常轻量。

### 知识记忆模块（KMM）

- **设计动机**：MoE 将知识隐式编码在参数中，每次查询都需经过线性变换，缺乏透明性和灵活重用能力。
- **核心思想**：引入**参数化键–值（Key–Value）记忆结构**，将全局知识显式存储在可寻址的槽（slots）中，将知识存储与计算路径解耦，支持直接查询与检索。
- **技术细节**：
  - 输入为 MLA 的潜在表征 c_KV ∈ R^(L×d_c)，先通过可学习的投影 W_H 映射到查询空间：H = c_KV W_H。
  - 知识库包含 F 个字段：K ∈ R^(F×d_u)（键）和 V ∈ R^(F×d_v)（值），两者随机初始化并端到端训练。
  - 采用**多组检索（multi-group retrieval）**：将查询 H 和键值参数按特征维度分为 c 组，在每组内计算缩放点积相似度、经 softmax 加权聚合值向量，最后拼接各组输出：
    - Z^(i) = softmax( H^(i) K^(i)ᵀ / √d_u ) V^(i)
  - 检索结果经线性投影 W_O 回到模型维度，得到 O_K，与 MLA 输出相加后送入 MoE。
- **与注意力的区别**：注意力中键和值由输入动态计算，用于建模序列内部依赖；KMM 使用固定的参数化键值，用于复用跨任务的全局知识。KMM 具有可解释性和可编辑性优势。
- **可视化验证**：在 MMLU 五个领域（代数、化学、物理、政治、历史）上，KMM 的知识字段自发涌现出领域专精化现象（如 Field 25 专用于历史、Field 51 专用于物理），证明其具备结构化知识组织和可解释检索能力。

## 论文的主要结论与发现

1. **预训练加速显著**：LoKiFormer 达到基线 10k 步 PPL 的时间仅需 7.5k（验证集）步，收敛速度提升 **1.33×**。
2. **两大模块均有贡献且互补**：单加 LFA 使 MMLU 从 17.9 提升至 21.2，再加 KMM 提升至 22.9，二者结合达到 25.7（零样本基座模型），表明 LFA 与 KMM 各自解决不同层面的效率问题。
3. **同规模下性能领先**：7B 模型在 MMLU（91.5）、CMMLU（93.4）、C-Eval（92.8）、ARC-C（96.2）上超越所有同规模基线，甚至超过 Llama-3.1-405B、Hunyuan-Large 等大一个数量级的模型。
4. **KMM 知识字段具有领域专精化和可编辑性**：字段删除实验表明，移除特定字段主要损害对应领域性能（如移除 Field 32 使代数下降 31.8%），且跨领域影响符合学科语义关联（政治/历史相互影响，STEM 领域间影响有限）。
5. **KMM 字段间近乎正交**：最大非对角余弦相似度仅约 0.059，说明字段没有塌缩或冗余。
6. **LFA 让注意力更专注于全局建模**：注意力熵分析表明 LFA 将局部特征提取从注意力中解耦出来，使注意力保持更宽的接收野。

## 优点

1. **问题定位准确**：指出了现有 LLM 架构两个真实且重要的低效来源——注意力缺乏局部归纳偏置、MoE 知识存储与计算耦合。
2. **模块设计轻量且互补**：LFA 仅增加 0.41% 参数，KMM 增加约 2.12%，两者分别针对局部和全局信息，形成清晰的职责分工，且与 MLA、MoE 等主流架构良好兼容。
3. **可解释性与可编辑性突破**：KMM 将知识显式存储在可寻址字段中，通过可视化验证了领域专化现象（spontaneous domain specialization），并通过字段删除实验证明了知识的可编辑性，这是传统 MoE 难以实现的。
4. **不干扰 KV Cache 和推理效率**：LFA 不改变注意力稀疏性和 KV 缓存机制，推理吞吐几乎不受影响。
5. **严谨的消融设计**：对卷积核大小、分组策略、字段数量等超参数均进行了独立验证，选择有据可依。
6. **多规模验证**：覆盖 1B 到 60B 六个规模，证明了方法的可扩展性。
7. **SFT 数据去污染严格**：五阶段数据构建流水线中包含了字面匹配、语义匹配、知识三元组匹配等多重去污染策略，残漏率控制在 0.1% 以下，并进行了额外实验排除数据偏差。

## 不足与局限

1. **GSM8K 表现明显偏弱**：LoKiFormer-7B 在 GSM8K 上为 73.0，远低于 Llama-3.1-8B（84.5）、Qwen2.5-7B（91.6）甚至远小于自身的 Phi-3-medium（91.0）。论文对数学推理能力偏弱的原因未作说明，这可能是架构（如 KMM 对推理类知识支持有限）或数据分布（4.5T 语料中数学占比）导致的问题。
2. **跨论文对比公平性受限**：与 Llama、Qwen 等基线对比时，各模型的训练数据、token 数、SFT 流程并不一致。虽然论文使用 4.5T tokens 训练 7B 模型，但基线的训练 token 数可能更多或更少（如 Llama-3.1-8B 约 15T tokens），因此 Table 2/3 的领先优势并不能完全归因于架构改进。
3. **绝对训练规模有限**：主实验虽然声称 4.5T tokens，但消融实验仅训练 10k 步（约 21B tokens），kernel size 更大值（k>4）和 fields 更大值（F>128）因成本未探索，最优超参数可能存在偏移。
4. **未包含长上下文评估**：论文声称 MLA 对长上下文建模有利，且 33B/60B 使用 4096 上下文训练，但未在长上下文基准（如 LongBench）上进行评估。
5. **SFT 数据集构建的主观性**：第三阶段依赖 LLM（Qwen-Max）筛选和生成问答对，可能引入评判模型的偏差；语义检索过滤（阶段 2）可能使数据偏斜于特定知识领域（虽然论文做了控制实验缓解此疑虑）。
6. **缺少训练稳定性细节**：论文仅提及梯度范数低于 1.0，未展示完整训练损失曲线、峰值学习率策略（warmup/decay schedule）等复现所需的关键信息。
7. **KMM 字段数量**：论文在 7B 模型上仅用 64 个字段，无法充分展示大规模参数下字段容量的扩展空间；知识字段删除实验仅针对 Layer 4，其他层的可编辑性证据不足。
