## 摘要
扩散语言模型（DLMs）通过迭代精化序列，使得早期预测能够随上下文演化而被修正。这种回滚能力使其有别于不可逆的自回归生成，但也导致推理成本高昂。每次去噪更新都会改变全局上下文，迫使提示（prompt）和响应（response）状态都被重新计算，尽管只有响应令牌是可修订的。键值（KV）缓存本可降低此成本，但传统缓存假设历史状态不可变，因此难以与回滚兼容。在本文中，我们引入了面向可回滚扩散语言模型的高效回滚缓存隐藏状态自适应复用方法（Archer），一种无需训练的KV缓存方法。Archer不对称地将可变的响应状态与当前假设保持同步，同时在有界状态邻域内复用提示的K/V。尽管在双向注意力下提示表示也会变化，但其令牌身份保持不变；因此，有界复用能够摊销重复的提示计算，而无需缓存可变响应状态。它还延迟了来自暂定令牌的反馈，减少了对瞬时高置信度错误的过早强化，并为回滚纠正这些错误提供了更多机会。我们的分析将提示复用刻画为一种与可逆性对齐的缓存边界，界定了其状态相关的近似误差，并给出了保持全刷新决策的解码器余量条件。现有DLM加速方法往往以质量换取速度。Archer改变了这一权衡前沿，在主测试套件上实现了最佳平均性能33.63%以及2.57倍的平均加速。在评估的各种设置中，它使Pass@1最多提升3.05个百分点，并达到最高2.95倍的加速。受控分析将质量提升与延迟提示反馈联系起来，并验证了状态感知的刷新策略。我们的代码可在 https://github.com/Hxnng/Archer 获取。

## Abstract
Diffusion language models (DLMs) iteratively refine a sequence, allowing earlier predictions to be revised as context evolves. This rollback capability distinguishes them from irreversible autoregressive generation, but makes inference costly. Every denoising update alters the global context, forcing both prompt and response states to be recomputed even though only response tokens are revisable. Key-value (KV) caching could reduce this cost, yet conventional caching assumes immutable historical states and is therefore difficult to reconcile with rollback. In this paper, we introduce Adaptive Reuse of Cached Hidden States for Efficient Rollback (Archer), a training-free KV caching method for rollback-capable DLMs. Archer asymmetrically keeps the mutable response synchronized with the current hypothesis while reusing prompt K/V within a bounded state neighborhood. Although prompt representations also change under bidirectional attention, their token identities remain fixed; bounded reuse therefore amortizes repeated prompt computation without caching mutable response states. It also delays feedback from tentative tokens, reducing premature reinforcement of transient high-confidence errors and giving rollback more opportunity to correct them. Our analysis characterizes prompt reuse as a reversibility-aligned cache boundary, bounds its state-dependent approximation error, and gives a decoder-margin condition for preserving full-refresh decisions. Existing DLM acceleration often trades quality for speed. Archer shifts this frontier, attaining the best mean performance of 33.63% together with a 2.57x mean speedup on the main suite. Across evaluated settings, it improves Pass@1 by up to 3.05 points and reaches up to 2.95x speedup. Controlled analyses connect the quality gain to delayed prompt feedback and validate state-aware refresh. Our code is available at https://github.com/Hxnng/Archer.

## 1. 核心问题与整体含义（研究动机与背景）

- **研究背景**：扩散语言模型（DLMs）通过迭代双向去噪生成文本，与不可逆的自回归生成不同，它天然支持"回滚"（rollback）——即早期预测可在后续上下文出现矛盾时被重新修订。这一能力对结构化生成（如代码生成）尤其有价值，但代价高昂：每次去噪更新都会改变全局上下文，导致 prompt 和 response 两部分的隐藏状态都必须重新计算，即便只有 response 是可修订的。
- **核心矛盾**：传统 KV 缓存技术假设历史状态不可变（如自回归解码中的因果注意力），因此与迁移学习中可修订生成相互冲突。若完全重算，则反复处理不变的 prompt，浪费计算；若缓存全部状态，则可能保留来自已废弃生成的旧激活，造成不一致。
- **研究问题**：如何在保留 DLM 回滚能力（即每个生成 token 都保持可修订）的前提下，引入 KV 缓存以提高推理效率？现有加速方法（如 Fast-dLLM、dKV-Cache、dLLM-Cache）针对的是无 token 级回滚的解码，无法直接迁移；而现有回滚解码器（如 Saber）则在每次回滚时进行全序列前向，计算开销大。
- **核心洞见**：在双向注意力下，prompt 的表示虽然随生成状态变化，但其 token 身份保持固定。因此，提示部分是合适的缓存边界——可以复用 prompt 的 K/V 而不损害生成 token 的可修订性，同时有界复用还能延迟"暂定 token"的反馈，减少对瞬时高置信度错误的过早强化，给回滚更多修正机会。

## 2. 方法论：核心思想、技术细节与算法流程

### 2.1 总体设计
- **Archer**：一种无需训练的 KV 缓存控制器，与任何回滚解码器（如 Saber）兼容。
- 核心原则：**非对称状态复用**——prompt 的 K/V 被缓存复用，response 区域（所有可修订的生成 token）在每个更新步骤前全部重新计算，确保任意生成 token 的可修订性不被破坏。

### 2.2 核心机制
- **缓存边界**：设 p 为 prompt，g_t 为当前 response，C_p(g) 表示在响应 g 下计算得到的 prompt K/V。全量（eager）解码计算  
  z*_t = Φ_θ(g_t; C_p(g_t))，  
  而 Archer 在缓存有效期内计算  
  ẑ_t = Φ_θ(g_t; C_p(g_r))，  
  其中 g_r 为缓存创建时的响应状态。
- **注意力计算**：在每一层，response 的 query 同时与缓存的 prompt K/V 和近期重新计算的 response K/V 进行注意力，即  
  Attn(Q_g^ℓ(g_t), [K_p^ℓ(g_r) ∥ K_g^ℓ(g_t)], [V_p^ℓ(g_r) ∥ V_g^ℓ(g_t)])，  
  保证所有生成 embedding、隐藏状态和 logits 都反映当前 g_t，只有 response→prompt 的反馈路径锚定在 g_r。

### 2.3 状态感知刷新策略
- 定义锚点相对距离 D_t = d_H(g_t, g_r)（即 Hamming 距离，两响应间的 token 差异数）。
- 当 D_t ≥ K（半径阈值）时，执行全量前向（Full Forward）刷新缓存并更新锚点 g_r ← g_t；否则使用缓存路径（Cached Forward）。
- 此策略以"响应状态漂移量"而非"使用次数/年龄"决定刷新时机：少量微小更新可继续复用缓存，而一次大规模回滚可立即触发同步。其效果是交替进行"局部复用"与"全局同步"——即延迟反馈与周期校正的受控过程。

### 2.4 算法流程（Algorithm 1）
1. 初始化：g ← g₀，g_r ← g₀，执行一次全量前向得到初始 logits 和缓存 C_r。
2. 循环直到终止：
   - 调用解码器 D 更新 g ← D(g, z)。
   - 若未终止：计算 d_H(g, g_r)。
   - 若 d_H ≥ K，执行全量前向并刷新锚点；否则执行缓存前向。
3. 返回最终序列 g。

### 2.5 理论保证（关键结论）
- **命题 1（稠密回滚闭包）**：在稠密双向注意力下，任意响应位置的修改会结构性地影响所有位置，因此生成侧状态无法获得通用精确复用保证；Archer 不缓存任何生成状态，从而保留全部回滚动作。
- **效率分析**：缓存步的代价约为全量步的 G/(P+G)；考虑刷新比例 q_K 后，理论加速为 S(K) ≈ [q_K + (1−q_K)·G/(P+G)]⁻¹。
- **近似误差界**：在 Lipschitz 假设下，缓存与全量 logits 的误差满足 ‖z*_t − ẑ_t‖∞ ≤ Γ√D_t < Γ√K，即误差受响应漂移量（而非缓存年龄）控制。
- **决策保真度**：设解码器在状态 ξ 下的决策余量为 m_D(ξ, z)，当 Γ√D_t < m_D 时，Archer 与全量解码选择相同转移；若每一步都满足则该轨迹完全一致。
- **反馈控制视角**：Archer 抑制了 response→prompt→response 的间接反馈路径（∂_C Φ_θ · ∂_g C_p），具有"时间锚定"效应：可降低对暂定错误的即时自强化，但过度延迟也会损害有用上下文传递。

## 6. 主要结论与发现

- **性能与效率兼得**：在主套件上，Archer 达到 33.63% 的平均性能（所有方法中最高），同时获得 2.57× 平均加速；相比 Saber，在各基准上实现 1.36–1.81× 加速，且质量普遍提升（MBPP Base +0.47、MBPP-ET +1.17、LiveCodeBench +2.75、HumanEval-ET +0.60）。
- **跨骨干一致性**：在 LLaDA-8B、Dream-7B、DiffuCoder-7B 三个模型上，加速均达 1.36–1.78×，质量在 5/6 个设置下提升（最高 +3.05 Pass@1），说明 Arcehr 不只是针对单一模型的行为特化。
- **延迟反馈有正面作用**：配对状态干预显示，延迟 prompt 反馈（Cached）比立即反馈（Fresh）在相同回滚机制下多解出 5 个独有问题（23 vs 18），两分支修订率均为 99.53%，证明质量差异来自反馈时序而非回滚被禁用。
- **状态距离优于缓存年龄**：行动分歧随 D_t 单调上升（19.88%→65.09%）；控制年龄后，状态距离的部分相关系数仍为 0.145，而控制状态距离后年龄降至 0.040–0.045，故 D_t 是更好的刷新信号。
- **非代码领域可迁移**：FinQA 加速 2.50× 且准确率提升 0.61 点；PubMedQA 加速 1.48× 且准确率提升 0.10 点；MATH-500 在质量几乎不变（−0.60）下加速 1.27×。
- **回滚没有被削弱**：Archer 的修订位置比例（26.93%–30.24%）与 Saber（27.87%–29.18%）相当，平均更新次数并未缩短，说明加速源自每步成本降低而非减少修正机会。

## 7. 优点

- **思路新颖**：明确提出"缓存边界必须遵循回滚语义"这一设计原则，将 prompt 状态识别为与可修订性兼容的缓存边界，不同于既有 DLM 缓存方法（生成侧缓存）的范式。
- **理论扎实**：给出从依赖结构（稠密回滚闭包）到效率模型、近似误差界、决策保真度的完整证明链，把"缓存 staleness 何时有害/有益"形式化为反馈控制问题，区分了数值保真与决策保真。
- **实验严谨性高**：配对状态干预、无干扰阴影前向、部分 Spearman 相关分析等设计能较好隔离变量，避免将性能差异归因于错误的机制；跨骨干与跨领域实验增强了结论的泛化性。
- **无需训练、即插即用**：Archer 不改变底层 DLM 或回滚采样策略，可叠加在现有系统上，实用性强。
- **开源透明**：代码公开于 GitHub，便于复现。

## 8. 不足与局限

- **实验覆盖有限**：主实验集中在代码生成和 256 token 长度；更长的上下文（如 >2048 response）、多语言、问答、摘要等任务尚未验证。跨领域实验的 FinQA 采用了替代评估指标（提取答案的数值准确率），与官方程序执行评分存在差距。
- **与全量 Saber 相比仍非 Pareto 改进**：在 HumanEval Base 上 Archer 的 Pass@1 比 Saber 低 1.22 点，说明延迟提示反馈并不保证质量单调提升，存在任务依赖性（论文也承认这是"归纳偏置"而非免费保证）。
- **采样随机性空白**：所有实验均使用温度 0 的确定性解码（单次生成），未评估在采样式生成或多样化输出场景下 Archer 的稳健性。
- **理论保证较弱**：Lipschitz 常数在预训练大模型上无法实际计算，近似误差界属于"结构保证"而非"数值界"；决策保真的充分条件也无法在运行时验证。
- **资源信息不透明**：未报告 GPU 硬件、显存占用、能耗等，难以判断实际部署成本。
- **生成侧缓存仍被放弃**：Archer 故意不缓存任何生成状态，虽然保全可修订性，但也放弃了进一步加速的可能。论文承认，若能利用稀疏注意力、有效性证书或不变依赖区域识别机制，生成侧缓存是未来方向。
