## 摘要
全模态大语言模型（Omni-LLMs）联合处理音频、视频和文本，但长多模态序列会带来大量的预填充（prefill）和KV缓存开销。现有的全模态压缩方法主要侧重于LLM之前的令牌缩减，而跨LLM边界的模态特定压缩尚未得到充分探索。我们提出A-PACK，一种两阶段框架，将音频剪枝推迟到查询条件下的多模态交互出现之后。我们的分析表明，与视频相比，音频在每个令牌上表现出更高的任务相关信息密度和表示多样性。我们进一步发现，局部音视频动态为视觉选择提供了比逐令牌匹配更有效的线索。因此，我们在LLM之前保留音频并用局部动态压缩视频，随后在LLM内部逐步剪枝低相关性的音频和视觉令牌及其KV缓存条目。在Qwen2.5-Omni-7B/3B的四个基准上，A-PACK在评估的先前方法中取得了最强的平均性能，同时将预填充FLOPs减少高达78%，并将解码吞吐量提升高达2.21倍。

## Abstract
Omni-modal LLMs jointly process audio, video, and text, but long multimodal sequences incur substantial prefill and KV-cache costs. Existing omni-modal compression methods primarily focus on pre-LLM token reduction, leaving modality-specific compression across the LLM boundary underexplored. We propose A-PACK, a two-stage framework that defers audio pruning until query-conditioned multimodal interactions emerge. Our analysis shows that audio exhibits higher task-relevant information density and representational diversity per token than video. We further find that local audio-visual dynamics provide a more effective cue for visual selection than token-wise matching. We therefore preserve audio and compress video with local dynamics before the LLM, then progressively prune low-relevance audio and visual tokens and their KV-cache entries inside the LLM. Across four benchmarks on Qwen2.5-Omni-7B/3B, A-PACK achieves the strongest average performance among the evaluated prior methods while reducing prefill FLOPs by up to 78% and improving decoding throughput by up to 2.21x.

## 1. 核心问题与整体含义（研究动机与背景）

- **问题背景**：全模态大语言模型（Omni-LLMs）联合处理音频、视频和文本，但长多模态序列会引发显著的 **prefill 计算开销**和 **KV-cache 内存开销**，严重制约推理效率。
- **现有方法的不足**：现有的全模态 token 压缩方法（如 OmniZip、OmniSelect 等）**几乎全部聚焦于 LLM 之前的 token 缩减**（pre-LLM），即在音频、视频与查询文本被联合上下文化之前就做模态选择。此时各模态仍由独立的模态特征表示，相关性估计不完整。
- **早期剪枝的风险**：在 LLM 之前对音频进行剪枝可能丢弃简短但关键的证据（如短暂的喊声、瞬间的音效），这些证据在后续多模态推理中可能至关重要。
- **核心洞见**：token 相关性的判断标准会随着 LLM 边界而改变——在融合之前，音频 token 密度高、信息量大，应保留；而视频流冗余度高，可激进压缩。融合之后，多模态上下文使低相关 token 的评估更可靠，此时再进行音频剪枝更合理。
- **相应启发**：局部音视频动态（local audio-visual dynamics），即短时间窗口内两种模态表征的协同演化，比逐 token 匹配更能反映真实的视听对应关系。
- **论文整体含义**：提出 **A-PACK** 两阶段框架，将"何时压缩各模态"作为核心决策维度，在 LLM 前后采用不同的压缩策略，实现了跨模态边界的高效全模态压缩。

## 2. 方法论：核心思想、关键技术细节与算法流程

### 2.1 总体框架

A-PACK 采用两阶段压缩策略，以 LLM 边界为分界点：

- **阶段一（pre-LLM）**：保留全部音频 token，仅压缩视频 token。利用查询相关性和局部音视频动态分配视觉预算，并移除视频内冗余。
- **阶段二（inner-LLM）**：在解码器中间层开始，利用查询注意力逐步剪枝低相关性的音频和视觉 token，并同步移除对应 KV-cache 条目，实现"延迟音频剪枝"并降低解码开销。

### 2.2 阶段一：pre-LLM 局部对齐压缩（Local Alignment Compression）

- **局部 CKA 作为对齐度量**：使用线性中心核对齐（Centered Kernel Alignment, CKA），在长度为 \(w=3\) 的时间滑窗内比较音频与视觉表征的协方差结构，而非逐个 token 的相似度。
  公式：\( c_f = \text{CKA}(A_f, V_f) = \frac{\|V_f^\top A_f\|_F^2}{\|A_f^\top A_f\|_F \|V_f^\top V_f\|_F} \)
  - CKA 优点：对称、保留结构信息、避免最优传输的 Sinkhorn 开销和强制匹配问题（当视觉 token 数远超音频 token 时）。
- **门控细粒度补充（Gated Fine Pass）**：当剪辑平均 CKA 低于阈值 \(\tau\)（即短窗口无法捕捉时间偏移对应关系，如旁白先于动作出现）时，补充逐帧音视频直接相似度作为回退信号：
  公式：\( s_f = \begin{cases} c_f, & \bar{c} \ge \tau \\ (1-\beta)c_f + \beta(1-\hat{d}_f), & \bar{c} < \tau \end{cases} \)
- **分段与预算分配**：
  - 利用连续帧余弦相似度进行场景切分。
  - 每个场景段的重要性得分考虑峰值和持续相关性：\( g_m = \sqrt{|G_m|}[\lambda \max_{f \in G_m} r_f + (1-\lambda)\frac{1}{|G_m|}\sum_{f \in G_m} r_f] \)，再按比例分配视觉预算 \( B_m = B_v \frac{g_m}{\sum g_{m'}} \)。
- **锚点式 token 选择（Anchor-based Token Selection）**：
  - 每个场景的首帧作为锚点帧，使用 **DA-FPS（Density-Aware Farthest-Point Sampling）** 选取多样且高覆盖的 token。
  - 非锚点帧仅保留与锚点同空间位置相似度最低的 token，去除已有内容冗余，保留新出现的证据。

### 2.3 阶段二：inner-LLM 查询感知压缩（Query-Aware Compression）

- **动机**：pre-LLM 表征尚未包含细粒度的查询条件多模态上下文，因此需要延迟音频剪枝。
- **评分公式**：从中间解码器层开始，用最后一个查询 token 的表示 \(q\) 与缓存 token 的 key \(k_i\) 计算缩放点积注意力得分：
  公式：\( I_i = \frac{\exp(q^\top k_i / \sqrt{d})}{\sum_{j \in S} \exp(q^\top k_j / \sqrt{d})} \)
- **Token 保留**：每层保留得分最高的 \((1-P)\) 比例 token：\( S \leftarrow \text{TopK}_{\lceil(1-P)|S|\rceil}(S; I) \)，逐步压缩序列。
- **KV-cache 同步剪枝**：被移除 token 的 key-value 条目同步删除，减少后续层注意力和解码阶段的计算量。
- **算法流程**（Algorithm 1 摘要）：音频嵌入重采样到帧轴→场景切分→段级与帧级预算分配→锚点/D-FPS token 选择→送入 LLM→从中间层开始逐层剪枝至结束。

## 6. 主要结论与发现

1. **音频逐 token 效用更高**：音频 token 的任务相关信息密度比视频高约 9.8 倍（遮挡 KL 更大），有效秩高约 1.7 倍，说明每 token 的信息量和多样性都更强。
2. **局部音视频动态优于逐点匹配**：在 8 个 WorldSense 领域全部获得提升，配对预测 McNemar 检验 p=0.0117，统计显著。
3. **两阶段压缩达到最佳精度-效率权衡**：LLM 前保留音频 + 局部动态压视频，LLM 内查询注意力渐进剪枝双模态 token，任何单阶段替换都不如完整 A-PACK。
4. **A-PACK 为最高平均精度**：7B 模型在 35% 档保留 98.8% 精度，25% 档保留 97.0%；3B 模型对应为 97.3% 和 95.5%，均优于所有基线。
5. **效率收益显著**：prefill FLOPs 最高减少 78%，解码吞吐最高提升 2.21 倍（51.4 tok/s vs OmniZip 的 31.1 tok/s），AVUT 上 GPU 内存降低 2.3 GB。
6. **音频保留广受益**：在固定总预算下，从 20% 提升到 80% 音频保留率，AVUT 相对精度提高约 10%、WorldSense 提高约 8%，即使视觉主导任务也受益。

## 7. 优点

- **时机感知的压缩设计**：创造性地区分"压缩哪些 token"与"何时压缩各模态"，将音频剪枝推迟到查询条件交互形成之后，这是对现有"仅 pre-LLM 压缩"范式的实质性推进。
- **局部动态度量的合理性**：使用局部窗口 CKA 捕捉模态间的协同演化，而非逐点静态相似度，更符合真实音视频事件的时间本地性；门控回退机制有效地处理了时间偏移场景。
- **跨模态边界的统一框架**：pre-LLM 阶段以音频为引导压缩视频，inner-LLM 阶段联合剪枝音视频并同步移除 KV-cache，在保证精度的同时直接缩短了解码序列，加速了自回归生成，这是仅 pre-LLM 压缩方法无法实现的。
- **训练无关、即插即用**：无需任何微调或额外训练，可直接应用于现成 Qwen2.5-Omni 模型，实用性强。
- **实验严谨性高**：统计显著性检验（Wilcoxon、McNemar）、逐任务/逐领域报告、超参数敏感性分析完备；以 prefill-FLOPs 为基准对齐比较，比名义 token 保留率对比更公平；效率计算解析透明、可复现。
- **消融设计清晰**：阶段消融（Pre only → A-PACK）、阶段替换消融（Random/FastV/DyCoke 替换任一阶段）、参数敏感性分析三者互相印证，各模块贡献明确。

## 8. 不足与局限

- **时间偏移与未对齐的敏感度**：虽然门控机制缓解了该问题，但局部 CKA 本质上对音频-视觉时间偏移敏感。如果跨模态对应存在较大延迟（如长旁白），w=3 窗口仍可能无法捕捉正确对应，性能会受损（窗口从 3 增大到 5/7/9 时 WorldSense 精度下降约 3.5–3.8 点）。
- **细粒度时间定位能力有限**：定性失败案例显示，即使保留了音频和对应视觉上下文，A-PACK 仍无法精确回答需要秒级定位的问题（如"笑声具体发生在 0:05–0:07"），说明粗粒度事件保留与精确时间戳解析是两种不同的能力要求，后者仍需改进。
- **聚合式压缩存在不可逆信息损失**：inner-LLM 渐进剪枝对 mid-level 层之后的 token 直接丢弃，无法恢复。对于需要贯穿全文的长程证据，后续层再聚焦可能受限。
- **音频保留策略具有条件性**：论文显示保留音频在 AVUT（音频中心）和 WorldSense（视觉中心但依赖音频）上均有效，但作者也承认策略可能因模型和任务而异，在纯视觉任务或无音频事件的任务上可能不适用。
- **未涵盖所有全模态推理场景**：虽然选取了 5 个代表性基准，但缺乏对多轮对话、音频生成（TTS）、实时流

式流式推理等场景的评估。长视频（>1小时）的端到端表现和音频-视觉时间偏移极端情形未被系统覆盖。
- **计算开销前置但未完全消除**：pre-LLM 阶段的场景切分、逐帧/逐窗口 CKA 计算、DA-FPS 采样均需在 LLM 之前完成，虽避免了 LLM 计算，但仍引入额外的前处理延迟和 CPU/GPU 开销，论文未详细分解该阶段的时间成本。
- **固定窗口设置缺乏自适应性**：\( w=3 \) 的全局窗口假设所有视频的音频-视觉对齐尺度一致，但实际视频节奏差异巨大（快剪 vs 慢叙事），自适应窗口或分层窗口可能进一步提升稳定性。
- **对查询长度的鲁棒性未验证**：inner-LLM 评分使用最后一个查询 token，当查询是多轮对话（多段指令历史）时，单一 token 可能无法充分代表完整查询语义，该场景未在实验中验证。
- **与微调类方法的兼容性未知**：A-PACK 是 training-free 方法，其与需微调的 token 缩减方法（如感知型压缩）的结合潜力、以及在微调后模型中继续生效的能力，论文未进行讨论。

## 9. 未来研究方向

- **自适应音频压缩时机**：探索基于音频事件密度和语言查询结构的动态判断机制，决定何时（pre-LLM 或 inner-LLM）以及以多大幅度压缩音频 token，从而将两阶段框架推广为更通用的时序感知压缩策略。
- **跨模态长程依赖建模**：在 inner-LLM 剪枝中引入对长程相关性的保护机制（如关键 token 回退、记忆槽或分层摘要），减少不可逆丢弃对长视频推理的影响，并改善需要贯穿全文证据的任务表现。
- **时间定位能力的增强**：将局部 CKA 和锚点选择扩展为时间戳感知的表示，保留事件的时间边界信息，使压缩后的 token 候选集更有利于秒级定位问答。
- **扩展至更多模态与更大模型**：将两阶段压缩框架迁移到更大规模的全模态模型（如 70B 级）以及其他模态组合（如图像+音频+点云、带外部工具调用），验证其通用性和可扩展性。
- **联合训练与压缩的协同**：探索在微调阶段引入"压缩即插拔"模块，使模型在训练时即适应训练后的 token 稀疏性，从而在训练与推理之间建立更紧密的一致性。
- **流式/在线场景适配**：将 A-PACK 的局部对齐和渐进剪枝思想应用于流式全模态推理，在视频不断到达的过程中实时决定保留哪些 token，以支持实时交互和低延时生成。

## 10. 总结

A-PACK 从"何时压缩"这一被长期忽视的视角出发，提出了以 LLM 边界为分界的两阶段全模态 token 压缩框架：LLM 前利用局部音视频动态引导视频压缩、LLM 内利用查询感知注意力渐进剪枝音视频 token。该方法在无需微调的前提下，在多个全模态理解基准上取得优于现有方法的精度-效率权衡，尤其在音频中心任务和细粒度时间推理任务上展现了"延迟剪枝"带来的关键优势。其严谨的统计检验、透明的效率分析和完备的消融实验为结论提供了坚实的支撑。尽管存在对时间偏移敏感、长程证据不可逆丢失等局限，但 A-PACK 为建设"何时压缩"这一新维度上的高效全模态推理研究提供了清晰且可扩展的基线框架。
