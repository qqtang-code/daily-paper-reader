## 摘要
扩散变换器（DiTs）在时空标记上产生二次方自注意力开销。现有的免训练稀疏注意力方法通常从块级或聚类级代理分数构建稀疏掩码，这可能掩盖键之间的细粒度差异，并在激进稀疏下漏掉高贡献键。此外，此类代理分数可能导致过度集中的softmax分布，使得Top-p为某些查询聚类保留过少的键。尽管固定的Top-k最小值缓解了这种失效模式，但共享值无法适应不同头和输入的变化。为解决这两个局限，我们提出SCOPE，一种免训练的稀疏注意力框架，结合3D-RoPE对齐的键子空间聚类与在线逐头Top-k估计，用于高效的视频DiT推理。SCOPE将RoPE后的键划分为时间、高度和宽度子空间，独立聚类，并通过查找表聚合相应的质心分数，为每个查询聚类获得每个键的代理分数。在现有的混合Top-p/固定Top-k选择基础上，SCOPE通过平均每个头内初始保留的键数（按查询聚类大小加权）在线推导出头特定的Top-k值，并仅对初始保留键数低于该值的查询聚类选择额外键。然后对选定的原始键和值计算稀疏注意力。在六个模型-任务配置下，SCOPE在保真度和延迟方面均持续优于现有的免训练基线，在720p HunyuanVideo上实现高达1.99倍的端到端加速，相对于密集注意力PSNR为28.46 dB。

## Abstract
Diffusion Transformers (DiTs) incur quadratic self-attention cost over spatiotemporal tokens. Existing training-free sparse attention methods often construct sparse masks from block-level or cluster-level proxy scores, which can obscure fine-grained differences among keys and miss high contribution keys under aggressive sparsity. Moreover, such proxy scores may yield overly concentrated softmax distributions, causing Top-$p$ to retain too few keys for some query clusters. Although a fixed Top-$k$ minimum alleviates this failure mode, a shared value cannot adapt to variations across heads and inputs. To address both limitations, we propose SCOPE, a training-free sparse attention framework that combines 3D-RoPE-aligned key subspace clustering with online per-head Top-$k$ estimation for efficient video-DiT inference. SCOPE partitions post-RoPE keys into temporal, height, and width subspaces, clusters them independently, and aggregates the corresponding centroid scores through lookup tables to obtain per key proxy scores for each query cluster. Building on existing hybrid Top-$p$/fixed Top-$k$ selection, SCOPE derives a head-specific Top-$k$ value online by averaging the initial retained key counts within each head, weighted by query cluster size, and selects additional keys only for query clusters whose initial retained key counts fall below this value. Sparse attention is then computed over the selected original keys and values. Across six model--task configurations, SCOPE consistently outperforms existing training-free baselines in both fidelity and latency, achieving up to a $1.99\times$ end-to-end speedup on 720p HunyuanVideo with $28.46$ dB PSNR relative to dense attention.

## 1. 核心问题与整体含义

- 视频 Diffusion Transformers（DiTs）将时空潜变量展平为成千上万个 token，自注意力复杂度为 O(N²d)，成为高分辨率、长视频推理的主要瓶颈。
- 现有训练免费的稀疏注意力方法存在两个关键缺陷：
  - 使用块级或聚类级代理分数为多个 key 分配同一重要性，掩盖了 key 间的细粒度差异，在激进稀疏下容易漏掉高贡献 key。
  - 代理分数导致的 softmax 分布可能过度集中，使 Top-p 为部分查询簇保留过少 key；而固定 Top-k 最小值虽然缓解了该问题，却无法适应不同头与不同输入的变化。
- SCOPE 的目标是在不修改预训练模型的前提下，构建更精细、更具自适应性的稀疏注意力掩码，从而在保持对密集注意力保真度的同时显著加速视频 DiT 推理。

## 2. 方法论

### 核心思想
- 利用视频 DiT 中 3D-RoPE 在时间、高度、宽度三个坐标上作用于互不相交通道范围的特点，将 post-RoPE key 划分为三个子空间并独立聚类，形成组合式细粒度代理分数。
- 在混合 Top-p/固定 Top-k 的基础上，根据当前 head 的初始保留计数在线估计一个逐头 Top-k 值，只扩展低于该值的查询簇。

### 关键技术细节
- **查询全维聚类**：对 post-RoPE queries 进行 K-means 聚类，Cq=300，同一查询簇共享同一 key 排序与选择集合。
- **3D-RoPE 对齐的 key 子空间聚类**：将每个 key 按 3D-RoPE 的通道范围拆分为 kᵀ、kᴴ、kᵂ，在每个子空间独立做 K-means（CT=CH=CW=333），得到子空间质心与分配。
- **组合打分**：对每个查询簇质心切片与各子空间质心做点积，形成紧凑查找表 Pᵐ ∈ R^{Cq×Cm}；每个 key 通过查表并求和三个分数得到代理 logit：
  - s̃_{c,j} = (1/√d) Σ_{m∈{T,H,W}} Pᵐ[c, zᵐ_j]
- **混合 Top-p/固定 Top-k**：对每个查询簇先按代理 logit 排序，得到 Top-p 保留数 t_c^{(p)}，再与固定 k_fix = ⌈αN⌉ 取最大值作为初始保留数 b_c。
- **在线逐头 Top-k 估计**：
  - k_head = ⌈ (Σ n_c b_c) / (Σ n_c) ⌉，即按查询簇大小加权的平均保留数。
  - 最终保留数 r_c = max{b_c, k_head}，仅扩展低于该值的簇。
- **稀疏注意力执行**：选择完成后，使用原始 Q、K、V 计算 softmax 注意力；代理分数只用于选择，不参与最终注意力计算。

## 7. 优点

- **免训练、免离线校准**：不需要修改模型参数，也不需要密集注意力 profiling 或存储逐头调度表。
- **子空间分解符合 3D-RoPE 结构**：独立建模时间/高度/宽度子空间，组合码数量随子空间数指数增长，而打分开销仅线性增长，计算效率高。
- **细粒度 key 区分**：避免了全维聚类中同簇 key 共享分数的粗粒度问题，附录实验显示在相同 oracle recall 下 SCOPE 保留的 key 比例明显更低。
- **在线自适应 Top-k**：从当前 head 的统计量实时估计保留下限，能适应不同层、不同去噪步和不同输入。
- **公平对比**：与基线共享完全相同的数据、种子和采样配置，并使用官方实现，仅调稀疏参数，结果可信度高。
