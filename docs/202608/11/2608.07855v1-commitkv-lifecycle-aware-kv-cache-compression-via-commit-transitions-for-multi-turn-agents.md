## 摘要
多轮推理与行动（ReAct）代理会积累不断增长的推理、工具调用和观察轨迹。它们的键值（KV）缓存随之增长，增加了模型推理期间的内存使用和注意力成本。现有的KV缓存压缩方法通过驱逐注意力得分较低的状态来降低这些成本。然而，当前轮次中的低注意力并不意味着未来无关，因为暂时不活跃的信息可能稍后变得重要。因此，基于快照的驱逐方法不能明确区分暂时休眠的信息与似乎已完成其作用的信息。在本文中，我们提出了CommitKV，它通过提交转换来识别KV生命周期。具体来说，CommitKV首先将已完成的代理事件划分为令牌页，并在工具调用提交之前和提交返回的观察结果被整合之后，比较每个符合条件的页面的删除效果。基于这些配对测量，CommitKV将休眠页面与从高到低的完成候选项区分开来。然后，它应用贪婪联合测试，仅当候选者的提交后组合效应保持有界时才接受其退役。最后，在后续的压缩检查点，已接受的页面被排除，等待提交后测量的有界页面集合受到保护，其余KV状态使用相同的键、值和绝对位置的令牌索引保留在缓存预算内。这些机制确保CommitKV能够区分休眠信息与已完成其观察作用且可以安全删除的信息。在各种基准上的实验表明，CommitKV减少了代理内存使用，加速了端到端推理，并比现有的KV缓存压缩方法实现了更高的准确性。

## Abstract
Multi-turn Reasoning-and-Acting (ReAct) agents accumulate growing trajectories of reasoning, tool calls, and observations. Their key-value (KV) caches grow accordingly, increasing memory use and attention cost during model inference. Existing KV cache compression methods reduce these costs by evicting states with low attention scores. However, low attention in the current turn does not imply future irrelevance, as temporarily inactive information may become important later. Snapshot-based eviction methods therefore do not explicitly distinguish temporarily dormant information from information that appears to have completed its role. In this paper, we present CommitKV, which identifies KV lifecycles through commit transitions. Specifically, CommitKV first divides completed agent events into token pages and compares each eligible page's deletion effect before a tool-call commit and after the commit's returned observation has been incorporated. Based on these paired measurements, CommitKV distinguishes dormant pages from high-to-low completion candidates. It then applies a greedy joint test, accepting candidates for retirement only when their combined post-commit effect remains bounded. Finally, at a later compression checkpoint, accepted pages are excluded, a bounded set of pages awaiting post-commit measurement is protected, and the remaining KV states are retained within the cache budget using the same token indices for keys, values, and absolute positions. These mechanisms ensure that CommitKV can distinguish dormant information from information that has completed its observed role and can be safely removed. Experiments on various benchmarks show that CommitKV reduces agent memory use, accelerates end-to-end inference, and achieves higher accuracy than existing KV cache compression methods.

## 2. 方法论

### 核心思想
CommitKV 引入 **提交转换（commit transition）** 的概念：将每次工具调用的结束视为一个提交边界（commit boundary），在同一事件页面（event page）上，分别测量其在工具调用提交之前和返回观察被整合之后两个时间窗口内的"删除效应"，通过前后配对测量来推断该页面的生命周期状态，从而区分"休眠"与"已完成"。

### 关键技术细节

1. **事件与页面划分（Agent Events and Pages）**
   - 每个已完成的工具调用 \(a_i\) 和返回观察 \(o_i\) 称为一个"代理事件"。
   - 每个事件被划分为连续的不重叠"事件页"（event page），页面大小上限为 \(G\)（实验中 \(G=16\) token）。页面是测量影响力和决定是否删除的基本单位。

2. **配对查询窗口（Paired Query Windows）**
   - 对工具调用 \(a_t\)，设其提交点为 \(c\)（工具调用生成结束的位置）。
   - **提交前窗口** \(Q_c^- = \{|y_t|-W+1, \dots, |y_t|\}\)：工具调用末尾最后 \(W\) 个解码查询位置。
   - **提交后窗口** \(Q_c^+ = \{|x_{t+1}|+1, \dots, |x_{t+1}|+W\}\)：下一轮开始、观察被整合之后的头 \(W\) 个解码查询位置。
   - 窗口大小 \(W=8\)。

3. **删除效应（Deletion Effect）**
   - 对某一注意力头，若删除页面 \(E\) 中的 token 并重新归一化剩余注意力权重，则更新后的注意力输出为：
     \[
     o_{p}^{\setminus E} = \frac{o_p - \sum_{i \in E, p_i \le p} a_{p_i} v_i}{1 - \sum_{i \in E, p_i \le p} a_{p_i}}
     \]
   - 针对查询窗口 \(Q\) 的删除效应定义为跨头最大相对输出变化：
     \[
     R(E; Q) = \max_h \max_{p \in Q} \frac{\|o_p - o_p^{\setminus E}\|_2}{\|o_p\|_2}
     \]
   - 提交前效应 \(R_c^-(E) = R(E; Q_c^-)\)，提交后效应 \(R_c^+(E) = R(E; Q_c^+)\)。

4. **状态判定：结合绝对效应与百分位排名**
   - 由于前后窗口的查询 token 不同，数值尺度可能有差异，仅用固定阈值不可靠。因此同时使用绝对删除效应和百分位排名：
     - 高影响力状态：\(R \ge \tau_{use}\) 且 百分位 \(P \ge \rho_{use}\)（实验中 \(\tau_{use}=0.05, \rho_{use}=0.75\)）。
     - 低影响力状态：\(R \le \tau_{dead}\) 且 百分位 \(P \le \rho_{dead}\)（实验中 \(\tau_{dead}=0.01, \rho_{dead}=0.25\)）。
   - 引入中间"不确定"状态，避免在证据不足时强行归类。

5. **生命周期状态分类**
   - **high→low**：提交前高、提交后低 → **完成候选（completion candidate）**，可能已完成角色。
   - **low→low**：前后都低 → **休眠（dormant）**，保留，不按生命周期规则删除。
   - **low→high**：新激活（newly active），保留。
   - **high→high**：仍活跃（still active），保留。
   - **其他**：不确定，不参与退役。

6. **贪婪联合验证（Greedy Joint Validation）**
   - 单个页面删除效应小，多个页面联合删除效应可能积累导致输出剧变。因此对完成候选按提交后效应升序（次排序为提交前效应降序）排列，逐个测试联合删除的效应是否满足：
     \[
     R_c^+(D_c \cup \{E\}) \le \tau_{joint}
     \]
     （实验中 \(\tau_{joint}=0.01\)），满足则加入退役集 \(D_c\)，否则保留。

7. **保护未完成转换的页面（Protecting Incomplete Transitions）**
   - 提交前效应已测得、但提交后效应尚未收集的页面不能提前删除，否则生命周期状态无法确定。
   - 这些"待定页面"（pending pages）的 token 索引集合 \(\mathcal{N}_j\) 需被保护，且数量受限于预留预算：
     \[
     |\mathcal{N}_j| \le B_N = \lfloor \eta B \rfloor
     \]
     其中 \(B\) 是总 token 预算，\(\eta=0.125\) 是保留给待定测量的比例。

8. **固定预算压缩（Fixed-Budget Compression）**
   - 在压缩检查点 \(j\)：排除退役页面 token；保护待定页面 index；在剩余 resident tokens 中按预算 \(B\) 选择保留索引集 \(\mathcal{I}_j\)，要求 \(\mathcal{N}_j \subseteq \mathcal{I}_j\) 且 \(|\mathcal{I}_j| \le B\)。
   - 同一索引集 \(\mathcal{I}_j\) 同时应用于键、值、绝对位置，保证 RoPE 位置信息的一致性。
   - 压缩检查点触发策略与 R-KV/TriAttention 一致：每解码 128 个 token 触发一次压缩。

## 6. 主要结论与发现

1. **准确率优势**：在 4096 token 预算下，CommitKV 在所有压缩方法中平均准确率最高，超越最强基线 19.85%（Qwen3-14B）、5.49%（Qwen3.6-27B）、1.54%（DeepSeek-R1-Distill-Llama-8B）。

**局限的适用范围**：只在 ReAct 式代理框架下验证。若代理采用不同的工具调用协议（例如不产生显式文本形式的工具调用，而是结构化 API 调用或并行工具调用），提交边界的定义方式需要重新设计，方法的通用性尚不明确。

### 其他不足

- **未提供失败案例分析**：论文没有深入分析 CommitKV 在哪些具体问题/样本上出现了明显性能退化，也缺少 on 与 FullKV 相比的误差来源剖析（如误删关键证据、误判休眠等），不利于后续针对性改进。
- **未讨论安全性**：压缩可能丢失与有毒内容、隐私信息相关的 token，论文未讨论缓存压缩在安全对齐方面的潜在影响。
- **缺少与更先进压缩范式的对比**：未与基于训练/基于学习（如自编码器式压缩、低秩压缩）的缓存压缩方法对比，也未与 KV 量化方法结合讨论，方法论上存在一定盲区。

## 9. 可能的改进方向与开放性挑战

1. **自适应阈值与少超参化**：当前 7~8 个超参数依赖人工设定，可通过在轻量校准集上的自动搜索（如基于少量代理轨道的贝叶斯优化）或归一化策略来消除对绝对阈值的依赖，提高可迁移性。
2. **跨事件边界泛化**：将"提交边界"概念推广到更通用的语义单元，例如对话回合切换、文档段落切换、用户意图切换等，使方法不仅能用于工具调用型代理，还能用于纯文本多轮问答和长文档场景。
3. **极小预算下的弹性压缩**：在 1024 甚至更低预算下，探索优先级分层（如休眠页先于活跃页淘汰、待定页保护预算动态调整）以及压缩后剩余内容的语义重构（如摘要 token 注入），进一步逼近 FullKV 性能。
4. **学习驱动的生命周期判定**：用轻量分类器或排序模型替代手工阈值判定"休眠/完成/活跃"，利用代理轨道数据训练一个页面生命周期预测器，使判定更加稳健。
5. **与量化/结构化剪枝结合**：CommitKV 目前保留 token 粒度，若将其与 KV 量化、按头剪枝结合，可以在相同显存预算内保留更多语义信息。
6. **性能建模与延迟剖析**：尽管端到端速度提升明显，但删除效应测量本身的开销、页面扫描上限（64 页）的权衡尚缺详细剖析；可进一步研究测量预算的自适应分配。

## 10. 总体评价

### 一句话概括

> CommitKV 是一篇将**生命周期视角**引入代理场景 KV 缓存压缩的论文，通过"工具调用提交"这一天然的语义边界，实现了对"休眠"与"已完成"两类低注意力页面的显式区分，并在准确率与推理效率上同时取得显著收益。

### 论文的学术贡献定位

- 在思路上，它纠正了快照式压缩"低注意力=可删除"这一隐含假设，提出了"低注意力可能意味着休眠而非无用"这一重要认识。这一洞察不仅对该方法本身有价值，对整个 KV 压缩研究领域都具有启发意义——任何基于注意力分数的压缩方法都可能面临类似的"误删休眠信息"风险。
- 在技术上，它提供了一套完整的度量—判定—筛选—保护—压缩流程，各个模块之间的耦合设计合理，且通过消融验证了每个模块的必要性，方法论扎实。
- 在应用上，该方法直接面向多轮工具调用代理这一当前最受关注的 AI 应用形态，实验覆盖了主流开源模型与真实基准，落地价值明确。

### 值得注意的总体判断

- 该工作的核心价值在于**提供了一种识别与保护"休眠信息"的通用范式**，即使其具体实现（配对窗口、删除效应测量）未来被更高效方案取代，"以语义事件边界来划分缓存生命周期"的思想依然具有持久的方法论意义。
- 论文在 4096 token 这类中等预算下已达到与 FullKV 相当的水平，在 2048 token 小预算下大幅领先同类方法，说明该方向的边际收益在预算紧张时更为明显，这与当前长轨迹代理对显存越来越敏感的实际需求高度契合。
- 主要的开放风险在于：参数的脆弱性、对工具调用边界的依赖，以及缺乏跨任务的自适应能力。后续工作若能针对上述风险做简化与泛化，将使该方法具备更广的适用范围。

## 附：关键术语速查

| 术语 | 含义 |
|------|------|
| Commit Boundary | 工具调用结束（提交）的位置，作为生命周期测量的语义边界 |
| Event Page | 一个代理事件内连续的不重叠 token 块，作为删除/保留的基本单位 |
| Deletion Effect | 模拟删除某页面后注意力输出相对变化的幅度，衡量该页面影响力 |
| Dormant State | 前后窗口均低影响力的页面，可能将来复用，予以保留 |
| Completed State | 提交前高影响力、提交后低影响力的页面，作为退役候选 |
| Pending Pages | 已测得提交前效应、尚未测得提交后效应的页面，需临时保护 |
| Joint Validation | 将多个退役候选合并后重新验证联合删除效应，防止累积误差 |
| Percentile Calibration | 以同窗口内所有页面的百分位排名辅助绝对阈值，规避跨窗口尺度差异 |
