## 摘要
基于Transformer的大语言模型（LLM）在许多任务上表现出色，但其键值（KV）缓存随序列长度线性增长，给长上下文推理带来了严重的内存瓶颈。现有的启发式驱逐方法（如H$_2$O和SnapKV）依赖静态注意力或位置信号，往往无法捕捉标记未来的预测影响力。我们提出DistillCache，一个将KV缓存驱逐建模为序列决策问题的强化学习框架。DistillCache利用丰富的内部模型信号（注意力统计、值范数、熵和位置）学习轻量级策略网络，并通过每步KL散度奖励使用REINFORCE进行训练，以保持完整缓存的输出分布。在7B参数指令微调Transformer（Mistral-7B-Instruct-v0.3）上，DistillCache在25%缓存预算下保留了LongBench上94.2%的完整缓存准确率，在长上下文任务上比强启发式基线（H$_2$O、SnapKV）高出最多2.7个绝对百分点，并且在我们重新实现的并发基于RL的方法（ForesightKV、RLKV）上高出最多1.4个百分点。在推理基准上，DistillCache与最佳并发方法相当，并在激进压缩下超越它。它还提供了高达2.1倍的完整缓存吞吐量，同时保持有竞争力的实际效率。这些结果突显了所学到的、分布感知策略对内存高效长上下文LLM推理的有效性。

## Abstract
Transformer-based large language models (LLMs) achieve strong performance across many tasks, but their Key-Value (KV) cache grows linearly with sequence length, creating a severe memory bottleneck for long-context inference. Existing heuristic eviction methods (e.g., H$_2$O and SnapKV) rely on static attention or positional signals that often fail to capture a token's future predictive influence. We propose DistillCache, a reinforcement learning framework that formulates KV-cache eviction as a sequential decision problem. DistillCache learns a lightweight policy network using rich internal model signals (attention statistics, value norms, entropy, and position) and trains it with REINFORCE via a per-step KL-divergence reward to preserve the full-cache output distribution. On a 7B-parameter instruction-tuned Transformer (Mistral-7B-Instruct-v0.3), DistillCache retains 94.2% of full-cache accuracy on LongBench at a 25% cache budget, outperforming both strong heuristic baselines (H$_2$O, SnapKV) by up to 2.7 absolute points and, under our re-implementations, concurrent RL-based methods (ForesightKV, RLKV) by up to 1.4 points on long-context tasks. On reasoning benchmarks, DistillCache is competitive with the best concurrent method and surpasses it under aggressive compression. It also delivers up to 2.1x full-cache throughput while maintaining competitive practical efficiency. These results highlight the effectiveness of learned, distribution-aware policies for memory-efficient long-context LLM inference.

- **核心瓶颈**：Transformer 大语言模型在自回归解码时依赖 KV 缓存来避免重复计算，但 KV 缓存大小随序列长度**线性增长**，在长上下文场景下成为严重的内存与吞吐瓶颈。
- **现有方法不足**：已有启发式驱逐方法（如 H₂O、SnapKV）依赖**静态的注意力统计或位置信号**来判定 token 重要性，但此类启发式信号未必能捕捉 token 对**未来预测的实际影响力**，尤其在长程依赖或结构化推理任务中表现不佳。
- **整体研究含义**：论文提出将 KV 缓存驱逐视为一个**序列决策问题**，利用强化学习训练一个轻量策略网络，直接以“保留全缓存输出分布”为目标，从而突破静态启发式方法的局限，实现内存受限条件下更优的生成质量与内存开销权衡。

## 2. 方法论

### 2.1 核心思想
- 以**逐步骤 KL 散度奖励**引导策略：每一步选择保留哪些缓存 token，使得剪枝后模型的下一 token 预测分布尽量接近全缓存模型。
- 采用 **REINFORCE** 策略梯度方法训练，以显式内存预算为约束，直接优化**长期缓存效用**，而非依赖监督式的重要性代理标签。

### 2.2 关键技术细节

**状态空间**：为每个缓存 token 构建五维特征向量：
- **αᵢ**：最近一次前向传递中该 token 在所有头/层上的平均注意力质量；
- **‖vᵢ‖₂**：值向量的 L2 范数；
- **σᵢ**：注意力质量跨头的方差；
- **Hᵢ**：近期查询侧注意力熵的注意力加权平均值（衡量被集中查询还是弥散注意选中）；
- **posᵢ**：归一化序列位置。

**动作空间**：策略网络（轻量 MLP，约 20 万参数）为每个 token 打分；训练时通过 Gumbel 扰动从 Plackett–Luce 分布中采样 Top-B 子集；推理时确定性选取 Top-B。

**训练架构**：维护两个缓存——
- **教师缓存**：从不剪枝，提供完整缓存分布 P_t；
- **学生缓存**：每步按策略剪枝，提供剪枝后分布 P̂_t。
- 奖励定义为 **R_t = −D_KL(P_t ‖ P̂_t)**。

**理论支撑**：论文给出从 evicted attention mass ε_t 到 KL 散度的上界推导：软max的局部Lipschitz连续性确保每步KL散度被 evicted attention mass 的平方所约束，为KL奖励提供了原则性基础。

**优化细节**：
- REINFORCE + 熵正则化（β=0.01）+ 折扣回报（γ=0.99）；
- 使用 RLOO（leave-one-out）基线降低方差；
- 对数分区函数用动态规划精确计算，O(L·B) 复杂度。

**推理流程**：教师分支移除，仅一次前向传播，策略评分后剪枝，生成当前 token 不受影响（剪枝服务于下一步解码）。

- 在 **25% 缓存预算**下，DistillCache 在 LongBench 保留 **94.2%** 的全缓存精度（绝对精度 39.1 vs 全缓存 41.5），优于 H₂O 和 SnapKV 最高 **2.7 个绝对百分点**，优于并发 RL 方法（ForesightKV、RLKV）**0.9–1.4 个点**。

## 7. 优点（方法/实验亮点）

- **目标函数设计精密**：以逐 KL 散度作为奖励，直接对齐“保持分布”这一本质目标，且天然侧重低熵（高脆弱性）token——无需显式熵过滤器即可自动惩罚易受驱逐影响的预测。
- **理论推导支撑**：从 evicted attention mass 到 KL 散度上界的推导为奖励函数提供了严谨的理论动机。

- **无硬编码保护**：策略自动学习保留注意力汇（attention sink）和近期 token，将 H₂O/StreamingLLM 的专家规则作为特例复现。
- **训练可扩展性好**：教师/学生双缓存设计保证因果一致性；精确对数分区函数的 DP 算法避免了蒙特卡洛近似方差。
- **零样本迁移能力**：跨架构迁移实验证明策略捕获了一定的通用缓存重要性模式。
- **报告规范**：多种子均值±标准差、完整超参数披露、消融层次清晰。

## 8. 不足与局限

- **训练成本高**：约 130 GPU 小时 + 双倍训练内存，显著高于零训练启发式方法；REINFORCE 方差问题仍需熵正则与多种子平均来缓解。
