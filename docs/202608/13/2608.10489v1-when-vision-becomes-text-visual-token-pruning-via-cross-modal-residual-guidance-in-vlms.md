## 摘要
丰富的视觉信息增强了视觉语言模型（VLM）的感知能力，但海量的视觉令牌也导致推理成本上升。现有的视觉令牌剪枝方法依赖于基于相似性的引导，利用文本-视觉及视觉-视觉令牌之间的成对相关性进行压缩。然而，这些方法仅捕捉局部的逐层信号，忽略了VLM的完整推理过程。本文重新审视VLM推理，提出一种全新的高效引导方案，对基于相似性的引导进行补充。具体而言，我们识别出一个关键现象：随着LLM层数的加深，文本令牌通过自注意力持续聚合视觉信息，逐步将部分视觉内容吸收进文本表示中。为量化这一现象，我们从几何表示的角度提出跨模态吸收（Cross Modal Absorption, CMA）指标，用于衡量文本吸收了多少视觉信息，结果显示在更深的层中，更多视觉令牌可近似由文本子空间解释。据此，我们提出跨模态残差（Cross Modal Residual, CMR）方法：通过吉洪诺夫正则化最小二乘将视觉令牌投影到文本子空间，并利用重建残差量化文本无法解释的视觉信息。最后，基于CMR，我们提出SIEVE，一种免训练的视觉令牌压缩方法，结合CMR、文本注意力相关性和残差空间多样性，以保留任务相关且互补的令牌。在多种VLM架构上的实验验证了SIEVE的有效性。例如，在LLaVA-NeXT-7B上，SIEVE仅保留11.1%的视觉令牌，同时保留了原始平均性能的97.5%，实现了3.62倍的预填充加速、2.49倍的端到端加速，以及6.02倍的KV缓存缩减。

## Abstract
Abundant visual information strengthens vision-language model (VLM) perception, yet massive visual tokens raise inference costs. Existing visual token pruning methods rely on similarity-based guidance, which exploits pairwise text-vision and vision-vision token correlations for compression. However, such methods only capture local layer-level signals and overlook the whole inference process in VLM. In this paper, we revisit VLM inference and present a new efficient guidance scheme that complements similarity-based guidance. In particular, we identify a key observation: as LLM layers deepen, text tokens continuously aggregate visual information via self-attention and progressively absorb partial visual content into textual representations. To quantify this phenomenon, we propose Cross Modal Absorption (CMA) from a geometric representation perspective to measure how much visual information is absorbed by text, revealing that more visual tokens in deeper layers can be approximately explained by the text subspace. We accordingly propose Cross Modal Residual (CMR). It projects visual tokens onto the text subspace via Tikhonov regularized least squares and exploits reconstruction residuals to quantify visual information that cannot be explained by text. Finally, based on CMR, we present SIEVE, a training-free visual token compression method that combines CMR, text-attention relevance, and residual-space diversity to retain task-relevant and complementary tokens. Experiments on diverse VLM architectures verify the effectiveness of SIEVE. For instance, on LLaVA-NeXT-7B, SIEVE keeps only $11.1\%$ of visual tokens while preserving $97.5\%$ of the original average performance, achieving $3.62\times$ prefill speedup, $2.49\times$ end-to-end speedup, and a $6.02\times$ KV-cache reduction.

- **研究背景与动机**：视觉语言模型（VLM）将图像编码为大量视觉令牌，与文本令牌一起送入 LLM 进行联合推理。视觉令牌数量庞大，导致自注意力计算、KV 缓存和推理时延显著上升。在高分辨率图像、多图输入和视频理解场景中，这一问题尤为严峻，因此需要高效的视觉令牌压缩方法。
- **现有方法的不足**：主流压缩方法依赖两类信号——注意力分数（衡量文本对视觉令牌的局部相关性）和特征相似性（衡量视觉令牌之间的冗余）。但这些信号仅刻画单一层的局部状态，缺少对整个多模态推理过程的全局视角，难以捕捉跨层动态变化中的真实令牌重要性。
- **本文的核心发现**：随着 LLM 层数加深，文本令牌通过自注意力持续聚合视觉信息，视觉令牌表示逐渐被"吸收"进文本子空间，即深层中有更多视觉令牌可被文本表示近似解释。这一现象意味着传统的"视觉信息始终独立"的假设不成立，压缩应聚焦于文本无法解释的残余信息。
- **整体含义**：文章提出一种新的剪枝指导范式——跨模态残差引导，从几何表示角度量化视觉信息被文本吸收的程度，并据此设计免训练的压缩方法 SIEVE，在极低令牌保留率下维持模型性能，实现显著的推理加速和 KV 缓存缩减。

## 2. 方法论

### 2.1 核心思想：跨模态吸收（CMA）

- 从几何视角定义**跨模态吸收（Cross Modal Absorption, CMA）**，衡量某一层中整体视觉令牌表示能被文本子空间解释的比例：

\[
\text{CMA} = 1 - \frac{\|V_c - \hat{V}_c\|_F^2}{\|V_c\|_F^2}
\]

- 实验显示，CMA 随 LLM 层数加深而单调上升（在 TextVQA 上从第 1 层的 0.017 增至第 32 层的 0.396，Spearman 相关系数 ρ = +0.99），证实视觉令牌被文本子空间逐步吸收。

### 2.2 令牌级指标：跨模态残差（CMR）

- CMA 是层级的，而压缩需要逐令牌决策。文章将视角细化到令牌级，提出**跨模态残差（Cross Modal Residual, CMR）**。
- 计算流程：
  1. 以文本表示的均值作中心化参照，消除跨模态共享的背景成分；
  2. 对每个视觉令牌，用吉洪诺夫（Tikhonov）正则化最小二乘，将其重建为文本令牌的线性组合；
  3. 正则化系数 λ 由文本格拉姆矩阵的特征值分布自适应确定（按能量比例阈值 η）;
  4. 得到闭式解和重建结果，CMR 定义为重建残差与原表示范数之比：

\[
\text{CMR}_i = \frac{\|v_{c,i} - \hat{v}_{c,i}\|_2}{\|v_{c,i}\|_2}
\]

- CMR 值越大，说明该视觉令牌携带越多文本无法解释的独特视觉信息，越应保留；CMR 值越低，则说明其信息已被文本吸收，冗余度高，可优先剪除。

### 2.3 注意力信号

- CMR 仅刻画几何独特性，不保证与当前文本查询相关。因此引入文本到视觉的注意力信号：

\[
a_i = \sum_{h \in H_{\text{top}}} \sum_{t \in T} \alpha_{h t, i}
\]

- 仅保留对视觉区域注意力总质量最高的前 ρ_h 比例头，减少噪声头的干扰。
- 兼容 FlashAttention：采用双前向流策略，通过辅助值矩阵标记视觉令牌位置，无需显式实例化完整注意力矩阵即可获取所需注意力统计量。

### 2.4 融合分数与残差空间多样性选择

- 综合分数为注意力和 CMR 的**乘法融合**：

\[
\text{Score}_i = a_i^2 \cdot \text{CMR}_i^2
\]

- 选择阶段采用**残差空间多样性贪心选择**：
  1. 在残差空间（原始表示减去文本子空间重建）中计算令牌间余弦相似度平方，作为冗余度量；
  2. 每步选择当前分数最高的令牌，然后按相似度对剩余候选令牌的分数进行折扣抑制（式 14），迭代至达到预算 K。

- 残差空间与原始空间相比，已去除文本可解释的共享成分，其方向更直接反映各令牌独特的视觉信息，能更精准识别互补令牌。
