## 摘要
检索增强生成（RAG）在多次查询中重复预填充相同文本块，导致冗余计算。位置无关缓存（PIC）通过跨位置重用预计算的键值（KV）来缓解这一问题，但其效率受大量文本标记的制约。将文本块渲染为图像可将文本压缩为更少的视觉标记，但渲染图像的PIC比文本PIC面临更严重的质量下降。这种表示特异性差距主要源于独立编译的缓存之间的上下文不匹配，以及视觉压缩过程中细粒度文本证据的丢失。现有的PIC修复方法主要通过选择性重计算来解决前者，但会引入在线计算，且无法恢复丢失的文本细节。我们提出QV-PIC，一种由模型原生模板引导的查询感知双分辨率PIC重用框架。离线阶段，QV-PIC在模型原生聊天模板前缀下编译视觉缓存，无需在线重计算即可提升PIC质量。在线阶段，它通过低分辨率保留全局上下文，并在高分辨率预算内通过累积查询相关性分数恢复细粒度文本证据，同时保持视觉压缩的效率优势。在六项任务中，QV-PIC相较于原始渲染图像PIC将平均F1分数提高了21.6个百分点，缩小了与原始文本PIC的差距，并比优化后的文本PIC高出2.58 F1，同时将TTFT降低了17.2%。相对于完整预填充，其TTFT降低了83.8%。

## Abstract
Retrieval-Augmented Generation (RAG) repeatedly prefills identical text chunks across queries, incurring redundant computations. Position-Independent Caching (PIC) mitigates it by reusing precomputed Key-Value (KV) across positions, but its efficiency is constrained by the large volume of text tokens. Rendering text chunks as images can compress the text into fewer visual tokens, but the rendered-image PIC suffers more severe quality degradation than the text PIC. This representation-specific gap primarily arises from contextual mismatches across independently compiled caches and the loss of fine-grained textual evidence during visual compression. Existing PIC repair methods mainly address the former through selective recomputation, but they incur online computation and cannot recover lost textual details. We propose QV-PIC, a query-aware dual-resolution PIC reuse framework guided by model-native templates. Offline, QV-PIC compiles visual caches under the model's native chat-template prefix, improving PIC quality without online recomputation. Online, it preserves global context with low resolution and restores fine-grained textual evidence within a high-resolution budget by cumulative query relevance scores, retaining the efficiency benefit of visual compression. Across six tasks, QV-PIC improves average F1 by 21.6 points over vanilla rendered-image PIC, closes the gap to vanilla text PIC, and surpasses optimized text PIC by 2.58 F1 while reducing TTFT by 17.2\%. Relative to full prefill, it cuts TTFT by 83.8%.

# QV-PIC 论文详细中文总结

## 1. 核心问题与研究动机

- **背景**：检索增强生成（RAG）需要为多个查询重复预填充相同的文档块，造成大量冗余计算。尽管位置无关缓存（PIC）可以通过跨位置复用预计算的键值（KV）缓存来消除重复 prefill，但其效率受限于**文本 token 的庞大体量**——KV 的传输与计算仍随上下文长度增长。
- **新机遇与瓶颈**：将文本块渲染为图像、用视觉 token 承载文本信息，可在不显著损失全 prefill 质量的前提下实现 3–4 倍 token 压缩（如 Glyph 模型）。但论文发现：**渲染图像 PIC 的质量下降比文本 PIC 更严重**——在六项 LongBench QA 任务上，72 DPI 图像 PIC 较全 prefill 平均 F1 下降约 12.2 个点，而文本 PIC 仅下降数个点。
- **两个核心失败原因**：
  1. **编译上下文不匹配**：独立编译的缓存缺少全 prefill 时的上下文条件（如聊天模板前缀），组合后缓存状态错位；
  2. **细粒度证据丢失**：视觉编码将字符、数字、标点和布局压缩为聚合视觉 token，答案相关的细粒度文本证据可能在缓存构建前就被模糊、混淆或丢弃。
- **现有方法之不足**：已有的 PIC 修复（如 EPIC、CacheBlend 等）依赖选择性在线重计算，既增加在线延迟，又无法恢复视觉编码时已丢失的文本细节。

## 2. 方法论：QV-PIC 框架

### 核心思想
通过**离线模板条件编译** + **在线查询感知双分辨率分配**，让渲染图像 PIC 既能保持视觉压缩的效率，又能接近甚至超越文本 PIC 的重用质量。组合两大互补组件，分别对治两大失败模式。

### 2.1 整体工作流（两阶段）

- **Phase I（离线）**：为每个可复用文档块渲染**低分辨率（72 DPI）和高分辨率（120 DPI）** 两个版本，各自在**模型原生聊天模板前缀**下独立编译 KV 缓存，存储时剥离前缀 KV，但保留模板条件下的图像 KV；同时存储 token 数元数据、来源顺序元数据和源文本嵌入（BGE-M3）。
- **Phase II（在线）**：用 BGE-M3 对查询编码，与各块的源文本嵌入做余弦相似度排序；将不超过预算 B 个最相关的渲染图像提升为高分辨率；随后按当前请求上下文顺序组装激活的缓存，执行 M-RoPE 位置再锚定，仅在线计算查询 prefill 与答案生成。

### 2.2 关键技术细节

- **模型原生模板条件编译**：
  \[
  C_{r_i} = \mathrm{Strip}_h \left( \mathrm{KV}_M([h; x_{r_i}]) \right)
  \]
  使用模型自带聊天模板前缀 h 作为编译条件，编译后仅剥离 h 的 KV 条目，保留被该条件“影响过”的图像 KV。在线时只需附加一份共享前缀缓存 \(\mathrm{KV}_M(h)\)。相比任意 dummy prefix（对长度和 token 身份敏感），模型原生模板与训练时输入接口对齐，修复系统性上下文不匹配且不需要在线重计算。

- **M-RoPE 再锚定**：
  \[
  K_{r_\ell,i} = R_\ell\left( \bar{K}_{r_\ell,i}, P_i(q) \right)
  \]
  独立编译时 key 在旋转前存储；服务时按当前上下文顺序派生的位置重新施加 M-RoPE 旋转，实现跨位置复用。Value 与位置无关，直接拼接。

- **查询感知双分辨率分配**：
  - 嵌入与相关性打分：
    \[
    e_i = \frac{E(c_i)}{\|E(c_i)\|_2}, \quad e_q = \frac{E(q)}{\|E(q)\|_2}, \quad s_i = \max(e_q^\top e_i, 0)
    \]
  - 选择最小的 top-k 集合，使**归一化累积正相关性**达到阈值 α（实验中 α=0.65），且受硬上限 B（实验中 B=4）约束：
    \[
    k^\star = \min\left( B, \min\{ k : \frac{\sum_{j=1}^k s_{\pi_j}}{\sum_{i=1}^n s_i} \ge \alpha \} \right)
    \]
  - 全正相关性为 0 时取最高分块作确定性回退。
  - 激活前缀长度：
    \[
    N(q) = \sum_{i=1}^n n_{L_i} + \sum_{i \in S(q)} (n_{H_i} - n_{L_i}), \quad |S(q)| \le B
    \]
  - 在线路由开销仅为 \(T_{\text{route}} = T_E(q) + O(nd) + O(n\log n)\)，渲染、视觉编码、KV 编译全部离线完成。

### 2.3 与既有方法的关键区别

- 用**模板条件**替代选择性重计算，将修复成本从在线转移到离线；
- 用**查询感知的分辨率分配**替代均匀分辨率，在保持全上下文低分辨率覆盖的同时，将高分辨率预算只分配给查询相关的图像；
- 不做 token 选择或重计算，在线路径无额外推理。

## 6. 主要结论与发现

- **模板条件优于任意前缀和在线重计算**：120 DPI 下模板条件将图像 PIC 从 32.9 提升至 52.1 F1，将原 12.0 点的劣势转为 0.4 点优势；dummy prefix 从 k=2 增至 k=16 时 F1 不断下降，说明与模型原生输入接口对齐才有效，而非任何前缀。
- **均匀 DPI 缩放收益不稳定**：提高 DPI 可提升部分任务 F1，但非单调；TTFT 却随 token 数一致增长——为选择性高分辨率分配提供了动机。
- **QV-PIC 全面超越**：相比原始图像 PIC，平均 F1 提升 21.6 点；比优化后的文本 PIC 高 2.58 F1 且 TTFT 降低 17.2%；比全 prefill 在线预填充时间降低 83.8%。
- **组件协同性**：模板条件单独带来 +16.1 F1（32.7→48.8），双分辨率分配单独几乎无增益（32.5），二者组合达到 54.3——模板条件先建立可靠 KV 基础，分辨率分配才有效。
- **跨模型泛化成立**：在 GLM-4.1V 上 QV-PIC 达到最高 F1 且 TTFT 更低；在 LLaVA-OneVision-2 上接近最佳 F1 同时 TTFT 显著更低。

## 7. 方法优点

- **对照精准**：用长度匹配的 dummy-prefix-4 排除“任意前缀都有用”的混淆，证明模型原生模板的不可替代性；
- **效率与效果双优**：模板条件修复完全离线，双分辨率分配让高分辨率开销只用于被查询激活的子集，在实践中同时改善 F1 与 TTFT；
- **问题拆解清晰**：将退化机理分解为编译上下文不匹配与细粒度证据丢失，分别用两个正交组件应对，消融实验验证了互补性；
- **泛化验证严谨**：选择同源系、跨系两类 VLM，排除了结果仅依赖 Glyph 渲染文本专属调优的可能；
- **系统建模完整**：对在线路由时间、激活前缀长度有显式公式，可部署性论证扎实。

## 8. 不足与局限

- **基准范围有限**：只在 LongBench 的 6 个 QA 任务上评测，未覆盖摘要、Few-shot 学习、代码或中文任务；
- **模型规模有限**：所有实验均在 8–9B 参数范围内，更大 VLM 上的行为未知；
- **指标单一**：仅 F1 与 TTFT，缺少端到端延迟分解、GPU 显存占用、离线缓存构建与存储成本的分析；
- **依赖外部编码器**：查询-块相关性完全依赖 BGE-M3，未评估与 VLM 自身注意力相关性的一致性，路由误差可能被放大；
- **NarrativeQA 的不完整 DPI 扫描**削弱了整体趋势的完整性；
- **α 与 B 超参数未做敏感性分析**：α=0.65、B=4 是否稳健未报告；
- **未讨论视觉渲染的通用失败模式**：例如超长表格、复杂排版、手写文本等情况下的表现；其适用边界有待进一步明确。
