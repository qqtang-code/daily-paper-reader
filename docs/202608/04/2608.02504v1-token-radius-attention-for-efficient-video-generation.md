## 摘要
视频扩散变换器（VDiTs）能够实现高保真生成，但密集的3D自注意力带来了二次方成本。现有的基于头级和块级的稀疏方法在查询之间共享计算预算，忽视了令牌特定的注意力需求。我们观察到，保留密度在不同查询间存在差异，但与注意力熵呈对数线性相关，而主导交互形成了以查询为中心的邻域，其半径随令牌而变化。基于这些发现，我们提出了令牌半径注意力（TRA），一种无需训练的框架，将查询熵映射到解析令牌预算，并将其转换为时间衰减的半径，无需显式键排序。融合熵提取、预热重用和块稀疏掩码构建进一步降低了开销。在七个Wan2.1、Wan2.2和HunyuanVideo T2V/I2V配置中，TRA仅保留9%至19%的注意力交互，实现了1.56倍至2.05倍的加速，并保持了有竞争力的生成质量。代码可在https://github.com/IF-LAB-PKU/Token-Radius-Attention获取。

## Abstract
Video Diffusion Transformers (VDiTs) enable high-fidelity generation but incur quadratic cost from dense 3D self-attention. Existing head- and block-level sparse methods share computation budgets across queries, overlooking token-specific attention demand. We observe that retained density varies across queries yet correlates log-linearly with attention entropy, while dominant interactions form query-centered neighborhoods with token-dependent radii. Based on these findings, we propose Token Radius Attention (TRA), a training-free framework that maps query entropy to an analytic token budget and converts it into a temporally decayed radius without explicit key ranking. Fused entropy extraction, warm-up reuse, and block-sparse mask construction further reduce overhead. Across seven Wan2.1, Wan2.2, and HunyuanVideo T2V/I2V configurations, TRA retains only 9-19% of attention interactions and achieves 1.56x-2.05x speedup with competitive generation quality. Code is available at https://github.com/IF-LAB-PKU/Token-Radius-Attention.

# Token Radius Attention (TRA) 论文总结

## 1. 核心问题与整体含义（研究动机与背景）

- **背景**：视频扩散 Transformer（VDiT）已成为高保真视频生成的主导架构，但其密集三维自注意力需要对所有 token 计算 O(N²) 的交互，成本随视频时长和分辨率快速增长，成为推理与部署的主要瓶颈。
- **现有方法不足**：已有的无训练稀疏注意力方法主要分为两类：
  - **头级方法**（如 SVG、Radial Attention、Sparse-vDiT）：为整个注意力头分配固定空间/时间模式；
  - **块级方法**（如 SVG2、SpargeAttn、SVOO）：选择重要的 query–key 块。
- **关键洞察**：两类方法都隐含假设同一头或同一块内的查询具有相似注意力需求，但自注意力是逐 query 独立进行 softmax 归一化的，不同查询所需保留的 token 数量天然不同——集中型查询只需少量 token，弥散型查询则需要大量 token。共享预算会浪费集中型查询的计算，同时丢失弥散型查询的关键信息，损害生成质量。
- **论文目标**：提出一种查询级（token-level）的自适应稀疏注意力方法，在不训练的前提下，既满足逐查询的计算需求，又能保持规则的执行结构以匹配硬件加速。

## 2. 方法论（核心思想、关键技术、公式与流程）

**核心思想：熵 → 预算 → 半径（Entropy-to-Budget-to-Radius）**

TRA 是一个无需训练的框架，通过提取查询级注意力熵来分配每个查询的 token 预算，再将该预算转化为以查询为中心、随时间衰减的空间半径掩码，最终通过定制 CUDA 内核高效执行。

### 2.1 两个关键实证洞察

- **洞察 I：查询特定的注意力稀疏性**
  - 定义：对查询 i，保留密度 `Bτ_i = Kτ_i / N`，其中 `Kτ_i` 是达到目标注意力质量 τ 所需的最少 top-k 键数。
  - 发现：同一层、同一头内不同查询的保留密度可相差数量级；且 `log Bτ_i` 与注意力熵 `H_i` 近似线性相关，R² = 0.940–0.966（Wan）及 0.978–0.993（HunyuanVideo）。
  - 因此，注意力熵可作为分配查询级预算的紧凑信号。

- **洞察 II：令牌半径注意力模式**
  - 高注意力键在空间上形成以查询为中心的近似圆形邻域，且圆半径随查询、头、层变化。
  - 归一化注意力概率随二维空间距离 ds 近似指数衰减（R²≈0.79–0.994），说明用一个半径参数即可单调控制支持的扩展/收缩。

### 2.2 技术流程与公式

1. **熵到预算（Entropy-to-Budget Mapping）**
   - 查询 i 的注意力熵：`H_i = -Σ_j p_ij log p_ij`。
   - 采用“熵等效均匀支持”近似：假设存在 m_i 个等概率有效键，则由 `H_i = log m_i` 得 `m_i = exp(H_i)`。
   - 估计达到目标质量 τ 所需键数：`bKτ_i = ⌈τ exp(H_i)⌉`，相应的预算密度 `bBτ_i ≈ τ exp(H_i)/N`。
   - 该映射是解析、单调的，无需逐查询对键排序。

2. **预算到半径（Budget-to-Radius Mask Construction）**
   - 空间和时间距离：`d_s(i,j) = sqrt((x_i-x_j)² + (y_i-y_j)²)`，`d_t(i,j) = |f_i - f_j|`。
   - 时间衰减规则：`φ(δ)=exp(-γδ)`，查询 i 在帧 t 的半径 `r_i,t = r_i φ(|t-f_i|)`。
   - 连续近似初始化：令 `C_cont_i(r) = Σ_t π r² φ²(|t-f_i|) = bKτ_i`，得到初始 `r_i`。
   - 边界感知修正：精确计算格点计数 `C_grid_i(r)`，选择满足 `C_grid_i(r) ≥ bKτ_i` 的最小候选半径。
   - 最终掩码：`M_ij = I[d_s(i,j) ≤ r_i φ(|f_j-f_i|)]`，注意文本键保持全可见。
   - 数学定义：`TRA(Q,K,V) = Softmax(QKᵀ/√d + B(M))V`，其中 `B(M)` 为 −∞/0 掩码。

3. **高效实现（Efficient Radius Masking and Entropy）**
   - **Flash Radius Mask Kernel**：将每个 H×W 帧分块（tile），按 tile-major 重排 token；在 CUDA 核中融合距离计算、半径比较、块剪枝与 token 投票，把不规则 token 掩码转换为规则块掩码，交给 FlashInfer 的块稀疏注意力执行。
   - **Fused Attention Entropy Kernel**：利用恒等式 `H_i = log Z_i - Σ_j p_ij s_ij`，在 online softmax 过程中在线累积熵，无需显式物化完整注意力矩阵。
   - **跨步重用**：仅在前 25% 去噪步（预热阶段）计算熵并生成预算/半径/掩码，后续稀疏步直接复用；经验证查询级熵跨步余弦相似度≥0.945。

## 8. 局限与不足

- **仅验证了推理加速**：作为 training-free 方法，TRA 不改变模型参数，因此无法在训练阶段节省成本；若需要与蒸馏、量化等方法联合优化，仍需额外适配。
- **对极端低预算场景的适应性未充分探讨**：论文主要展示保留 9%–19% 交互的结果，未系统测试更激进的稀疏化（如 <5%）下的质量衰减边界。
- **超参数需要根据模型调整**：时间衰减系数 γ、预热步数、稠密层位置等均需人工设定，论文仅提供启发式（如 γ=0.6 vs 0.95），缺乏自动自适应机制。
- **依赖熵作为唯一预算信号**：虽然熵-密度线性关系拟合良好，但存在少量离群查询（如背景平坦区域的低熵查询），可能影响极端情况下的质量。
- **掩码结构仍受限于圆形/时间衰减假设**：真实注意力可能呈现更复杂的形状（如条状、多峰分布），TRA 的单一圆形邻域假设可能不是最优覆盖。
- **缺少与训练型稀疏方法的对比**：未考虑如 learnable sparsity、token pruning 等训练型方案，无法判断在同等预算下 TRA 与它们的质量差距。

## 9. 总结与启示

TRA 的核心贡献在于将稀疏注意力的决策粒度从“头级/块级”推进到“查询级”，并通过熵这一几乎零成本的信号直接预测每个查询所需的 token 预算，再借助规则化的时空半径掩码保证了硬件效率。实验证明，在保持甚至逼近稠密注意力质量的前提下，TRA 能在现有 VDiT 模型上取得近 2× 的端到端加速，且无需任何训练。

这一工作对高效视频生成的启示主要有三点：其一，自注意力的稀疏化应尊重逐查询的 softmax 归一化本质，固定模式的方法存在天然上限；其二，注意力统计量（熵）可以作为一种“元特征”被廉价提取并用于动态预算分配，类似的思路可推广到其他 transformer 推理优化场景；其三，规则化的稀疏模式（如半径掩码）在保持表达能力的同时，能够与主流块稀疏推理库高效衔接，是实用化的重要前提。
