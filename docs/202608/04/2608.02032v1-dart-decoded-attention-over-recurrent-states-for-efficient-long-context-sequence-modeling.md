## 摘要
现代语言模型主要基于Transformer、循环模型及其混合架构构建。Transformer依赖token级注意力记忆，而循环模型如状态空间模型（SSM）和线性注意力保持紧凑的循环状态。这些架构通常独立实例化或在层级交错，留下一个问题：共享的记忆表示能否同时支持循环压缩和注意力式检索。我们通过Mamba-2的状态空间对偶（SSD）视角研究这个问题，其中SSM状态可以被解释为压缩的关联键值（KV）缓存。我们观察到Mamba-2从该状态解码token条件值但不解码token条件键。基于这一观察，我们提出DART（对循环状态的解码注意力），它保留Mamba-2分块扫描产生的块状态贡献作为块状态记忆，从这些记忆解码token条件键和值，并对生成的KV对执行状态记忆注意力（SMA）。然后通过门控残差连接将检索到的输出与原生Mamba-2输出结合。DART通过复用Mamba-2分块扫描并将SMA实现为FlashAttention风格的计算来支持实际训练。我们的分析和实验表明，与匹配的注意力基线相比，DART显著减少了长度相关的推理缓存（例如，当块大小S=256且状态大小N=128时节省75%）。与Mamba-2相比，DART在保持一般语言建模质量的同时显著改善了关联召回和检索。

## Abstract
Modern language models are built primarily from Transformers, recurrent models, and their hybrid architectures. Transformers rely on token-level attention memories, while recurrent models such as state space models (SSMs) and linear attention maintain compact recurrent states. These architectures are typically instantiated separately or interleaved at the layer level, leaving open whether a shared memory representation can support both recurrent compression and attention-style retrieval. We study this question through the state space duality (SSD) view of Mamba-2, where the SSM state can be interpreted as a compressed associative key--value (KV) cache. We observe that Mamba-2 decodes token-conditioned values from this state but does not decode token-conditioned keys. Based on this observation, we propose DART (Decoded Attention over Recurrent sTates), which retains the chunk state contributions produced by the Mamba-2 chunked scan as chunk state memories, decodes token-conditioned keys and values from these memories, and performs state-memory attention (SMA) over the resulting KV pairs. The retrieved output is then combined with the native Mamba-2 output through a gated residual connection. DART supports practical training by reusing the Mamba-2 chunked scan and implementing SMA as a FlashAttention-style computation. Our analysis and experiments show that DART substantially reduces the length-dependent inference cache compared with a matched attention baseline (e.g., $75\%$ savings when the chunk size is $S=256$ and the state size is $N=128$). Compared with Mamba-2, DART substantially improves associative recall and retrieval while preserving general language-modeling quality.

## 1. 核心问题与研究动机

- **背景**：现代语言模型主要分为三类架构——Transformer（依赖token级注意力与线性增长的KV缓存）、纯循环模型（如SSM/线性注意力，维护紧凑循环状态但存在记忆瓶颈）、以及二者混合的架构（通常以层为单位交错堆叠）。
- **核心问题**：能否用**同一个共享记忆表示**同时支持循环压缩（recurrent compression）与注意力式检索（attention-style retrieval）？现有混合架构大多将token级注意力记忆与紧凑循环状态作为两种独立的记忆形式，通过分层交错简单组合，并未深究二者在表示层面的统一可能性。
- **关键观察**：借助Mamba-2的状态空间对偶（SSD）视角，SSM状态可被视为压缩的KV缓存。作者发现Mamba-2在解码时只从该缓存中**读取值（value）**，却**不解码键（key）**——这留下了利用压缩状态进行注意力式检索的空白。
- **研究意义**：若能从压缩的循环状态中同时解码出键和值，则注意力无需遍历所有token级KV条目，而只需检索由循环扫描产生的小量压缩记忆，从而在保持压缩优势的同时获得注意力式检索能力，为长上下文高效建模开辟新路径。

## 2. 方法论：DART架构

### 2.1 核心思想
- **SSD视角下的统一**：将Mamba-2的分块状态贡献（chunk state contribution）∆H[c]保留为“块状态记忆”（chunk state memory），同时支持**从左侧读取值**（Cₜ∆H[c]）和**从右侧解码键**（∆H[c]Eₜ），实现同一记忆表示上的双向解码。
- **状态记忆注意力（SMA）**：对历史块状态记忆执行attention，即查询Qₜ作用于解码出的键Kₜ,꜀，获得块级logit后进行softmax归一化，再对值Vₜ,꜀加权求和得到检索输出Rₜ。

### 2.2 关键技术细节
- **三元向量构造**：由块输入Uₜ投影出三个向量——查询Qₜ（用于块路由）、Mamba-2原生读向量Cₜ（共享给SMA做值侧读取，经验上独立读向量无法学到有效召回）、值侧验证器Eₜ（将状态记忆转为token条件化键）。
- **门控残差融合**：SMA读出力Rₜ通过逐token标量门控Gₜ = SiLU(UₜW_G)（零初始化）作为残差修正加入SSM分支输出，保证训练初期的稳定性。
- **训练效率**：复用Mamba-2的chunked scan算法产生块状态记忆；SMA以FlashAttention风格实现——查询tile（块）流式遍历历史块，在片上（on-chip）构建K/V，在线softmax更新统计量，仅将输出与logsumexp写回HBM，反向传播时通过重计算恢复中间张量。
- **归一化技巧**：对Qₜ、Eₜ做RMSNorm，并以块状态沿P轴的逆RMS稳定评分分支，避免物化归一化副本。

### 2.3 关键公式（文字说明）
- **块状态贡献**：每个块的贡献由块内token的BᵀX经衰减累积而成，维度为N×P（键轴N × 值轴P）。
- **键值解码**：值侧读出为Cₜ与状态记忆左乘（得1×P向量），键侧读出为状态记忆与Eₜ右乘（得N×1向量）。
- **SMA输出**：块logit = QₜKₜ,꜀/√N，softmax归一化后加权求和得Rₜ；最终输出Yₜ = CₜHₜ + GₜRₜ。
- **计算复杂度**：训练时SMA计算量为O(L²NP/S)，相对token级注意力的比率为N/S（N<S时更优）。
- **推理缓存**：每块仅存一个状态记忆，缓存大小为O(LNP/S)，与匹配注意力基线（O(2LP)）的比值为N/(2S)——S=256、N=128时仅占25%，即节省75%缓存。

## 6. 主要结论与发现

1. **DART显著提升关联回忆**：MQAR上，DART在状态规模N=16时就接近或超过Mamba-2在N=64时的准确率，N=64时几乎完美；而Mamba-2在状态或宽度较小时严重退化。
2. **推理缓存大幅缩减**：以S=256、N=128为例，相比匹配的token级注意力KV缓存节省75%的长度相关缓存；前向时间也比FlashAttention-2在测试设置中低约37.5%。
3. **语言建模质量保持甚至小幅提升**：Pile困惑度与Mamba-2相当，Pile准确率与零样本平均分均有所提高，参数仅增加不到3%。
4. **检索能力显著增强**：SWDE/FDA等抽取型任务提升幅度最大（如130M规模SWDE从17.1%提升至34.9%），NIAH多个设置中Mamba-2近乎失败而DART恢复大量目标。

6. **SMA分支是增益来源**：去除SMA残差读出力后性能大幅下降，说明压缩记忆的显式可寻址性是关键。

- **概念创新**：首次在统一记忆表示上同时实现循环压缩与注意力式检索，突破了“交错混合”的既有范式，回答了共享记忆表示可行性的基本问题。
- **理论优雅**：从SSD对偶视角自然推导出“值侧读出已存在、键侧读出缺失”的空白，补全了对称性。
