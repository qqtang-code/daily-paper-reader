## 摘要
在长上下文大语言模型推理中，键值（KV）缓存已成为主要的内存和带宽瓶颈，使得超低位量化变得越来越重要。然而，现有的基于旋转的INT2方法在完整的注意力读出之前优化缓存统计或代理误差，尽管模型最终受到通过注意力和输出投影 $W_O$ 传播的误差的影响。为了解决这一不匹配问题，我们提出了 OptR，一种输出感知的旋转方法，它最小化 $W_O$ 之后的注意力输出误差。OptR 将 $W_O$ 之后的注意力输出误差分解为键引发和值引发的项，并通过完整的 INT2 量化和注意力路径学习每头的正交校正。OptR 进一步应用注意力等价的键重参数化来减少大的通道偏移，而不改变 softmax 分布。在三个模型和五个推理与编码基准上，OptR 一致地改进了 QuaRot 和 OSCAR，并增强了长上下文检索，同时保留了分页 KV 缓存格式，且推理开销可忽略不计。

## Abstract
The key-value (KV) cache has become a major memory and bandwidth bottleneck in long-context large language model inference, making ultra-low-bit quantization increasingly important. However, existing rotation-based INT2 methods optimize cache statistics or proxy errors before the complete attention readout, even though the model is ultimately affected by the error propagated through attention and the output projection $W_O$. To address this mismatch, we propose \textit{OptR}, an output-aware rotation method that minimizes post-$W_O$ attention-output error. OptR decomposes the post-$W_O$ attention-output error into key- and value-induced terms and learns per-head orthogonal corrections through the full INT2 quantization and attention path. OptR further applies an attention-equivalent key reparameterization to reduce large channel-wise offsets without changing the softmax distribution. Across three models and five reasoning and coding benchmarks, OptR consistently improves both QuaRot and OSCAR and strengthens long-context retrieval, while preserving the paged KV-cache format with negligible inference overhead.

# 论文总结

## 一、核心问题与研究动机

- 长上下文大语言模型推理中，KV 缓存是主要的内存与带宽瓶颈。上下文越长、批量越大、模型越深，KV 缓存存储与访存开销越严重。
- INT2 量化将 KV 缓存每个元素压缩到 2 bit（约为 BF16 的 1/8、INT4 的 1/2），能显著扩展可支持的上下文长度或批量大小，因此具有重要价值。
- 传统旋转式量化方法（如 QuaRot、RotateKV、OSCAR）会在完整注意力读出之前，基于缓存统计量或代理误差（如重建误差）来选择旋转矩阵。
- 但模型实际受影响的是 KV 量化误差经过注意力加权、投影矩阵 $W_O$ 之后的输出误差；这个误差会进入残差流并向后传播。因此，代理目标与真实输出误差之间存在“不匹配”问题，可能选到次优旋转。
- 本文针对这一目标不匹配，提出 **OptR（Output-Aware Rotation）**，在输出空间中对旋转矩阵进行优化，从而更直接地保护后续层所观察到的注意力输出。

## 二、方法论

- **核心思想**：对任意已有的旋转式 INT2 KV 缓存方法（如 QuaRot、OSCAR），OptR 附加一组“输出感知”的正交校正旋转，最小化 $W_O$ 后的注意力输出误差，并保持旋转的线性结构、缓存布局和部署兼容性。

- **误差分解**：
  - 将量化后的有效 KV 经过注意力与 $W_O$ 后产生的总输出误差分解为两项：
    - 键引发误差 $\delta y_{K}$：由键量化改变注意力分布（softmax）进而导致注意力输出变化；
    - 值引发误差 $\delta y_{V}$：由值量化经注意力加权聚合后产生的输出变化。
  - 这一分解说明原始重建误差只是代理；真正该优化的是输出空间误差 $E_{out}$。

- **键重参数化（attention-equivalent key reparameterization）**：
  - 对每个 KV 头，先估计通道级键均值 $\mu$，在旋转和量化前对所有键做 $k_s - \mu$。
  - 由于同一均值被所有键共享，对某个 query 的所有 logits 都加上相同常数，不改变 softmax 分布，因此这一变换是“注意力等价”的。
  - 只对键做，不对值做（移动值会改变注意力输出）。
  - 好处是缩小 INT2 量化的动态范围，减小离群值带来的量化误差。

- **正交旋转细化（Orthogonal Rotation Refinement）**：
  - 对每个 KV 头，学习非约束矩阵 $A$，构造斜对称生成器 $S = A - A^\top$，通过矩阵指数 $R = R_0 \exp(S)$ 得到正交校正。
  - 这样校正矩阵始终是正交的，不需要投影回 Stiefel 流形。
  - 可适用于任意基础旋转 $R_0$（Hadamard、OSCAR 频谱协方差旋转等）。

- **键旋转校准**：
  - 在值保持 BF16 的情况下，优化键旋转。
  - 目标函数 $L_K$ 包含两项：KL 散度（保持注意力分布接近 BF16）+ 键引发的 $W_O$ 后输出误差（带权重 $\lambda_K$，默认 1.0）。

- **值旋转校准**：
  - 固定已学好的键旋转及其引入的注意力分布，优化值旋转。
  - 目标函数 $L_V$ 仅衡量值量化经注意力加权和 $W_O$ 投影后的输出误差。

- **INT2 感知训练**：
  - 整个校准过程端到端经过“旋转 → 裁剪 → 分组 INT2 量化 → 反量化 → 逆旋转”的完整路径。
  - INT2 取整不可导，使用直通估计器（STE）计算梯度。
  - 只优化旋转生成参数，模型权重全部冻结。

- **推理阶段实现**：
  - 旋转后的量化键直接存入 INT2 缓存；查询端旋转到 KV 头对应的坐标系（GQA 场景每个查询头用其KV头的旋转）。
  - 值旋转及其逆操作被折叠进值投影和 $W_O$ 中，不额外增加 kernel。
  - 键重参数化的均值预乘旋转后离线计算，在线只需一次减法。
  - 保持分页 KV 缓存（paged KV-cache）和前缀缓存兼容性。

## 六、主要结论与发现

- 现有旋转式 INT2 方法只优化缓存重建或注意力读出前的代理误差，导致输出空间误差较大；OptR 直接优化 $W_O$ 后注意力输出误差，能显著改善量化精度。
- 在 Qwen3-8B 的 AIME25 上，QuaRot 由 17.33% 提升到 66.67%，OSCAR 由 54.67% 提升到 66.00%，接近 BF16 的 68.00%。
- 在三个模型和全部五个推理/编程基准上，OptR 一致提升 QuaRot 和 OSCAR，不仅不依赖特定旋转初始化，且长期上下文检索（RULER-NIAH）在 64K/128K 下提升尤为显著。
- OptR 同时降低逐层的 post-WO 输出误差和传播到后续层的残差流误差，且误差改善分布在大多数层和 KV 头。
- 推理阶段只需一次性离线校准（分钟级），运行时保持分页 KV 缓存兼容，延迟/吞吐/显存开销可忽略（<2%）。

## 七、优点

- **目标设计合理**：首次将 INT2 KV 量化优化目标推进到输出空间，直接匹配模型实际受到的误差影响，解决了“重建误差=最优旋转”的错误假设。
- **误差分解清晰**：将输出误差分解为键引发和值引发项，并分别设计校准目标（键含 KL 项，值只含输出误差项），便于分层优化。
- **技术完整**：键重参数化不改变注意力分布、正交校正可微分、STE 处理不可导量化、旋转参数少、模型权重冻结，工程化程度高。
- **通用性和兼容性**：不依赖特定旋转初始化，可直接叠加到 QuaRot 和 OSCAR；保留分页 KV 缓存、前缀缓存、融合解码内核，实际部署友好。
- **实验规范**：多模型、多任务、多长度，带 5 种子统计，消融齐全，效率分析细致，结论可信度高。

## 八、不足与局限

- **模型规模覆盖有限**：只验证到 14B，未在 30B/70B 等更大模型上测试，规模外推能力未知。
- **任务覆盖偏窄**：评估集中于数学推理、代码生成和 NIAH 检索，尚未覆盖通用语言理解、对话、RAG 等更广泛的场景。
- **校准数据依赖**：使用 GPQA-Diamond 轨迹进行校准，但该数据集同时出现在评测列表中；虽然 token 级不重叠，仍存在评估偏差风险。
- **TurboQuant 对比不充分**：只给了单次运行结果，且是无混合精度版本，未与其完整版本比较，削弱了作为强基线对比的力度。
- **超参数敏感性**：$\lambda_K$ 的最优值依赖基础旋转（OSCAR 用 1.0 最好，QuaRot 用 10 最好），实验中为统一取 1.0，说明对基线有轻微依赖，需额外调参或自适应策略。
- **仅关注 INT2**：没有验证该方法在 INT3/INT4 等位宽下是否同样有效；超低位宽场景下优势明显，但不足以说明更宽位宽下的必要性。
- **长上下文上限受限**：部分模型只测到 32K；128K 只覆盖 Qwen3-8B 且仍有明显精度掉落（69.58→41），说明超长上下文仍存在挑战。
