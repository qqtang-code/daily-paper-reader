## 摘要
近期的高分辨率多模态大语言模型（MLLMs）每个输入生成数千个视觉标记，导致视觉标记爆炸，带来严重的延迟瓶颈。虽然标记剪枝缓解了这一问题，但最先进的子集优化方法通常依赖迭代子集构建，以联合捕捉视觉多样性和指令相关性。随着视觉标记数量的增加，这种顺序依赖性引入了显著的选择开销，严重限制了理论FLOPs减少向实际墙钟加速的转化。为解决这一局限，我们提出了单向剪枝器（SFPruner），一种视觉标记剪枝的结构化重构方法，将冗余控制直接嵌入评分空间，绕开了迭代组合优化的需求。我们的非迭代框架通过两种互补机制在单次前向传播中实现冗余感知的重要性选择。首先，为在协方差层面衰减冗余，我们引入了一种语义引导的脊杠杆机制。通过整合指令相关性和视觉显著性，该机制抑制主导协方差方向并缓解表示偏差。其次，基于排序的方向性掩码通过非对称相似性竞争解决残余重叠，其中得分较高的标记通过并行张量操作显式抑制冗余的低分备选标记。大量评估表明，我们的方法保持稳定的选择成本，在Qwen2.5-VL中512个标记时，将标记选择过程从112.4毫秒减少至仅2.5毫秒，最多减少110毫秒。这种结构效率成功地将理论上的标记减少转化为实际推理加速，同时在高压缩下与最先进技术相比保持极具竞争力的性能。

## Abstract
Recent high-resolution Multimodal Large Language Models (MLLMs) generate thousands of visual tokens per input, leading to a visual token explosion that introduces severe latency bottlenecks. While token pruning mitigates this issue, state-of-the-art subset-optimization methods typically rely on iterative subset construction to jointly capture visual diversity and instruction relevance. As visual token counts scale, this sequential dependency introduces significant selection overhead, severely limiting the translation of theoretical FLOPs reductions into actual wall-clock speedups. To address this limitation, we propose Single-Forward Pruner (SFPruner), a structural reformulation of visual token pruning that embeds redundancy control directly into the scoring space, bypassing the need for iterative combinatorial optimization. Our non-iterative framework achieves redundancy-aware importance selection in a single forward pass through two complementary mechanisms. First, to attenuate redundancy at the covariance level, we introduce a semantics-guided ridge leverage scheme. By integrating instruction relevance and visual saliency, this mechanism suppresses dominant covariance directions and mitigates representation bias. Second, ranking-based directional masking resolves residual overlap through asymmetric similarity competition, where higher-scoring tokens explicitly suppress redundant lower-scoring alternatives via parallel tensor operations. Extensive evaluations demonstrate that our approach maintains stable selection costs, reducing the token selection process by up to 110 ms, from 112.4 ms to just 2.5 ms at 512 tokens in Qwen2.5-VL. This structural efficiency successfully translates theoretical token reductions into tangible inference speedups while preserving highly competitive performance against state-of-the-art techniques under aggressive compression.

### 1. 核心问题与整体意义

高分辨率多模态大语言模型（MLLMs）在处理视觉输入时，会为每张图像生成数千个视觉 token（如 Qwen2.5-VL 在高分辨率下可产生上万 token），导致自注意力计算量随序列长度平方增长，形成严重的显存和延迟瓶颈，极大限制了实际部署的可行性。**视觉 token 剪枝**因此成为缓解该瓶颈的关键技术——其目标是在昂贵的注意力运算前，剔除冗余 token 而保留信息量最大的子集。

然而，当前方法存在一个根本性矛盾：
- **启发式方法**（如基于注意力或相似度的 Top-K 筛选）速度快，但缺乏对 token 间结构性冗余的建模，在激进压缩下性能严重下降；
- **子集优化方法**（如基于 DPP、多样性最大化、MWIS 的方法）能够显式建模重要性与多样性，但其依赖**迭代式顺序贪心搜索**，选择延迟随 token 数量增长而急剧上升，使得理论上的 FLOPs 减少无法转化为实际推理加速。

当 token 数量达到数千甚至上万时，**选择开销本身成为新的系统瓶颈**——例如在 Qwen2.5-VL 上选择 512 个 token，CDPruner 需要 112.4 ms，这一开销甚至可能抵消剪枝带来的注意力计算节省。本文的核心贡献即在于回答：**能否在不使用迭代组合优化的情况下，实现冗余感知的高质量 token 选择？** 作者给出了肯定的答案，提出了 SFPruner（Single-Forward Pruner），将冗余控制直接嵌入评分空间，以一次前向传播完成选择。

### 2. 方法论（SFPruner）

**核心思想**：消除迭代子集构建的依赖，把冗余建模分解为**协方差层面的全局冗余衰减**和**成对层面的局部重叠抑制**两个可并行计算的结构化步骤，使整条选择流程仅由矩阵运算和 Top-K 操作组成。

#### 2.1 语义引导（Semantic Guidance）

建立 token 的基础重要性分数，融合两类信号：
- **文本相关性**：视觉 token 与指令文本嵌入的余弦相似度，经温度缩放归一化获得，记为 `S_rel`
- **视觉显著性**：视觉编码器自注意力中全局 token（CLS）对各视觉 token 的注意力权重，记为 `S_attn`

两者通过线性融合得到 `S_guide = α · S_rel + (1-α) · S_attn`，并做 Min-Max 归一化。对于缺乏文本编码器的模型（如 Qwen2.5-VL），仅使用视觉显著性。

#### 2.2 协方差级冗余衰减：语义引导的岭杠杆分数（SG-RLS）

借鉴随机数值线性代数（RandNLA）中的岭杠杆分数（Ridge Leverage Score, RLS）思想：
- 计算视觉 token 特征协方差矩阵 `C = VᵀV ∈ R^(D×D)`（注意：D 为特征维度，而非 N 个 token）；
- 计算每个 token 的杠杆分数 `ℓᵢ = vᵢ(C + λI)⁻¹vᵢᵀ`；
- 岭正则化项 `λI` 抑制协方差矩阵中占主导的特征方向，使与高能量子空间对齐的 token 获得较低分数，而结构独特的 token 获得较高分数；
- 最终得分为 `S_SG-RLS = ℓᵢ · S_guide,i`，形成 "软 AND 门"，要求 token 同时具备**结构独特性**与**语义相关性**。

工程上利用 Woodbury 矩阵恒等式在 Gram 矩阵与特征协方差之间建立对偶等价，从而可灵活选择在 N 和 D 中较小维度上进行矩阵求逆，避免了高分辨率下 N×N 求逆的 O(N³) 开销，最终计算复杂度为 O(ND²)，并通过 Cholesky 分解保证数值稳定性。

#### 2.3 基于排序的方向性掩码（Ranking-Based Directional Masking）

解决 SG-RLS 未能覆盖的成对局部重叠：
- 构造掩码矩阵 `M_ij = I(S_SG-RLS,j > S_SG-RLS,i)`，**只允许高得分 token 抑制低得分 token**（非对称竞争）；
- 计算抑制惩罚 `Pᵢ = 1 - maxⱼ(M_ij · C_sim,ij)`，其中 `C_sim = VVᵀ` 为 token 间余弦相似度矩阵；
- 最终得分 `S_final,i = S_SG-RLS,i · Pᵢ`，再经一次 Top-K 操作得到保留子集。

整条流程全部由矩阵乘法、逐元素比较和行归约组成，完全避免了迭代循环。

### 6. 主要结论与发现

1. **冗余感知剪枝不必然需要迭代子集构建**：通过将冗余控制嵌入评分空间，SFPruner 在保持选择质量的同时彻底消除了迭代依赖，实现了稳定的选择开销。

2. **效率提升显著**：
   - Qwen2.5-VL 上 512 token 选择：112.4 ms → 2.5 ms（约 **45 倍加速**）；
   - 选择延迟几乎不随保留 token 数量的变化而改变（呈现**保留不变性**）；
   - 在 N=16,384 token 的极端情况下仅需 50.0 ms，而 DivPrune 需 2.6 s、CDPruner 需 1.5 s。

3. **性能保持竞争力**：在 40% 保留率下达 99.0% 相对性能；在 LLaVA-NeXT 的 640-token 保留设定下实现 100.0%；甚至在 5.5% 的极端压缩下仍保持 96.4%，超过多数启发式方法。

4. **SG-RLS 与方向性掩码具备互补性**：前者处理全局协方差冗余，后者消除局部重叠，两者结合在消融实验中取得最优平衡（98.3% Rel., 2.3 ms）。

5. **极限分辨率下可实现真实的端到端加速**：在 N=9,216 时，总推理时间从 6,101 s 降至 3,601 s，说明当剪枝开销受控时，FLOPs 减少可以实际转化为加速。

### 7. 优点

1. **问题洞察精准**：指出子集优化方法在高分辨率场景下的"选择开销悖论"——为节省计算而付出的选择成本反而主导了总延迟，切中实际部署痛点。

2. **方法论创新性强**：将岭杠杆分数（RLS）从算法理论引入视觉 token 剪枝，将冗余建模从"迭代状态更新"重构为"一次全局矩阵运算"，实现了理论到实践的跃迁。

3. **工程实现精巧**：
   - 利用 Woodbury 对偶实现 N×N 与 D×D 求逆的动态选择，规避了高维矩阵求逆的计算瓶颈；
   - 方向性掩码通过并行张量操作完成非对称抑制，设计简洁而有效。

4. **泛化性好**：在三种截然不同的架构（多块切片、单序列密集、多帧视频）上均验证了方法的有效性，且无需针对特定模型调参或训练。

5. **实验严谨度高**：微架构级剖析揭示了现有方法延迟增高的根源，使效率论证有据可依；消融实验设计系统全面。
