## 摘要
长期运行的智能体越来越倾向于重用其键值缓存作为记忆：服务系统保留一部分缓存条目，丢弃其余部分。因此，驱逐和情景记忆方案基于一个很少被直接检验的前提：即使产生观察结果的源事件消失了，保留的事件仍然包含信息。我们通过从提供的上下文中省略一个早期观察来测试这一前提，保持智能体其他历史记录相同。在那些对该观察敏感的项目中，答案绝大多数情况下遵循被省略的值，尽管没有任何提供的跨度指明哪个值是正确的。我们将此称为语义物化：下游事件的缓存行充当了输入已消失的计算的独立可服务视图。这种物化也可以是有意为之的。一个精心措辞、不含答案的事件，在Qwen3-8B上将符合源事件的恢复率从6%提高到51%，即使从未提及该值；而被动地从长期对话中收集自然提及则没有发现任何优势。这样的缓存行所携带的信息是具体且有界的。紧凑的状态得以存活，较大的载荷则退化到偶然水平，而一个构造是否能够写入完全取决于措辞而非单纯的含义，因此模型理解得同样好的两种措辞可能产生截然不同的结果。这为稀疏事件-键值对服务提供了内存契约：写什么、写在哪里、以及源事件消失后什么会存活。对于任何进行驱逐的人来说，推论是：丢弃一个源事件而未观察到准确率下降，并不能证明该源事件是不必要的。

## Abstract
Long-horizon agents increasingly reuse their KV cache as memory: a serving system keeps a subset of cached entries and drops the rest. Eviction and episodic-memory schemes therefore rest on a premise rarely tested directly, that a retained event is still informative once the observations that produced it are gone. We test it by omitting one earlier observation from what is served, across otherwise identical agent histories. Among items sensitive to that observation, the answer overwhelmingly follows the omitted value, though no served span says which value is correct. We call this semantic materialization: a downstream event's cached rows act as an independently servable view of computation whose inputs are gone. It can also be written on purpose. A deliberately phrased, answer-free event raises donor-aligned recovery from 6% to 51% on Qwen3-8B without ever naming the value, whereas passively harvesting natural mentions from long-term dialog yields no detected advantage. What such a row carries is specific and bounded. Compact state survives, larger payloads decay toward chance, and whether a construction writes at all turns on phrasing rather than on meaning alone, so two phrasings the model comprehends equally well can diverge sharply. The result is a memory contract for sparse event-KV serving: what to write, where it lands, and what survives once the source is gone. For anyone who evicts the corollary is that dropping a source event and observing no accuracy loss does not show the source was unnecessary.

## 2. 方法论：核心思想、关键技术细节

- **核心思想**：采用“供体对”（donor pair）设计——构建两个字节完全相同的智能体历史，仅在源事件中翻转一个隐藏值（如 ONLINE/OFFLINE），然后从服务集中移除该源事件，只服务下游根事件（root event）。若模型回答与隐藏的源值一致，则证明 KV 缓存行携带了源状态。
- **术语定义**：
  - **语义物化**：下游事件 KV 行中包含了源自上游计算的状态，而无需在文本中显式重复。
  - **触发器（trigger）**：写时刻的构造（如“M mirrors S”）决定了事件是否能物化状态。
  - **着陆点（landing）**：状态物化在下游哪条缓存行中（根事件 vs 引用边事件）。
  - **访问（access）**：通过查询从缓存行中提取状态的能力，受载荷大小和查询形式影响。
- **关键技术细节**：

  - 服务时只选择一部分缓存行（∑），丢弃源事件，查询接在最后。
  - 使用贪婪解码（greedy decoding）和候选 logit 探测（forced-choice logit probes）。
  - 实验控制：供体对中所有被服务的 token 和位置完全相同，仅源事件的值不同。

## 6. 主要结论与发现

1. **语义物化存在**：在供体敏感项中，模型答案 99:0 遵循被省略的源值（Qwen3-8B），尽管被服务的文本从未提及该值。超过一半的供体对表现出依赖关系。
2. **可编程性**：通过刻意构造的无答案载体事件，可以将供体对齐恢复率从 6%（被动提及）提升至 51%（NL 计算指令），显式文本达到 100%。自然对话中被动收集无优势。
3. **写触发取决于表面形式**：相同含义但不同措辞的构造在写透率上相差数十个百分点，没有通用构造在所有模型上都有效。
4. **着陆点结构化**：根事件携带主要信号，引用边事件大多只是路由到根事件；服务集的变化（添加其他行）会显著影响读出口。
5. **访问限制在紧凑状态**：二元状态恢复率高（93.4%），4路/8路近偶然（22%/16%），三位数数值无法恢复。衍生结论需要通过写时提示（compute note）才能提升。
6. **驱逐的含义**：丢弃源事件后无准确率下降，不能证明源事件不重要——因为下游事件可能已携带答案。
7. **更新**：可通过追加补丁（patch）实现状态修正，比重算便宜，但需注意对历史查询的影响。

## 7. 优点

- **方法创新**：提出了“语义物化”这一新现象，并通过供体对设计实现了因果识别，区分了文本内容与隐藏状态。
- **控制严谨**：服务集字节相同、位置相同，排除了解码波动；使用多种控制（回声控制、隔离编码）。
- **系统全面**：覆盖了“写-着陆-访问”整个契约，并在合成数据和真实对话上验证。
- **实用价值**：为稀疏 KV 服务提供了设计原则（编程原语），提醒驱逐策略设计者谨慎解释无精度损失现象。
- **可复现**：开源实验脚本、配置和模型版本。

## 8. 不足与局限

- **载荷范围有限**：仅对紧凑状态（二元）有效，复杂信息（数值、长文本）无法恢复，限制了实际应用场景。
- **写触发器依赖表面形式**：无通用构造，不同模型需单独校准，增加了工程部署难度。
- **自然对话无效果**：被动收集自然提及不产生优势，说明该原语需要人为设计事件，不能自动从普通对话中挖掘。
- **模型兼容性限制**：在 Gemma-4 的滑动窗口层上，紧凑服务与原生服务存在差异，需要特殊处理（原生位置服务）。
- **真实对话统计局限**：REALTALK 仅有 10 段对话且形成 3 个参与者聚类，正式推断仅基于 LoCoMo；Qwen3 在长对话上需使用 YaRN 扩展窗口，反而导致缺陷扩大。

- **计算资源信息缺失**：未报告硬件配置，不利于复现和效率评估。
