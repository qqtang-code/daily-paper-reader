## 摘要
现有的全模态大语言模型的令牌压缩方法通常依赖一种模态来决定在另一种模态中保留什么。我们发现这一假设常常不成立：对于同一查询，音频和视频的相关性往往在不同时刻达到峰值。这种跨模态显著性不匹配使得单向引导在激进压缩下容易丢弃回答关键线索。我们提出OmniScope，一种无需训练的令牌压缩框架，它将查询作为共享语义锚点，同时分别估计音频和视频的相关性。OmniScope分配模态特定的令牌预算，使用锚点增量策略修剪视觉令牌，同时保留全局上下文和时间变化，并在每秒内合并音频令牌以减少冗余同时保持时间连续性。在四个音频-视频基准测试和两个Qwen2.5-Omni模型规模上，OmniScope在所有压缩设置下均取得了最佳平均准确率。在总体令牌保留25%的情况下，它实现了高达3.53倍的预填充加速和超过15%的GPU内存减少，平均准确率仅下降0.35个百分点。这些结果表明了全模态大语言模型推理的一个简单设计原则：在模态间共享查询，但不共享显著性估计。代码开源在https://github.com/MAC-AutoML/OmniScope。

## Abstract
Existing token compression methods for omnimodal large language models typically rely on one modality to determine what to retain in the other. We show that this assumption often breaks down: for the same query, audio and video relevance often peaks at different moments. This cross-modal salience mismatch makes unidirectional guidance prone to discarding answer-critical cues under aggressive compression. We propose OmniScope, a training-free token compression framework that uses the query as a shared semantic anchor while estimating relevance separately for audio and video. OmniScope allocates modality-specific token budgets, prunes visual tokens with an anchor-delta strategy that preserves both global context and temporal changes, and merges audio tokens within each second to reduce redundancy while maintaining temporal continuity. Across four audio-video benchmarks and two Qwen2.5-Omni model scales, OmniScope achieves the best average accuracy across all compression settings. At 25% overall token retention, it delivers up to 3.53x prefill speedup and more than 15% GPU memory reduction, with only a 0.35-point drop in average accuracy. These results suggest a simple design principle for OmniLLM inference: share the query across modalities, but not the salience estimates. The code is available at https://github.com/MAC-AutoML/OmniScope.

- **核心问题**：现有压缩方法（如OmniZip）通常采用**单向跨模态引导**，即依赖一种模态的重要性来决定另一种模态保留什么。然而论文发现，对于同一查询，音频和视频的显著性峰值往往不同步（跨模态显著性不匹配）。如图1所示，哨声（音频关键）在早期达到峰值，而裁判手势（视觉关键）在后期达到峰值。如果仅用音频指引视觉，视觉关键信息可能被丢弃。实验表明约78.3%的查询-视频对中视觉与音频显著性只有弱相关性。
- **整体含义**：需要一种**模态解耦**的压缩策略：共享查询作为语义锚点，但让各模态独立评估自身重要性并分配预算，避免单向引导的脆弱性。

## 2. 论文提出的方法论：核心思想、关键技术细节

### 2.1 核心思想
- **查询感知评分**：以文本查询为共享锚点，独立计算视觉和音频令牌的查询相关性得分。
- **模态解耦预算分配**：视觉和音频分别根据自身得分按比例分配保留令牌数，不进行跨模态比较。
- **专门化的压缩策略**：视觉采用Anchor-Delta时空压缩（AD-STC），音频采用每秒令牌合并。

### 2.2 关键技术细节

#### 2.2.1 查询感知评分
- **视觉评分**：使用外部CLIP模型（CLIP ViT-L/14@336px）计算每一帧图像与查询的余弦相似度，得到帧级重要性分数 \( s_v^{(t)} \)。
- **音频评分**：利用LLM自身的音频编码器输出与查询词嵌入的相似度，计算门控跨模态相似度矩阵，聚合得到每秒音频重要性分数 \( s_a^{(s)} \)。为进一步增强时间连续性，对高分秒附近进行衰减式分数传播（公式6）。

#### 2.2.2 视觉压缩：Anchor-Delta Spatio-Temporal Compression (AD-STC)
- **锚定帧（偶数帧）**：采用密度峰值聚类（DPC-KNN）保留空间上最独特的令牌（低密度即高独特性的令牌）。
- **增量帧（奇数帧）**：根据保留率自适应切换策略：
  - 低压缩率（预算充足）：使用联合不可替代性分数（融合空间可替代性和时间可替代性，乘积取倒数），保留在空间和时间上都难以被替代的令牌。
  - 高压缩率（预算紧张）：仅计算当前帧与前一锚定帧的逐令牌余弦相似度，保留变化最大的令牌（最低相似度），集中预算捕获密集的时间增量。

#### 2.2.3 音频压缩：每秒二部图软匹配合并
- 在一秒段内，将令牌分成奇偶两组，计算相似度矩阵，选择最高相似度的 \( m \) 对进行融合（平均），而非丢弃。迭代进行直至达到目标令牌数。

### 2.3 算法流程（文字说明）
1. **评分阶段**：对输入视频的每一帧（CLIP）和每一秒音频（LLM内部嵌入）计算查询感知重要性得分。
2. **预算分配**：根据全局保留率（如45%或25%）和位置得分，按比例计算每帧/每秒应保留的令牌数。
3. **视觉压缩**：逐帧应用AD-STC——偶数帧用DPC-KNN选密度最低的令牌，奇数帧根据保留率阈值切换策略。
4. **音频压缩**：每秒内独立执行令牌合并。

## 6. 论文的主要结论与发现

1. **跨模态显著性不匹配是普遍现象**：约78.3%的样本中视觉与音频得分相关性弱（|ρ|<0.3），单向引导在高压缩比下易丢失关键信息。
2. **模态解耦压缩优于单向引导**：OmniScope在所有压缩率下平均准确率最高，45%保留时几乎无损，25%保留时仅降0.35点（7B模型），而OmniZip降1.55点。
3. **显著加速与内存节省**：25%保留时实现3.53×预填充加速，>15% GPU内存减少。
4. **视觉AD-STC平衡全局覆盖与时间增量**：交替锚定-增量帧及自适应策略优于统一策略。
5. **音频合并优于丢弃**：每秒二部图合并保留时间连续性和信息完整性，优于随机丢弃或能量过滤。

## 7. 优点

- **无需训练**：完全基于推理，即插即用，通用性强。
- **模态解耦设计**：避免单向引导的脆弱性，理论基础扎实（图2可视化支撑注意力增强方向）。
- **视觉压缩创新**：AD-STC通过交替帧角色和自适应策略，兼顾空间独特性和时间变化，解决现有视频压缩丢失全局语义的问题。
- **音频压缩精细**：以秒粒度进行合并而非粗粒度剪枝，保留时间连续性。
- **高效性**：音频评分利用已有嵌入，无额外内存开销；CLIP固定开销可摊销。
- **实验充分**：多基准、多模型、多压缩率，消融完整，开源代码。

## 8. 不足与局限

- **依赖外部CLIP评分器**：视觉评分需额外加载CLIP模型，引入固定推理开销（虽可摊销，但在极短生成场景仍显著）。

- **任务局限**：实验集中于多项选择QA，生成较短答案（通常1-2个token），未评测长文本生成（如视频描述）的端到端性能。
