## 摘要
大规模LLM推理面临内存墙挑战。KV缓存需要每秒数百GB的数十TB容量，但当前没有内存层次能同时满足两者。跨多代GPU系统使用各种LLaMA模型的特性表明，主机内存检索相比重新计算可实现高达100倍的加速，但仅支持数十个并发长上下文用户。电气CXL池化理论上可弥合这一差距，但交换延迟、电缆距离限制和功耗扩展问题阻碍了实际TB级部署。我们提出了Marvell光子结构内存设备，这是一种光子-CXL混合架构，用无源光纤洗牌替代电气交换机，通过无交换机的全交叉拓扑在16个主机间提供32TB共享内存。仿真结果显示，相比电气CXL池，延迟降低超过50%。模拟结果表明，PF内存设备通过将多轮对话工作负载的首令牌时间提升6.6倍，消除了缓存驱逐悬崖。

## Abstract
LLM inference at scale faces a memory wall. The KV cache demands tens of terabytes at hundreds of gigabytes per second, yet no current memory tier delivers both at once. Characterization across multi-generation GPU systems with various LLaMA models shows host memory retrieval achieves up to 100x speedup over re-computation but supports only tens of concurrent long-context users. Electrical CXL pooling theoretically bridges this gap, but switch latency, cable reach limits, and power-scaling issues prevent practical TB-scale deployments. We present the Marvell Photonic Fabric Memory Appliance, a photonic-CXL hybrid architecture replacing electrical switches with a passive fiber shuffle to deliver 32 TB shared memory across 16 hosts via a switch-free full- crossbar topology. Emulation results demonstrate over 50 percent latency reduction versus electrical CXL pools. Simulation results show that the PF Memory Appliance eliminates cache eviction cliffs by improving time-to-first-token by 6.6x for multi-turn conversations workloads.

- **论文动机**：设计一种新型内存架构，同时提供数十TB容量和超过100GB/s带宽，以支持大规模LLM推理中的KV缓存管理，避免因容量不足导致的缓存驱逐和性能悬崖。

## 2. 论文提出的方法论

### 核心思想
- 提出**Marvell Photonic Fabric (PF) Memory Appliance**，一种光子-CXL混合架构。
- 核心创新：用**无源光纤洗牌（passive fiber shuffle）**替代电气CXL交换机，构建**无交换机的全交叉（full-crossbar）拓扑**，实现16个主机间的32TB共享DDR5内存池。

### 关键技术细节
- **硬件组成**：
    - 16个**PF Memory Module**，每个模块是2.5D电光多芯片封装，包含：
        - 7.2 Tbps光子互连
        - 两个HBM3E堆栈（共72GB，作为写透缓存或额外池内存）
        - 8个DDR5接口（支持最多2TB DDR5）
        - 光学PIC内插器和光纤阵列单元
    - 16×16被动光纤洗牌：创建256条光学路径，实现任意主机到任意内存模块的直接访问。
    - **PF-NIC**：PCIe Gen6/CXL 3.1适配卡，桥接主机的CXL接口与光子互连。
    - 采用**GeSi电吸收调制器（EAM）**代替微环谐振器（MRR）或马赫-曾德调制器（MZM），兼顾热稳定性和小尺寸。
- **性能参数**：
    - 总容量：32 TB DDR5 + 1.125 TB HBM3E（可配置）
    - 每主机带宽：128 GB/s 单向
    - 总光学交换带宽：115 Tbps
    - 延迟：空闲状态下写224ns，读283ns；负载下写集中在210-250ns，读集中在275-320ns（尾延迟）
- **软件集成**：
    - 作为CXL Type-3设备，通过ACPI表枚举，Linux CXL子系统驱动。
    - 多主机共享内存使用**偏移量寻址**和**会合一致性协议**，避免缓存行级别的刷新操作。
    - 与vLLM、SGLang、NVIDIA Dynamo等框架通过插件接口集成，无需修改引擎内部。

### 核心公式
- KV检索加速比：`S = T_compute / T_memory`
    - `T_compute = b(2sP + 2s² n_head h_head L) / MFU`
    - `T_memory = K + bs/α`
    - 其中b为批大小，s为提示长度，P为参数量，n_head为注意力头数，h_head为头维度，L为层数，K为固定开销，α为每token加载成本。

## 6. 论文的主要结论与发现

1. **容量-带宽缺口明确**：主机内存提供充足带宽但容量不足，SSD提供容量但带宽不足，两者无法在单层中同时满足TB级容量和100+GB/s带宽。
2. **电气CXL扩展受限**：交换机延迟（70-500ns）、电缆距离（<2m需重定时器）和功耗问题导致无法实现实用TB级池。
3. **PF Memory Appliance优势**：
    - **延迟降低**：比电气CXL池（Beluga报告800-900ns）降低超过50%，实测约350ns（64字节访问）。
    - **带宽饱和**：在所有传输大小和访问模式下实现100%链路利用率（每端口25.6 GB/s有效带宽）。
    - **消除缓存驱逐悬崖**：在300并发多轮对话下，PF增强配置TTFT保持平坦（2.69秒），基线TTFT为17.7秒（6.6倍差距）。基线缓存命中率从82%暴跌至6.35%，PF增强保持82%。
4. **可扩展性**：单个8×H200系统+PF Memory Appliance可支持比2TB主机DRAM多**64倍**的并发多轮对话或长上下文会话，无缓存驱逐。

2. **技术成熟度**：采用工业界已证明的GeSi EAM调制器、2.5D电光封装、HBM3E缓存等组件，具备实际可行性。
