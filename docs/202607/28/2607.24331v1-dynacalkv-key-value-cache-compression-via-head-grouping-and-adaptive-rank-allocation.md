## 摘要
随着大型语言模型（LLMs）推理阶段需要处理长上下文窗口，关键值（KV）缓存最初旨在应对这一挑战，但随着上下文窗口的持续增长，它最终成为一个显著瓶颈。近年来，低秩压缩被研究作为一种在保持模型性能的同时减少KV缓存内存的有效方法。然而，现有方法中仅有少数区分对待键缓存和值缓存，尽管它们起着不同的作用。此外，这些方法通常采用固定的注意力头分组，这可能无法充分利用注意力头之间的结构相似性。在本文中，我们提出了一种改进的低秩KV缓存压缩框架。对于键缓存，我们基于中心核对齐（CKA）相似性动态分组注意力头，并在参数预算下自适应地分配秩预算。对于值缓存，我们采用与ReCalKV相同的方法，通过离线校准优化低秩分解以提高重构质量。在三个指令微调LLM上的实验结果表明，我们的方法在保持竞争性精度的同时减少了键缓存的参数数量。我们进一步观察到，所提出的策略对多头注意力（MHA）模型特别有效，而对于分组查询注意力（GQA）模型，尤其是在长上下文设置中，应更保守地应用。

## Abstract
As the inference phase of Large Language Models (LLMs) requires handling long context windows, the Key-Value (KV) cache initially appears to address this challenge but eventually becomes a significant bottleneck as the context window continues to grow. Low-rank compression has recently been studied as an effective approach to reduce KV cache memory while maintaining model performance. However, only a few existing methods treat the Key and Value caches differently, despite their distinct roles. Moreover, these methods typically employ fixed attention-head grouping, which may not fully exploit the structural similarity among attention heads. In this paper, we propose an improved low-rank KV cache compression framework. For the Key cache, we dynamically group attention heads based on Centered Kernel Alignment (CKA) similarity and allocate the rank budget adaptively under a parameter budget. For the Value cache, we adopt the same approach as ReCalKV, refining the low-rank decomposition through offline calibration to improve reconstruction quality. Experimental results on three instruction-tuned LLMs show that our method reduces the number of Key cache parameters while maintaining competitive accuracy. We further observe that the proposed strategy is particularly effective for Multi-Head Attention (MHA) models, whereas it should be applied more conservatively to Grouped-Query Attention (GQA) models, especially in long-context settings.

## 1. 论文的核心问题与整体含义（研究动机和背景）

大型语言模型（LLM）推理时，关键值（KV）缓存用于存储已生成token的注意力表示，避免了重复计算。但随着上下文窗口变长，KV缓存的内存占用线性增长，成为推理瓶颈。现有低秩压缩方法（如ReCalKV）虽然有效，但存在两个不足：  
- 未充分区分Key缓存和Value缓存的角色差异（Key主要作为索引，Value包含完整信息）；  
- 使用**固定大小的注意力头分组**（如每组4个头），未能根据头之间的相似性动态调整分组，导致压缩效率低。  

本文提出**DynaCalKV**框架，针对Key缓存基于CKA相似性动态分组并自适应分配秩预算，针对Value缓存沿用离线校准的低秩分解，在保持性能的同时进一步减少Key缓存参数。

## 2. 论文提出的方法论：核心思想、关键技术细节

**核心思想**：对Key缓存，先利用Centered Kernel Alignment（CKA）度量注意力头之间的表示相似性，然后通过层次聚类形成动态分组，再根据每组能量（奇异值平方和）分配初始秩，并通过贪心调整满足参数预算约束。对Value缓存，直接对整个投影矩阵做SVD低秩分解，并利用校准数据通过封闭解优化左、右因子以降低重构误差。

**关键技术细节**：
- **Key压缩**（算法1）：
  1. 给定Key投影矩阵 \(W^{(k)} \in \mathbb{R}^{m \times n}\)，秩预算r，候选聚类数K；
  2. 对每个K，使用凝聚层次聚类将h个头分组为K组，得到子矩阵 \(\{W_i\}\)；
  3. 按能量初始化每组秩 \(r_i = \text{round}(r \cdot \text{energy}(W_i) / \text{energy}(W^{(k)}))\)；
  4. 约束：总参数不超过ReCalKV的固定策略，即 \(\sum_i r_i \alpha_i \leq 4r/h\)，其中\(\alpha_i = h_i/h\)；
  5. 采用贪心调整：每次选择归一化能量损失\(\Delta E_i / \alpha_i\)最小的组，将其秩减1，直至满足约束；
  6. 对每个分组配置计算重构误差 + 秩利用率惩罚 \(\lambda (r - \sum r_i)\)，选最优K*。
- **Value压缩**（同ReCalKV）：
  1. 对整个Value投影矩阵做SVD得 \(W^{(v)} \approx L_v R_v\)；
  2. 利用校准数据集X，交替更新 \(L_v = W^{(v)} X X^\top R_v^\top (R_v X X^\top R_v^\top)^{-1}\) 和 \(R_v = (L_v^\top L_v)^{-1} L_v^\top W^{(v)}\)，最小化Frobenius范数重构误差。

1. **参数减少**：DynaCalKV较ReCalKV减少Key缓存参数 **16%–65%**，减少幅度与头维度dh负相关（dh越大，头相似性越低，分组更碎片化，减少少）。
2. **零-shot精度**：在常识任务（PIQA、ARC-e）上略有提升（+0.87%～+2.44%），在复杂推理任务上轻微下降（-0.28%～-3.00%），平均差异在±0.5%以内，说明压缩未严重损害性能。
3. **长上下文表现**：
