## 摘要
细粒度权重剪枝和激活稀疏化已成为降低Transformer模型推理计算和内存成本的有效方法。在中等稀疏度范围内，Gustavson数据流通过元数据驱动的索引累加，为在向量处理器上利用激活和权重稀疏性提供了一种自然执行模型。然而，现有的RVV架构缺乏对此模式的原生支持，迫使内核依赖软件索引解码和基于L1的索引内存操作，使得稀疏张量收缩远低于其Roofline性能上限。我们提出了Ventaglio，一种运行时可配置的稀疏执行单元，结合RVV ISA扩展，通过索引收集-累加-分散支持，将稀疏张量收缩推向其Roofline。Ventaglio集成到开源向量处理集群中，并在12nm FinFET中实现，相较于优化的RVV基线，加速了稀疏张量收缩内核6.9–7.4倍，而紧密L1耦合向量处理单元集群的面积开销仅为3.1%。我们构建了Ventaglio扩展的性能精确指令级模型，根据RTL实现进行校准，并利用其在4×4大规模多集群系统上进行扩展性能分析。使用经过DuoGPT剪枝的LLaMA-3-8B模型，实际双稀疏度为40–60%，Ventaglio在预填充和自回归解码阶段相较于稠密基线分别实现了2.40–5.25倍和2.06–3.16倍的加速。

## Abstract
Fine-grained weight pruning and activation sparsification have emerged as effective approaches for reducing the compute and memory cost of inference for Transformer models. In the moderate-sparsity regime, Gustavson's dataflow provides a natural execution model for exploiting both activation and weight sparsity on vector processors through metadata-driven indexed accumulation. However, existing RVV architectures lack native support for this pattern, forcing kernels to rely on software index decoding and L1-backed indexed memory operations that keep sparse tensor contractions far below their roofline performance bound. We present Ventaglio, a runtime-configurable sparse execution unit coupled with RVV ISA extensions that drives sparse tensor contractions toward their roofline through indexed gather-accumulate-scatter support. Integrated into an open-source vector processing cluster and implemented in 12nm FinFET, Ventaglio accelerates sparse tensor contraction kernels by $6.9\text{--}7.4\times$ over optimized RVV baselines, with only $3.1\%$ area overhead for a cluster of tightly-L1 coupled vector processing elements. We build a performance-accurate instruction-level model of the Ventaglio extension, calibrate it against RTL implementation, and leverage it for scale-out performance analysis on a large $4\times4$ multi-cluster system. Using a DuoGPT-pruned LLaMA-3-8B model with practical $40\text{--}60\%$ dual sparsity, Ventaglio achieves $2.40\text{--}5.25\times$ and $2.06\text{--}3.16\times$ speedup over dense baselines during prefill and autoregressive decoding, respectively.

- **核心问题**：现有实现依赖软件解码稀疏元数据和基于L1存储器的索引内存操作（gather/scatter），导致稀疏内核性能远低于Roofline模型的理论上限。具体表现为：①元数据解码在软件关键路径上；②索引累加通过通用内存操作而非核心内单元处理；③数据移动与计算解耦，无法高效链式执行。
- **整体含义**：设计一种低开销的硬件扩展，将稀疏元数据驱动的索引收集-累加-散射（gather-accumulate-scatter）提升为原生执行原语，使向量处理器在稀疏张量收缩中逼近Roofline性能。

### 2. 方法论：核心思想、关键技术细节
- **核心思想**：将扩展的稀疏累加状态从向量寄存器文件（VRF）中解耦，存储在专用的**多通道内存单元**中，该单元与向量算术单元（VAU）并行工作，提供非对称带宽而不争用VRF端口。同时扩展RVV指令集，实现元数据驱动的原生索引累加和地址后增语义。
- **关键技术细节**：
  - **Ventaglio内存单元**：采用多通道（C=4）锁存器标准单元存储器（SCM），每字1R1W端口，交错寻址，每个通道每周期贡献一个字，实现线性聚合带宽。容量为1 KiB，支持1:4、2:4和bitmap稀疏格式。
  - **Gather/Scatter数据路径**：模块化设计，一次仅激活一种稀疏模式（通过CSR选择），空闲路径门控以节能。包含节拍计数器管理打包元数据消耗，并在当前字最后一个有效节拍时预加载下一个元数据字。
  - **ISA扩展指令**：
    - `vlx.v`：从L1 SPM加载打包的索引元数据到VRF。
    - `vfxmacc.vf`：执行融合的索引乘加操作（fused indexed multiply-accumulate），通过5位`idx`字段选择索引上下文。
    - 地址后增指令（如`p.vlx.v inc`）：消除显式指针算术，减少循环控制开销。
  - **寄存器映射**：通过CSR标识映射到Ventaglio内存单元的VRF寄存器，旁路通道重定向访问，保持架构可见性，避免侵入式修改保留站。
- **算法/流程**（用文字说明）：
  1. 对每个非零激活元素，加载对应压缩权重行及其元数据。
  2. `vlx.v`加载元数据到VRF，配置Ventaglio的索引上下文。
  3. `vfxmacc.vf`在一次指令中完成：从Ventaglio内存单元收集目标累加器（gather），与激活值和权重值相乘，并将部分和散射（scatter）写回内存单元。
  4. 地址后增指令指针自动更新，进入下一个稀疏更新迭代。

### 7. 优点
- **硬件-软件协同优化**：提出新颖的**多通道内存单元**设计，解耦扩展累加状态与VRF，避免端口争用，并实现gather/scatter模块化。
- **ISA扩展简洁有效**：仅增加少数指令（`vlx.v`、`vfxmacc.vf`、地址后增），保持向后兼容，不破坏现有编译器/汇编代码。
- **低面积开销**：12nm下3.1%集群面积开销即实现6.9–7.4×加速，体现了极佳的效率比。
- **支持多种稀疏格式**：通过CSR可配置为1:4、2:4和bitmap模式，适应不同应用场景。
- **开放源码**：代码公开在GitHub（pulp-platform/spatz），可复现。
- **性能模型校准**：指令级模型与RTL偏差仅2.3%，为大规模多集群系统分析提供了可信度。
