## 摘要
长上下文召回在线性时间序列模型中突显了其写入记忆时的权衡。基于状态的线性模型，如状态空间模型（SSMs）和线性Transformer，采用密集写入方式，即每到达一个新 token 就更新整个状态，这会导致干扰并使得特定的历史 token 难以恢复。滑动窗口注意力（SWA）则表现出相反的行为：它通过存储显式的 token 表示来进行稀疏写入，但仅在一个固定窗口内，因此一旦相关 token 被驱逐，召回率就会下降。在这两类模型之间进行插值，我们引入了 Raven，一种线性时间序列模型，它维护一组固定的记忆槽，并在每一步中通过学习的、输入相关的路由仅衰减和更新选中的子集。这使得 Raven 能够减轻 SWA 中基于位置的覆盖和硬驱逐问题，同时减少 SSMs 中密集状态更新带来的干扰，从而更有效地保持长程内容。在各种召回密集型基准测试中，Raven 与先前的线性时间基线模型相比具有竞争力或更优，在 SWA 和 SSMs 均严重下降的长上下文召回任务中表现出色。当外推到训练长度 16 倍的上下文长度时，它仍然有效，并且在混合架构中也获得了类似的增益。

## Abstract
Long-context recall in linear-time sequence models highlights a tradeoff in how they write to memory. State-based linear models, such as state-space models (SSMs) and linear Transformers, write densely, updating the entire state for each newly arrived token, which leads to interference and makes specific past tokens hard to recover. Sliding-window attention (SWA) exhibits the opposite behavior: it writes sparsely by storing explicit token representations, but only within a fixed window, so recall drops once the relevant token is evicted. Interpolating between these models, we introduce Raven, a linear-time sequence model that maintains a fixed set of memory slots and, at each step, decays and updates only a selected subset via learned, input-dependent routing. This lets Raven mitigate SWA's position-based overwriting and hard eviction while reducing interference from dense state updates in SSMs, thereby preserving long-range content much more effectively. Across recall-intensive benchmarks, Raven is competitive with or outperforms prior linear-time baselines, achieving strong long-context recall where both SWA and SSMs sharply degrade. It remains effective when extrapolating to context lengths as large as 16x its training length, with similar gains in hybrid architectures.

**研究动机**：长上下文召回在线性时间序列模型中存在根本性的权衡：

- **滑动窗口注意力（SWA）**：相反地采用稀疏写入，仅保留最近固定窗口内的显式令牌表示，但一旦窗口滑动，较早的令牌就被硬驱逐，造成召回丢失。

现有模型要么写入过于密集（SSMs），要么写入过于位置化（SWA），缺乏“将信息写到哪里”和“信息持续多久”的分离控制。论文旨在填补这一空白，提出介于两者之间的模型，兼顾稀疏写入和持久存储。

**整体含义**：提出一种新的序列模型范式——路由槽记忆（RSMs），并实例化为Raven模型。通过输入依赖的稀疏路由选择性地更新记忆槽，同时施加显式衰减，从而在不牺牲模型容量的前提下实现高召回，并且能够外推到训练长度16倍以上的上下文。

## 2. 论文提出的方法论：核心思想、关键技术细节

### 2.1 核心思想
- **路由槽记忆（RSMs）框架**：形式化了一般线性递归模型中的写入位置选择。定义路由器向量 \( r_t \in \mathbb{R}^M \)，决定每个时间步哪些记忆槽被写入。SSMs对应全1路由器（所有槽更新），SWA对应独热向量（一个槽被覆盖）。Raven介于两者之间，使用稀疏输入依赖的路由。
- **解耦写入与遗忘**：Raven同时控制“写入哪个槽”和“写入/衰减的强度”，使模型能保护长距离关键信息。

### 2.2 关键技术细节
- **记忆结构**：维护两个独立状态 \( S_t^k, S_t^v \in \mathbb{R}^{M \times d} \)（key/value缓存），\( M \) 为记忆槽数，\( d \) 为每槽维度。
- **路由器设计**：
  - 计算原始得分：\( m_t = \sigma(W x_t) \in \mathbb{R}^M \)
  - 保留Top-K个最大条目，其余置零：\( g_t = \text{KeepTopK}(m_t) \)
  - 归一化：\( r_t = g_t / (\alpha \sum g_t[i]) \)，\(\alpha\)为超参数。
  - 训练时加入Gumbel噪声鼓励探索。
- **槽更新公式**：
  \[
  S_t^k = \exp(a_t r_t) \odot S_{t-1}^k + (1 - \exp(a_t r_t)) k_t^\top
  \]
  \[
  S_t^v = \exp(a_t r_t) \odot S_{t-1}^v + (1 - \exp(a_t r_t)) v_t^\top
  \]
  其中 \( a_t = -\text{SoftPlus}(w^\top x_t) \exp(\Delta) \) 是Mamba-2风格的标量衰减。
- **读取出**：\( o_t = (S_t^v)^\top \text{softmax}(S_t^k q_t) \)，注意力在 \( M \) 个槽上。
- **简化模块**：Raven省略了短程卷积，仅使用门控MLP作为通道混合器，结构比现有SSMs更简单。

### 2.3 与现有模型的联系
- SWA：路由器为时间相关的独热向量，无衰减。
- DeltaNet：路由器为密集的 \( k_t \)，使用秩-1投影。
- Raven：路由器为稀疏输入依赖的对角矩阵 \( \text{diag}(p_t) \)，\( p_t = 1 - \exp(a_t r_t) \)。

- **无需短程卷积**：Raven通过稀疏路由和衰减实现强召回，无需像其他线性模型那样依赖短程卷积。
