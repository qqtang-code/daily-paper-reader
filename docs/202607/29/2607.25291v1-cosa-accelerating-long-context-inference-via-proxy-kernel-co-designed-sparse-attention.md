## 摘要
自注意力的二次代价使得长上下文推理成本过高，而基于代理的块稀疏注意力已成为一种实用的补救措施。现有方法通常依赖代理预测二值稀疏掩码，并由内核使用该掩码执行稀疏注意力计算。在适度的预算下，这种方法有效。然而，随着预算收紧，估计的代理不可避免地会遗漏一些显著块，而内核只能机械地应用稀疏掩码，导致模型精度明显下降。我们提出CoSA，一种两阶段无需训练的代理-内核协同设计稀疏注意力方法，它将内核感知代理（KAP）与有序跳跃内核（OSK）相结合。在第一阶段，KAP在适度预算下选择块，并生成一个有序掩码，规定内核内部循环中KV页面的访问顺序。在第二阶段，OSK应用该掩码，并根据在线softmax统计在收紧预算下跳过更多块。在主流LLM骨干网络和长上下文基准测试中，CoSA在更低预算下实现了更高精度。令人印象深刻的是，CoSA在上下文长度为128K时实现了4.93倍的注意力加速，并将端到端的首token生成时间减少了2.53倍，且性能下降可忽略不计。

## Abstract
The quadratic cost of self-attention makes long-context inference prohibitively expensive, and proxy-based block-sparse attention has become a practical remedy. Existing methods typically rely on a proxy to predict a binary sparse mask and a kernel to consume this mask and perform sparse attention computation. Such an approach is effective under moderate budgets. However, as the budget tightens, the estimated proxy inevitably drops some salient blocks, while the kernel can only apply the sparse mask mechanically, leading to an evident drop in model accuracy. We propose CoSA, a two-stage training-free Sparse Attention under proxy-kernel CO-design, which couples a Kernel-Aware Proxy (KAP) with an Ordered-Skipping Kernel (OSK). In the first stage, the KAP selects blocks under a moderate budget and produces an ordered mask that prescribes the order in which KV pages are visited in the kernel inner loop. In the second stage, the OSK applies this mask and skips more blocks under a tightened budget given online-softmax statistics. Across mainstream LLM backbones and long-context benchmarks, CoSA attains higher accuracy at lower budgets. Impressively, CoSA achieves a 4.93$\times$ attention speedup and reduces end-to-end Time-to-First-Token by 2.53$\times$ under a context length of 128K with negligible performance degradation.

### 1. 核心问题与整体含义（研究动机和背景）

- **问题**：标准自注意力机制的平方复杂度使得长上下文推理成本过高。现有 **proxy-based 块稀疏注意力** 通过廉价代理预测二值稀疏掩码，让内核按掩码跳过部分块计算。该方法在中等预算下有效，但当预算收紧（即要求更高稀疏度）时，代理会遗漏真正重要的注意力块，内核机械地应用掩码导致模型精度明显下降。
- **核心挑战**：如何在大幅降低计算量（紧预算）的同时保持与全注意力接近的准确率，即平衡效率与保真度。

### 2. 论文提出的方法论

- **核心思想**：**proxy-kernel co-design（代理-内核协同设计）**，通过一个**有序计算掩码**（computation-order mask）作为桥梁，将代理和内核紧密耦合，实现两阶段稀疏化。
- **第一阶段：内核感知代理 (KAP)**
  - **块排序**：对 Q/K 做步长降采样，计算近似注意力分数 $\hat{S}$；对每块内的键做 MaxPool 后做 MaxNorm 得到块级重要性分数 $S^{KAP}_{ij}$；同时标记 **HRM (have rowmax)** 标志 $H_{ij}$，指示该块是否包含某查询行的全局最大值。
  - **标志分组排序**：对每个查询块，将候选键块按 HRM 标志分为两组，分别在组内按分数降序排序，并**优先访问 HRM 块**，非 HRM 块随后。在 **Stage-1 预算**（如 Top-p 选择）下截断生成有序掩码 $M_{KAP}$，它不仅指明哪些块保留，还规定了内核中访问的顺序。
- **第二阶段：有序跳跃内核 (OSK)**
  - **物理跳页**：利用 PagedAttention 的页面重映射机制，直接跳到 $M_{KAP}$ 指定的下一保留 KV 页面，避免对掩码丢弃的块进行循环控制和同步开销。
  - **内核内跳过 (IKS)**：对保留的块，利用在线 softmax 统计（running rowmax）按条件 $\max_r[m_{loc}[r] - m_i[r]] < \ln(\Delta/N)$ 判断是否跳过价值侧计算。条件使用真实 logits，比代理更精确。
  - **任意顺序页面访问**：利用 FlashAttention 的**顺序不变性**，先访问 HRM 块可使 running rowmax 快速接近全局最大值，缓解 skip 条件保守性（running max ≠ global max 以及单个 outlier 行 veto 的桶效应）。
- **算法流程**（Algorithm A）：KAP 生成有序掩码 → OSK 遍历保留页面 → 在线 softmax 更新 → 判断 IKS 跳过 → 执行计算/跳过。

- **主要结论**：CoSA 在所有稀疏方法中**以最低预算达到最高精度**。在 RULER 上平均精度 88.65%（Qwen3-8B）和 88.41%（Llama-3.1-8B），均优于 MInf、Flex、XAttn，预算分别为 22% 和 22%（远低于稠密的 100%）。LongBench-v2 上同样最优。

### 7. 优点

- **无需训练**：完全 inference-time 方法，易于部署到任意已训 LLM。
- **协同设计创新**：通过有序计算掩码将代理和内核连接，解决了紧预算下代理不可靠和内核跳跃保守的双重问题。
- **高效实现**：物理跳页减少无效循环；HRM 优先访问缓解桶效应；内核内跳过使用真实 logits 保持精度。
- **资源友好**：注意力加速随上下文长度线性增长，且能直接整合到基于 PagedAttention 的生产框架（如 vLLM）。
- **实验充分**：覆盖不同骨干、基准、预算、尺度，并进行了详尽的消融和帕累托分析。

- **仅覆盖预填充阶段**：稀疏化未应用于解码阶段（因解码中 query 形状不同和 KV cache 分页模式不同），限制了整体加速潜力。
