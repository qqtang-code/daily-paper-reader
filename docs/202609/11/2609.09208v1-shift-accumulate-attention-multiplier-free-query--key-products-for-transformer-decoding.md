## 摘要
二次幂（PoT）量化将乘法转化为位移，但迄今为止仅用于 softmax 后的注意力--值乘积。更早且规模更大的乘积 S=QK^T 尚未以同样方式重新表述。我们将键缓存量化为带符号的二次幂定点编码，使得 QK^T 中的每个标量乘法都变成符号翻转、位移和整数累加。定点裕量 F>=e_max 将每个移位指数 r=F-e 变为非负左移，使累加在整数运算中精确。我们加入了一种次幂尾数扩展，用一次额外的移位加法将得分误差减半；一种移位精确的在线 softmax，其运行最大值位于整数 log2 域中，使得每次重缩放本身都是精确移位；以及一种对数量化 AV 乘积。在 RTX 4090 上，1.1B Llama 解码器中的融合 CUDA 内核：在 B=8、T=32k 时，4 位内核比 FP16 缩放点积注意力快 4.60 倍，且 KV 缓存小 2.5 倍；批量解码在 B=64 时反超，达到 FP16 吞吐量的 1.22 倍，峰值内存为 11.02 GB 对 13.77 GB。在相同分块方案下，匹配的 INT8 乘累加内核达到 5.29 倍：在具有硬件 4 路 INT8 点积的 GPU 上，移位累加并不比它所替代的 MAC 更快。一个等存储对照——每个键恰好一个字节的 8 位移位码，通过相同内核运行——在相当精度下将仅算术替换的收益定为 2.02 倍。因此，PoT 表示的优势在于其密度和去除乘法器，而非原始 GPU 吞吐量。对指数宽度、尾数级别、粒度和舍入方式的扫描给出了设计经验：最近 PoT 相对误差与尺度无关，因此额外的指数位没有收益（在 3、4 和 5 位时 eps_S=0.1302），精度必须来自尾数项。

## Abstract
Power-of-two (PoT) quantisation turns a multiplication into a bit shift, so far only for the post-softmax attention--value product. The earlier and larger product, S=QK^T, has not been reformulated the same way. We quantise the key cache to a signed power-of-two fixed-point code, so that every scalar multiplication in QK^T becomes a sign flip, a bit shift and an integer accumulation. A fixed-point head-room F>= e_max turns every shift index r=F-e into a non-negative left shift, making the accumulation exact in integer arithmetic. We add a sub-power mantissa extension that halves the score error for one extra shift-add, a shift-exact online softmax whose running maximum lives in an integer log2 domain so that every rescaling is itself an exact shift, and a log-quantised AV product.   Fused CUDA kernels in a 1.1B Llama decoder on an RTX 4090: at B=8, T=32k the 4-bit kernel is 4.60x faster than FP16 scaled dot-product attention with a 2.5x smaller KV cache, and batched decoding crosses over at B=64 to 1.22x FP16 throughput at 11.02 against 13.77 GB peak memory. A matched INT8 multiply--accumulate kernel on the same tiling reaches 5.29x: on a GPU with a hardware 4-way INT8 dot product, shift-accumulate is not faster than the MAC it replaces. An iso-storage control--an 8-bit shift code of exactly one byte per key, run through the identical kernel--prices the arithmetic substitution alone at 2.02x at comparable accuracy. The advantage of the PoT representation is therefore its density and the removal of the multiplier, not raw GPU throughput. A sweep over exponent width, mantissa levels, granularity and rounding gives the design lesson: nearest-PoT relative error is scale-free, so extra exponent bits buy nothing (eps_S=0.1302 at 3, 4 and 5 bits) and accuracy must come from mantissa terms.

## 一、核心问题与整体含义

- **背景**：Transformer 解码中的缩放点积注意力包含两个密集矩阵乘：`S = QK^T` 与 `O = AV`，二者传统上都依赖乘法–累加（MAC）硬件。
- **已有工作的空白**：二次幂（Power-of-Two, PoT）量化能把乘法降为位移，但此前只用于 **softmax 之后的 AV 乘积**（如 FQ-ViT）。I-ViT 只把 requantisation scale 与非线性的近似做成 dyadic；P²-ViT 只约束量化 scale 为 PoT；ShiftAddViT 虽然去掉了注意力 MatMul 的乘法，但靠**二值化**操作数，只有 2 个电平。**没有任何工作把 `QK^T` 本身的一个操作数表示为有符号二次幂定点码**。
- **为什么 `QK^T` 更关键**：它是两个乘积中**更早、更大**的一个；解码时每个新生成的 token 都要完整读取整个 key cache，因此其**算术复杂度与位宽共同决定解码速率**。
- **整体含义**：本文主张把动态 K 激活本身做多级 PoT 编码，使两个注意力乘积都可用移位完成，从而在**去掉乘法器**的同时压缩 KV cache；但作者同时诚实地指出，在现有 GPU 上这一替换的收益主要来自**表示密度**，而非原始吞吐（因为硬件已有 4 路 INT8 点积 `__dp4a`，却没有对应的移位版本）。

## 二、方法论

### 1. 有符号二次幂键码
- 查询量化为 INT8（每向量步长 `Δ_i`）；键量化为有符号 PoT 定点码：
  `K_jm = s_j · σ_jm · 2^(−e_jm)`，`σ ∈ {−1,+1}`，`e ∈ {0,…,E}`，`e = E+1` 保留表示精确零。
- `b` 位字段分配：1 位符号 + `b−1` 位指数，故 `b=4` 对应 `E=6`。

### 2. 移位累加打分（核心公式）
- 引入公共定点裕量 `F` 与移位索引 `r_jm = F − e_jm`，得分内层求和变为纯整数**移位/符号/累加（SAC）**：
  `Ŝ_ij = Δ_i s_j 2^(−F) · Σ_m σ_jm (q̂_im ≪ r_jm)`
- 每个 (i,j) 只需在累加器形成后施加一次浮点因子，而**不是每项一次**。

### 3. 精确性
- 因 K 在量化前已按 `s_j` 归一化，所有 `e_jm ≥ 0`，故 `F ≥ E ⇒ r_jm ≥ 0`，所有移位都是**非负左移**，整数累加相对量化操作数**完全精确**，唯一误差来自操作数量化。
- 这是比"裕量减少截断"更强的结论。`d=64, F=7` 时累加上界 `≈1.04×10^6`，安全落在 INT32 内。

### 4. 尾数扩展（PoT-Mk 家族）
- 编码 `K̂ = s_j σ_jm (1 + m_jm/2^k) 2^(−e_jm)`，解码时每个置位需一次额外 shift-add，平均 `1 + k/2` 次移位。
- 3 位指数下，家族跨度从 4 位（PoT-4，一次移位）到 8 位（PoT-M4，最多五次移位），后者恰好**每元素一字节，与 INT8 KV cache 等存储**。
- 与通用 additive PoT 不同，第二项固定低一个 binade，**偏移编译期已知**。

### 5. 移位精确的在线 softmax 与 AV
- 把运行最大值放在整数 log₂ 域：`M = ⌈max_j s_ij log₂ e⌉`，则修正量 `k_j = round(M − s_ij log₂ e) ≥ 0`，`Ã_ij = 2^(−k_j)`，最大值增长时按 `2^(−ΔM)` 精确重缩放。
- AV 用 INT8 V + 每 token 的 PoT scale `2^(−g_j)`，令 `g_ref = min_j g_j` 保证移位索引不超过 `N`，per-tile INT32 累加器即可。

### 6. 融合内核与 cache
- 启动 `(split, H, B)` 个 128 线程 block；query 在寄存器内量化；cache 按 128 key 分块。
- 三阶段：① 向量化 16 字节码加载 + 无分支内循环算打分；② block 级在线 softmax；③ 共享内存暂存 INT8 value tile 并算 AV。
- cache 只存量化码：**PoT-4 每 key 101 字节 vs FP16 的 256 字节**。PyTorch 参考实现与内核输出吻合到 `2×10⁻⁴`。

### 7. 成本模型与 ISA 分析（本文的"请求硬件"部分）
- 一阶模型：`T ≈ max(R/Θ_mem, N/Θ_alu)`。
- 反汇编显示移位路径发射 **1011** 条整数 ALU 指令，而同等结构 MAC 内核只发 **409** 条；未打包的 query 还使占用率被压在 50%（MAC 为 67%）。结论：**瓶颈是指令发射，不是带宽**。
- PTX 的标量 `vshl/vshr` 带 `.add` 在 sm_89 上被**模拟**：clamp 形式 6.61 ops/term，wrap 形式 4.61，而普通 C 的 `(a≪b)+c` 只需 1.61（`SHF + IADD3` 已近最优），模拟开销主要来自移位量的 clamp/wrap 语义（PRMT/ISETP/SEL）。
- 真正缺失的是**打包的 4 路移位点积累加 DS4A**：`DS4A(Q,E,Σ,c) = c + Σ_{i<4} σ_i (q_i ≪ e_i)`。PTX SIMD video 集只有 `vadd4/vsub4`，移位仅标量形式。
- DS4A 的键侧操作数只需 `4×(1+3)=16` 位（对比 INT8 的 32 位），单元更小、读更窄；若以 `__dp4a` 同等吞吐提供，则 `T_proj = T_MAC · R(code)/R(INT8)`。
