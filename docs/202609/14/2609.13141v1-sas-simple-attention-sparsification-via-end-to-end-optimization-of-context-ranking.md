## 摘要
后训练注意力稀疏化通过为每个查询选择一小组上下文单元（词元或块），降低预训练 Transformer 的二次累积注意力开销。现有可训练方法通常使用轻量级选择器对上下文单元打分，随后进行硬 Top-K 选择，这会阻断来自语言建模损失的梯度。因此，这些方法通常蒸馏逐层的稠密注意力分布。尽管这促使选择器依据原始模型中的稠密注意力权重对上下文单元排序，但在固定注意力预算（即每个查询所关注的上下文单元数量）下，该排序并不直接与这些单元对预测的影响对齐，可能将有限预算浪费在不太有用的单元上。为解决这种不对齐问题，我们提出简单注意力稀疏化（SAS），一种门控稀疏注意力机制，可利用语言建模损失端到端地优化上下文排序。其核心思想是在训练期间将选择器的连续分数注入注意力 logits，使损失能够通过标准反向传播更新选择器。我们确定了若干对于这一简单设计在实践中良好运行至关重要的选择：以对数形式将门置于注意力 softmax 内部；使用归一化 softmax 门来校准历史上下文与始终保留的当前块；以及保留选择器的连续分数，使模型学习相对优先级而非仅进行硬选择。为支持长序列训练，我们实现了一个内存高效的 Triton 内核，将 SAS 集成到 FlashAttention 风格的计算中。在推理、长上下文理解和智能体任务中，SAS 在不同注意力预算下持续优于可训练稀疏注意力基线，在紧张预算下提升尤为显著，表明其能为下游任务实现更有效的上下文排序。

## Abstract
Post-training attention sparsification reduces the quadratic cumulative attention cost of pretrained Transformers by selecting a small set of context units (tokens or blocks) for each query. Existing trainable methods usually use a lightweight selector to score context units, followed by hard Top-K selection that blocks gradients from the language modeling loss. Consequently, these methods commonly distill layer-wise dense attention distributions. Although this encourages the selector to rank context units by dense attention weights in the original model, the ranking is not directly aligned with their impact on predictions under a fixed attention budget (i.e., the number of attended context units per query), potentially wasting the limited budget on less useful units. To address this misalignment, we propose Simple Attention Sparsification (SAS), a gated sparse attention mechanism that optimizes context ranking end-to-end with the language modeling loss. The key idea is to inject the selector's continuous scores into attention logits during training, allowing the loss to update the selector through standard backpropagation. We identify several choices crucial for this simple design to work well in practice: placing the gate inside the attention softmax in log form, using normalized softmax gates to calibrate historical context against the always-retained current block, and preserving continuous selector scores so the model learns relative priorities rather than only hard selections. To support long-sequence training, we implement a memory-efficient Triton kernel that integrates SAS into FlashAttention-style computation. Across reasoning, long-context understanding, and agentic tasks, SAS consistently outperforms trainable sparse attention baselines across attention budgets, with especially large gains under tight budgets, demonstrating more effective context ranking for downstream tasks.

## 1. 核心问题与整体含义

- **背景**：长上下文 LLM 自回归解码时，每个新 token 都要对所有历史 token 做稠密注意力，累计注意力成本随序列长度呈二次增长，成为长上下文推理的核心效率瓶颈。
- **研究动机**：实际部署中的高性能 LLM 多为稠密注意力模型，因此更希望采用“后训练注意力稀疏化”——在稠密预训练之后，为每个 query 选择少量上下文单元（token 或 block），避免改架构或重新预训练。
- **核心问题**：现有可训练稀疏方法通常用轻量 selector 打分，再做硬 Top-K 选择。硬 Top-K 不可微，梯度无法从语言建模损失传回 selector，因此只能依赖逐层稠密注意力蒸馏。
- **关键矛盾**：蒸馏让 selector 去匹配原稠密模型“在哪里分配注意力”，但在固定注意力预算下，真正重要的是哪些上下文单元对最终预测贡献更大。逐层注意力匹配可能忽略跨层互补性，也忽略 V 矩阵对输出的影响，导致有限预算被浪费在低价值单元上。
- **整体含义**：SAS 提出一种简单、端到端、无需教师注意力蒸馏的门控稀疏注意力机制，直接用语言建模损失优化上下文块排序，使稀疏选择更贴合下游预测目标。

## 2. 方法论

### 2.1 核心思想

- 将稀疏块选择重新表述为**上下文排序**：selector 为历史块打分，分数决定块的相对优先级，Top-K 只是排序后的离散化结果。
- 训练时不再把 selector 分数仅用于硬选择，而是把连续分数转化为 **log 空间门控**，注入注意力 softmax 内部，使语言建模损失可以通过标准反向传播更新 selector。
- 推理时仍使用硬 Top-K 块选择，保持稀疏注意力的效率优势。

### 2.2 训练与推理流程

- 设当前块为 \(B_0\)，始终保留且门 \(g_0=1\)；历史块为 \(H=\{B_1,\dots,B_C\}\)。
- Selector 为历史块输出分数 \(s\in\mathbb{R}^C\)，经 softmax 得到归一化门：
  \[
  g=\text{softmax}(s),\quad g_0=1
  \]
- 训练时选择 Top-K 历史块：
  \[
  I=\text{Top-K}(g,K),\quad S=B_0\cup\bigcup_{m\in I}B_m
  \]
- 训练注意力：
  \[
  o_{\text{SAS}}=\text{softmax}(qK_S^\top+\log g_S)V_S
  \]
  其中历史选中块获得归一化 log 门偏置，当前块保持无偏置。
- 推理时丢弃连续门，直接按 selector 分数做 Top-K：
  \[
  o=\text{softmax}(qK_S^\top)V_S
  \]
- 该设计使训练阶段梯度可回传至 selector，而推理阶段仍保持块稀疏计算。

### 2.3 四项关键设计选择

论文通过消融确定四个关键点：

1. **门位置：softmax 内部 vs 外部**
   - 内部门：\(\text{softmax}(qK^\top+\log g)V\)，门参与注意力归一化，直接重新分配注意力质量。
   - 外部门：\(\text{softmax}(qK^\top)(g\odot V)\)，只缩放 value 贡献，不改变注意力概率。
   - 内部门梯度形如：
     \[
     dg_m^{\text{inner}}=\sum_{i\in B_m}\frac{\tilde p_i}{g_m}d_o^\top(v_i-o)
     \]
     外部门梯度为：
     \[
     dg_m^{\text{outer}}=\sum_{i\in B_m}p_i d_o^\top v_i
     \]
     内部门提供相对重分配信号，实验更优。

2. **门激活：softmax 归一化 vs sigmoid / 原始 logits**
   - softmax 门将历史块与始终保留的当前块进行校准，且对全局平移不变。
   - sigmoid 门会逐渐饱和到 1，原始 logits 注入会塌缩到 0，二者都趋近于无门控，缺乏判别性。

3. **排序保留：连续软门 vs 硬 Top-K + STE**
   - 保留连续分数，让模型学习块的相对优先级，而不仅是二值选中/未选中。
   - 硬门虽降低训练损失，但梯度范数剧烈增大，最终稀疏性能更差。

4. **训练范围：稀疏范围 vs 全范围**
   - 稀疏范围只对选中块计算门控注意力，成本更低。
   - 全范围让未选中块也有自身梯度，早期优化更快，但最终性能与稀疏范围相当。
   - SAS 主要采用稀疏范围训练以降低长上下文训练成本。

### 2.4 Triton 内核实现

- 朴素实现需物化完整注意力矩阵，长上下文训练不可行。
- SAS 实现 FlashAttention 风格的 Triton 内核，将块门融合进 tile 级 \(qK^\top\) 计算。
- 前向：流式扫描 KV tile，对选中历史块加 log 门，未选块 mask 为 \(-\infty\)，当前块保留因果掩码与单位门；若某块无 query 选中则整块跳过。
- 反向：重算门控注意力概率，计算 Q/K/V 梯度，并把每个选中块内 token 的 score 梯度求和，得到块级 log 门梯度传回 selector。
- 结果：支持稀疏范围门控注意力训练，且不存储稠密注意力矩阵，保持 FlashAttention 式内存效率。
