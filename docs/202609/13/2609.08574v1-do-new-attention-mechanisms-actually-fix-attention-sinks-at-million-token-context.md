## 摘要
长上下文语言模型如今宣称具有一百万 token 的窗口，但有两种习惯限制了该窗口能被利用的程度。没有有用内容可读的注意力头仍将其预算花在第一个 token 上，这被称为注意力汇；而一个事实在上下文中的位置会改变模型是否能找到它。门控注意力在 NeurIPS 2025 上将首 token 注意力从 46.7% 降至 4.8%，而 Kimi K3 将该思路与 Kimi Delta Attention 和 Attention Residuals 结合，置于一百万 token 窗口之下，这一窗口长度是这些诊断曾被报告范围的八倍。本文追问这种修复能否经受这一跃迁。我们构建了 SinkProbe，一套测量汇质量、大规模激活、位置解析召回和近因差距的测试套件，并将其应用于四个小模型，这些模型仅在 token 混合方式和深度上不同。得到三个结果。产生注意力汇的是训练目标，而非架构。门控在我们的规模下未能复现其已发表的效果。汇质量、激活和位置偏置独立变化。代码、数据和测量协议发布于 https://github.com/sararizwan7/Attention-Mechanisms-in-1M-Context-Window

## Abstract
Long context language models now advertise windows of one million tokens, but two habits limit how much of that window is used. Attention heads with nothing useful to read still spend their budget on the first token, which is called the attention sink, and where a fact sits in the context changes whether the model finds it. Gated attention cut first token attention from 46.7 percent to 4.8 percent at NeurIPS 2025, and Kimi K3 pairs that idea with Kimi Delta Attention and Attention Residuals behind a one million token window, eight times past the range where these diagnostics have been reported. This paper asks whether the fix survives that jump. We build SinkProbe, a suite that measures sink mass, massive activation, position resolved recall and the recency gap, and apply it to four small models that differ only in how they mix tokens and depth. Three results follow. The training objective produces the sink, not the architecture. Gating did not reproduce its published effect at our scale. Sink mass, activations and position bias moved independently. Code, data and the measurement protocol are released at https://github.com/sararizwan7/Attention-Mechanisms-in-1M-Context-Window

## 1. 核心问题与整体含义

- **研究动机**：长上下文语言模型已宣称支持百万 token 窗口，但"窗口长度"与"可用记忆"之间存在巨大鸿沟。论文用"两个习惯"概括这一鸿沟：
  - **习惯一：注意力汇（attention sink）**。Softmax 注意力强制每个头将概率预算总和为 1，即使无有用内容可读，也必须把预算花在某处，实践中几乎总是落在第一个 token（通常是无语义的 BOS 标记）。Xiao 等（2024）发现剔除最初几个 token 会使流式模型崩溃；Qiu 等（2025）在 150 亿参数模型上测得首 token 平均吞掉 46.7% 注意力，单层高达 83%。
  - **习惯二：上下文读取不均**。"迷失在中间"（Lost in the Middle）导致 U 形位置曲线，两端好、中间差；在自然文本上通常近端更强，即"近因偏差"。
- **证据断层**：门控注意力（Qiu 等，NeurIPS 2025）报告首 token 注意力从 46.7% 降至 4.8%、最大激活从约 1053 降至约 94，但实验止于 128K token、150 亿参数；Kimi K3 采用 Kimi Delta Attention + Attention Residuals + 门控，宣称百万 token 窗口，却只报告基准分数而非机制诊断。**没有任何工作把"128K 的机制诊断"带到"1M 的长度"上**。
- **核心问题（标题即问题）**：当模型以门控与线性机制替换 softmax 并把窗口扩展到一百万 token 时，注意力汇会消失吗？上下文会被均匀读取吗？这两件事是同一个事件还是两个不同事件？论文尤其强调**最后一点**：汇与位置偏差通常被当作一个问题讨论，若实为两个，则修复前者对后者毫无帮助。

## 2. 方法论：SinkProbe 诊断套件

### 核心思想
构建一套可复现、可在笔记本上运行的四指标诊断工具，并在一个"受控阶梯"上逐层添加机制，使相邻两行的差异天然构成消融。

### 四个诊断指标（含公式说明）

- **汇质量 σ（式 1）**：对所有 softmax 层、所有头、所有查询位置 t≥2，求对位置 1（首 token）注意力的平均占比。跳过 t=1 因其只能看自己。均匀读取时理论值约为 1/T；在 T=160 时，未处理模型接近 0.5 意味着约 80 倍于均匀分配。同时报告**最差单层**值以捕捉集中现象。
- **巨量激活 μ（式 2）**：进入每层的隐状态中最大绝对值，在层上取平均。单独报告的原因是文献消融显示 μ 与 σ 可分离。
- **注意力熵 H（式 3）**：对所有可见位置的注意力分布求负熵（nats）。当汇"移动"到非首位时，熵可捕捉到。
- **位置解析召回 p(d) 与近因差 Δr（式 4）**：Δr = 后段（0.75,1] 平均召回 − 前段 [0,0.25] 平均召回。正值表示偏好近端，近零表示均匀读取。以 Wilson 分数区间报告。

### 四个模型的受控阶梯（宽度、深度、头数、数据、优化器、种子全部固定）

- **Softmax**：8 层因果 softmax + RoPE（应形成汇的基线）。
- **Softmax + gate**：在注意力输出上加逐通道、输入相关的 sigmoid 门（复现 Qiu 等机制）。
- **Hybrid 3:1**：3 层线性 delta 风格层 + 1 层门控全局层，重复两次，无位置编码（Kimi K3 模式的缩小版）。
- **Hybrid + AttnRes**：用 Block Attention Residuals 替换统一残差和。

### 关键实现细节

- **线性层**：状态 \(S_t = \mathrm{Diag}(a_t)S_{t-1} + k_t v_t^\top\)，输出 \(o_t = (S_t^\top q_t)\odot g_t\)；衰减 \(a_t\) 由输入生成并设下界以保证分块计算稳定；初始化时把通道衰减从约 0.78 到 0.999 铺开。**明确省略了真实 Kimi Delta Attention 的 delta 规则修正项**。
- **Attention Residuals**：8 层分 2 块（每块 4 层），块输出求和得 \(b_n\)，token embedding 保留为 \(b_0\)；每层用可学习伪查询 \(w_\ell\) 对 RMSNorm 后的源做 softmax 加权，构建自己的输入。
- **检索探针**：haystack 中植入一个 key-value 对（深度可控），散布若干干扰对，末尾提问。三个诚实性设计：干扰项键不同（不能靠复制唯一对作答）、只在单一位置评分、报告两个下限（盲猜与"返回上下文中任意值"）。
- **统计处理**：所有准确率为二项比例，用 Wilson 分数区间；给出样本量公式 \(n \ge z^2 p(1-p)/\epsilon^2\)；每模型 3 个种子，同时报告种子内区间与种子间离散度。
- **预注册阈值（表 IV）**：在大规模运行前固定通过/失败阈值，中间值一律报告为"不确定"，避免事后解读。

## 3. 实验设计

- **数据/场景**：完全合成、由种子生成的 key-value 检索任务（12 个不同键、12 个不同值、3 个干扰对、44 个填充符号）。haystack 使用周期 24 的 motif，一半位置随机替换——因为作者发现 haystack 可预测性对汇的形成影响极大（15% 随机化 → σ=0.095；50% 随机化 → σ=0.438）。
- **Benchmark**：自建 SinkProbe，含四个指标 + 两个召回下限（盲猜 8.3%、返回任意值 25%）。**只有超过 25% 上限才算真正检索**。
- **对比方法**：四个受控模型（Softmax、Softmax+gate、Hybrid 3:1、Hybrid+AttnRes）之间的逐步消融；另有一个**改变目标函数而非架构**的对照（去掉辅助下一 token 损失，只在答案位置计算损失）。
- **评估长度**：训练长度 96 token，评估 96/192/384/768（8 倍外推，作为"训练 64K 却要求 1M"的小尺度类比）。
- **成本模型**：无需运行模型，仅从 Kimi K3 报告的 93 层中 69 层为线性、24 层为全局，推算缓存增长（假设 bf16、latent rank 512、每头 128×128 状态）。

## 4. 资源与算力

- 论文明确说明：**硬件为 16 线程笔记本处理器，无加速器（no GPU）**；精度 float32；每模型训练 1500 步、batch size 16、AdamW、单周期学习率 2e-3。模型约 100 万参数，训练可在几分钟内完成。
- **未使用任何 GPU 集群或大规模算力**，论文以此作为设计目标之一（"读者用笔记本即可复现"）。
- 大规模验证（在 Kimi K3 权重上运行）**尚未执行**，论文第 VII 节给出协议与成本估计：1M token 那一行需 2156 条序列、约 21.6 亿 token 读取量，纯推理、无需梯度、可拆分请求，"适合分散在数天内的适度预算"。

## 5. 实验数量与充分性

- **实验规模**：4 个模型 × 3 个种子 = 12 次训练；每个模型 4 个评估长度；深度剖面每深度点每种子 32 条序列，聚合数字每长度每种子 128 条（三种子合并 384 条）；另有 1 组目标函数对照、1 组 haystack 噪声校准（单种子）、2 次失败的线性层修复尝试、1 套缓存成本计算、1 套单元测试（验证因果性、分块一致性到 3e-7、状态尺寸不随长度增长等）。
- **充分性评价**：
  - **客观/公平之处**：受控阶梯把宽度、深度、头数、数据、优化器、种子全部固定，相邻行差异即消融；统计上用 Wilson 区间并区分种子内与种子间两种变异；阈值预注册；检索任务设两个下限防"假检索"。
  - **不充分之处（作者自己承认）**：**Hybrid 两个模型完全没学会任务**（召回 6.0%、5.7%，低于盲猜 8.3%），因此其位置偏差数据无信息量；门控对比落在种子噪声内，被判为"不确定"；基线种子间 σ 从 0.089 到 0.455，跨度大于任何测得的架构差异。作者据此明确表示**小模型无法回答大模型的问题**，架构比较结论定为"不确定"。

## 6. 主要结论与发现

1. **汇由训练目标产生，而非架构**：同一 8 层 softmax 栈、同数据、同种子，只改损失覆盖范围——"每个位置都要预测"留下 31.6% 首 token 注意力（最差层 63.3%），"只回答末尾问题"仅 4.9%（最差层 6.7%），差 6 倍（最差层 9 倍），而**召回不变**（32.0% vs 33.3%），且种子离散度从 0.003 级别剧增。结论置信度高。
2. **门控在本文规模下未复现已发表效果**：σ 从 0.316 降至 0.261（−18%），但落在种子噪声内；关键解释是**门分数**——本文门控均值 0.686（门几乎全开），而已发表值在万亿 token 后为 0.116（门几乎全关）。机制在架构中，但未从权重中显现。
3. **σ、μ 与位置偏差三者独立变化**：
   - 门控把 μ 从 74.9 砍到 36.2（−52%），σ 仅降 17% 且仍在噪声内；
   - Attention Residuals 把 μ 从 97.9 降到 38.9（−60%），σ 反而从 0.183 升到 0.202；
   - 与文献中"value 投影后的门把 μ 从 1053 降到 125 但首 token 注意力仍为 0.297"一起，构成四次同向的"解耦"观察。
4. **位置偏差大、随长度翻转、且不跟随 σ**：召回随答案位置变化超过 20 个百分点，大于任何架构间差异；在训练长度内偏好开头（Δr 为负），在 768 token 外推时反转为偏好近端（基线 Δr=+15.2）；门控栈 σ 更低但 768 时深度曲线更陡。
5. **缓存算术成立**：93 层中 69 层为固定尺寸状态（74.2%，无需假设），1M token 时混合栈约 24 GiB，而同等深度全密集栈约 2.5 TiB，相差约 107 倍；低于约 8K token 时固定状态反而是更大项，说明该设计只在长上下文才划算。
6. **总体判断**：标题问题**仍然开放**，且无法用能在笔记本上训练的小模型来关闭；套件已就绪、阈值已固定，剩下的就是在发布权重上运行。

## 7. 优点

- **问题拆解清晰**：把"汇"与"位置偏差"明确当作两个独立测量，而不是一个问题的两面，这是全文最有价值的视角转换。
- **受控阶梯设计巧妙**：宽度、深度、数据、优化器、种子全部固定，只改 token 混合与深度混合规则，使相邻行天然成为消融，省去额外实验。
- **预注册协议（第 VII 节）**：在运行前固定测量长度、样本量、对照与阈值，并用表 XIII 提前规定四种结果组合各自的解读，避免"事后解释数据"。
- **统计严谨**：Wilson 区间 + 种子间离散度双报告；明确指出种子方差可能大于架构差异；样本量由公式推导而非拍脑袋。
- **诚实的负面结果**：作者主动承认 Hybrid 未学会任务、门控未复现、线性层缺少 delta 规则，并说明"失败属于我们的替代实现，不属于 Kimi K3"。
- **可复现性强**：纯 PyTorch + NumPy + Matplotlib，无预训练权重、无网络、无加速器；三个入口脚本按顺序运行即可复现全部图表；数据由种子生成，无需下载数据集。
- **成本模型无需运行**：用公开层数直接算出 74.2% 这一精确比例，并把两个未公开维度声明为可替换假设。

## 8. 不足与局限

-

- **规模不匹配是最根本的局限**：论文用约 100 万参数的玩具模型、96 token 训练长度去追问一个 1M token、千亿级参数模型的问题，作者自己承认"小模型无法回答大模型的问题"，因此所有架构层面的结论都被降级为"不确定"，只有"目标函数决定汇"这一条因对照强烈而保持较高置信度。
- **Hybrid 两个模型未学会任务**：召回率 6.0% 与 5.7%，低于盲猜下限 8.3%，意味着这两个模型的 σ、μ、Δr 全部无法解释为"已学会任务的模型所表现出的机制特征"，位置偏差数据实质无信息量。
- **门控未复现**：门分数均值 0.686（几乎全开）与已发表值 0.116（几乎全关）差距巨大，说明本文的门控训练不充分或初始化/优化路径不同，因此"门控无效"不能被解读为对 Qiu 等结论的反驳。
- **线性层实现不完整**：明确省略了 Kimi Delta Attention 的 delta 规则修正项，两次修复尝试失败，因此 Hybrid 的表现不能归因于 Kimi K3 的真实机制。
- **任务单一且合成**：只使用 key-value 检索这一种合成任务，没有自然语言、没有多跳推理、没有代码或长文档摘要；检索任务中"汇是否有用"与自然语言中"汇是否承担 no-op 语义"可能不同。
- **评估长度与目标差距大**：最长评估 768 token，仅为 1M 的约 1/1300；8 倍外推的类比虽有启发性，但不能替代真实长度上的测量。
- **成本模型含未验证假设**：latent rank 512、每头 128×128 状态、bf16 精度均为外部假设，两个未公开维度被声明为"可替换"，因此 24 GiB 与 2.5 TiB 的比值只在假设成立时有效。
- **对照实验数量有限**：目标函数对照只有一组、haystack 噪声校准只有单种子、深度剖面与聚合数字的样本量差异较大，部分结论（如 σ 的种子间离散）依赖较少的种子数（3 个）。
- **预注册协议尚未执行**：第 VII 节的协议与阈值虽已固定，但论文本身并未在 Kimi K3 权重上运行，因此"套件已就绪"只是方法学贡献，而非实证结论。
- **对已发表数值的跨模型比较需谨慎**：46.7%、4.8%、1053、125 等数字来自不同模型、不同数据、不同测量口径，本文将它们并置讨论虽具启发性，但严格意义上不构成同分布对照。

## 9. 总体评价与启示

- **核心贡献不在结论而在问题重构**：论文把"注意力汇"与"位置偏差"从"同一现象的两个侧面"重新表述为"两个可独立测量的量"，并用 σ、μ、H、Δr 四个指标将其操作化。这一视角转换比任何单一数值都更有持久价值。
- **方法论示范意义**：受控阶梯 + 预注册阈值 + Wilson 区间 + 种子间离散度 + 两个召回下限，构成了一套"小算力也能做严谨机制研究"的模板，可直接迁移到其他架构对比问题。
- **诚实的负面结果值得肯定**：主动报告 Hybrid 未学会、门控未复现、线性层缺 delta 规则、种子方差淹没架构差异，避免了在噪声上构建叙事。
- **对后续研究的直接指令**：论文实际上给出一条清晰路线图——把 SinkProbe 的四个指标、检索探针、预注册协议原样搬到 Kimi K3 或同级发布权重上运行，才能回答标题问题；在此之前，任何"新注意力机制修复了汇"的说法都缺乏机制层面的证据。
- **一句话总结**：这篇论文没有关闭标题中的问题，但它把问题从"窗口多长"推进到"汇与位置偏差是否同源、如何独立测量、如何在大模型上验证"，并留下了一套可执行、可复现、成本可控的验证协议。
