## 摘要
键值（KV）缓存驱逐对于扩展大语言模型中的长上下文推理至关重要。然而，现有策略主要依赖经验启发式方法，缺乏对固有非线性 softmax 注意力机制下 token 效用的严格刻画。在这项工作中，我们从局部信息几何的视角重新审视 KV 缓存驱逐，将注意力过程建模为非线性高斯通信信道。通过对注意力映射进行一阶泰勒展开，我们推导出雅可比信息容量，这是一个能够显式捕捉查询相关性、softmax 敏感性和结构多样性的新目标。在该理论指导下，我们提出 Jacap，一种容量感知的驱逐方法，它利用 softmax 感知的重要性加权和统计杠杆分数进行子集选择。跨多种架构和基准的大量实验表明，Jacap 在大多数场景中，尤其是在高压缩率情况下，具有更优的性能。

## Abstract
Key-value (KV) cache eviction is essential for scaling long-context inference in Large Language Models. However, existing policies predominantly rely on empirical heuristics, lacking a rigorous characterization of token utility under the inherently nonlinear softmax attention mechanism. In this work, we rethink KV cache eviction through the lens of local information geometry, modeling the attention process as a nonlinear Gaussian communication channel. By performing a first-order Taylor expansion of the attention mapping, we derive the Jacobian Information Capacity, a novel objective that explicitly captures query relevance, softmax sensitivity, and structural diversity. Guided by this theory, we introduce Jacap, a capacity-aware eviction method that utilizes softmax-aware importance weighting and statistical leverage scores for subset selection. Extensive experiments across diverse architectures and benchmarks demonstrate that \textsc{Jacap} delivers superior performance in most scenarios, particularly in high-compression regimes.

# Jacap：基于雅可比矩阵的非线性信息容量保持的 KV 缓存驱逐 — 论文总结

## 1. 核心问题与研究动机

- **背景**：大语言模型（LLM）被广泛用于多步推理、工具增强智能体、交互决策等长程任务，需处理数千至百万级 token 的长上下文。Transformer 推理成本随上下文长度快速增长，其中 KV 缓存的内存与延迟开销成为关键瓶颈。
- **现有方案**：KV 缓存驱逐（eviction）通过为每个缓存 token 打分、保留 top-ranked 子集来压缩缓存，因模型无关、易集成而广受关注。
- **核心问题**：现有驱逐策略（如 H2O、SnapKV 依赖注意力分数，StreamingLLM 依赖近因性，KNORM 依赖 value 范数）大多依赖**经验启发式**，缺乏对 softmax 注意力机制下 token 效用的严格刻画；它们通常**孤立地**对 token 打分，忽略缓存条目之间的冗余性与互补性，在高压缩率下表现不稳定。
- **已有理论局限**：CAP KV 借助信息瓶颈（IB）原理，在线性-高斯近似下将驱逐建模为最大化未来查询与注意力输出间的互信息，但**线性假设**把 query→output 映射视为固定变换，忽略了 softmax 归一化与竞争（饱和）动态，而这些恰恰是信息流分配的核心。
- **本文主张**：从**局部信息几何**视角出发，将保留的注意力建模为**非线性高斯信道**，通过一阶泰勒展开导出**雅可比信息容量（Jacobian Information Capacity）**，统一刻画查询相关性、softmax 敏感性与结构多样性，并据此提出实用驱逐算法 **Jacap**。

## 2. 方法论

### 2.1 核心思想

- 将 KV 驱逐形式化为约束函数逼近问题：在预算 |C| ≤ B 下最小化 E_q[‖f(q) − f_C(q)‖²]，其中 f_C(q) = U_C · softmax(K_C q / √d_k)。
- 把保留缓存视为噪声非线性信道：Y_C = f_C(q) + ε，ε ~ N(0, Σ_noise)，q ~ N(μ_Q, Λ_Q)，目标是最大化容量 L_C = I(q; Y_C | Z_C)。

### 2.2 关键技术细节

- **局部雅可比线性化（Lemma 1）**：在查询分布中心 μ_Q 处对 f_C 做一阶泰勒展开
  f_C(q) ≈ f_C(μ_Q) + J_C δq，其中
  **J_C = (1/√d_k) · U_C · S_C · K_C**，
  **S_C = Diag(α*_C) − α*_C (α*_C)ᵀ**，α*_C = softmax(K_C μ_Q / √d_k)。
- **雅可比信息容量（Theorem 1）**：
  L^Jac_C ≈ ½ log det(I + Σ_noise⁻¹ J_C Λ_Q J_Cᵀ)
  = ½ log det(I + (1/d_k) Σ_noise⁻¹ U_C S_C K_C Λ_Q K_Cᵀ S_C U_Cᵀ)。
- **与线性容量的区别**：引入 softmax 雅可比 S_C。其对角元 α_i(1−α_i) 度量 token 自身 logit 的局部敏感度（峰值在 α_i ≈ 0.5，在 α_i→0 或 1 时趋于 0，体现**饱和效应**）；非对角元 −α_i α_j 编码归一化带来的**token 间竞争**。
- **五要素分解**：key 可达性（K_C）、输出方向（U_C）、softmax 竞争（S_C）、查询统计（Λ_Q）、模型不确定性（Σ_noise）。

### 2.3 Jacap 算法（Algorithm 1）

为降低在线优化子集依赖的 log-det 目标的开销，采用一系列近似：

1. **子集无关的注意力近似**：在驱逐前的候选池 H_t 上用温度 τ 计算 ᾱ_i = softmax(k_iᵀ μ_Q / (τ√d_k))_i。
2. **对角化 softmax 竞争**：S_C ≈ Diag(ρ_i)，ρ_i = ᾱ_i(1−ᾱ_i)，保留饱和敏感度、舍弃成对耦合。
3. **对角化查询响应协方差**：K Λ_Q Kᵀ ≈ Diag(κ_i)，κ_i = k_iᵀ Λ_Q k_i。
4. **非线性重要度权重**：w_i = (1/d_k) · ᾱ_i²(1−ᾱ_i)² · κ_i。
5. **构建容量矩阵**：A_Jac = I + Σ_{j∈H_t} w_j u_j u_jᵀ（u_i = W_O v_i，或直接用 v_i 作轻量代理）。
6. **杠杆分数评分**：由矩阵行列式引理，score_i = w_i · u_iᵀ A_Jac⁻¹ u_i，取 top-B 构成保留子集 C。
- **复杂度**：每层每次驱逐 O(N d_h² + d_h³)，与 CAP KV 同量级，高于纯启发式的 O(N d_h)。

## 3. 实验设计

- **数据集 / 场景**：
  - **LongBench**：双语多任务长上下文理解基准，涵盖 SD-QA、MD-QA、摘要（SUMM）、少样本学习（FSL）、合成任务（SYNTH）、代码（CODE）共 16 个子任务。
  - **NIAH（Needle-in-Haystack）**：10k–120k token 上下文、needle depth 0.15–0.95 的稀疏检索场景。
  - **AIME25**：解码阶段在线驱逐的数学推理任务。
- **模型**：Qwen3-8B、Qwen3-14B、Llama3.1-8B（LongBench）；Qwen3-8B（NIAH）；Nemotron-7B（AIME25）。
- **压缩率**：LongBench 使用 0.25 / 0.5 / 0.75 / 0.9；NIAH 主文 0.75、附录 0.5；AIME25 用保留 token 数 2048 / 4096 / 8192 / 16384 控制预算。
- **对比基线**：CAP KV（线性容量信息论方法）、SnapKV（注意力启发式）、KeyDiff（key 相似度）、Expected Attention（EA，未来查询分布估计）、KNORM（l2 范数）。
- **消融**：温度参数 τ ∈ {1, 5, 10, 20, 30} 对 LongBench 平均性能的影响。
- **附加评估**：运行时效率（生成 100 token 的总耗时，8k–64k 输入、压缩率 0.6 与 0.8）。

  - **优点**：跨 4 个模型、3 类基准、多压缩率、多任务，覆盖较全面；高压缩率（0.75/0.9）与极长上下文（>100k）等困难场景均有覆盖；消融验证了关键超参 τ 的作用。

## 6. 主要结论与发现

- **LongBench**：在 0.75 压缩率下，Jacap 总体与 CAP KV 相当或略优，显著优于启发式基线；在 **0.9 极端压缩**下优势最大，平均分领先次优方法约 **5 分**，在 SD-QA、MD-QA 上保持更强，且随压缩率升高退化更稳定。
- **NIAH**：在深 needle 与长上下文（尤其 >100k token）下，Jacap 检索稳定性明显优于 SnapKV 等注意力方法，以及 KeyDiff、KNORM 等结构方法。
- **AIME25 在线解码**：在最小预算（2048）与最大预算（16384）下均取得最佳；4096 时与 CAP KV 持平；仅在 8192 时被 CAP KV 反超，说明在紧/宽预算下均具竞争力。
- **消融**：温度 τ ≈ 10 最优——过小使先验过于尖锐、过度聚焦少数高对齐 token；过大则过度平滑、退化为多样性主导的选择。
- **效率**：虽然理论复杂度更高（O(N d_h² + d_h³)），但实际运行时间与主流方法相当（head 维度小、矩阵运算高度并行）。

## 7. 优点

- **理论严谨且具解释性**：用非线性信道 + 一阶泰勒展开刻画 softmax 注意力，把线性容量作为特例纳入统一框架；明确揭示"高注意力≠高重要性"——饱和 token（α→1）局部信息价值低，中等注意力 token（α≈0.5）敏感度最高。
- **理论到算法的降维路径清晰**：通过对角化 S_C、KΛ_QKᵀ 等近似，把难以在线优化的子集依赖 log-det 目标转化为可高效计算的杠杆分数评分，兼顾原理性与实用性。
- **即插即用、模型无关**：与量化、系统级优化正交，可直接嵌入现有推理管线。
- **实验覆盖广**：跨 Qwen3-8B/14B、Llama3.1-8B、Nemotron-7B 四种架构，LongBench/NIAH/AIME25 三类任务，压缩率从 0.25 到 0.9 全覆盖，并包含运行时与超参消融。
- **高压缩场景针对性验证**：专门强调并验证了 0.9 极端压缩与 120k 长上下文下的鲁棒性。

## 8. 不足与局限

- **近似误差**：仅使用一阶泰勒展开，仅在查询分布中心 μ_Q 的局部邻域有效；在查询分布高度多峰或动态变化剧烈时表达能力受限（作者在结论中自述）。
- **对角化损失信息**：将 softmax 竞争矩阵 S_C 与查询响应协方差 KΛ_QKᵀ 均对角化，丢弃了 token 间竞争与相关性的成对结构，可能低估互补性组合的价值。
- **超参依赖**：温度 τ 需人工调参（最优约 10），不同模型/任务下的最优值未系统探究。
- **实验覆盖不均**：NIAH 与 AIME25 仅单一模型；AIME25 样本量小且 Jacap 在 8192 预算下逊于 CAP KV；缺乏统计显著性检验与多次运行方差报告。
- **计算开销**：复杂度高于启发式方法，作者未做严格延迟/吞吐的端到端系统级评估，仅在生成 100 token 的小规模运行时间上验证。
- **μ_Q 与 Λ_Q 估计**：依赖历史查询统计，在线解码初期或查询分布突变时估计可能不准，论文未深入分析其敏感性。
- **消融不完整**：对角近似、u_i 取 v_i 的代理选择、杠杆分数近似的必要性均缺乏单独消融验证。
