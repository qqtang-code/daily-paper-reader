## 摘要
尽管多模态大语言模型（MLLMs）在各类任务中表现出色，但其可扩展性仍受限于 KV 缓存存储的内存与计算开销。近期的 KV 缓存驱逐方法将基于余弦相似度的多样性度量与重要性度量相结合，以选择性地保留关键的键值对。然而，余弦相似度涉及归一化，会丢弃幅度信息；并且由于隐藏表示的各向异性特性，它在不同层之间往往会产生一致偏高的相似度值。在我们的研究 ECOKV 中，我们严格解构了现有多样性度量的能力。超越简单度量，我们提出一种几何感知的复合度量，联合利用欧氏距离和余弦相似度，从互补视角捕捉 token 多样性。此外，我们利用这两个度量来估计每个注意力头的冗余程度，从而在 token 选择过程中自适应地权衡多样性得分与重要性得分。最后，我们证明，通常用于保留近期 token 的观察窗口可以大幅缩小，从而将更多缓存容量分配给信息丰富的 token，并带来一致的性能提升。大量实验表明，ECOKV 在各种压缩率下均达到最先进性能，并且可以无缝集成到现有的 KV 缓存驱逐方法中。我们进一步分析了重要性与多样性之间的关系，并考察了跨层和注意力头的冗余模式。

## Abstract
Although multimodal Large Language Models (MLLMs) excel in diverse tasks, their scalability remains limited by the memory and computational overhead of KV cache storage. Recent KV cache eviction approaches incorporate a cosine similarity-based diversity metric with importance metrics to selectively retain critical key-value pairs. However, cosine similarity involves normalization that discards magnitude information, and it often yields uniformly high similarity values across layers due to the anisotropy property of hidden representations. In our study ECOKV, we rigorously deconstruct the capabilities of existing diversity metrics. Moving beyond simple measurement, we propose a geometry-aware composite metric that jointly leverages Euclidean distance and cosine similarity to capture token diversity from complementary perspectives. Furthermore, we use these two metrics to estimate the redundancy level of each attention head, allowing adaptive weighting between diversity and importance scores during token selection. Finally, we demonstrate that the observation window commonly employed to preserve recent tokens can be substantially reduced, thereby allocating more cache capacity to informative tokens and yielding consistent improvements. Extensive experiments demonstrate that ECOKV achieves state-of-the-art performance under various compression ratios and can be seamlessly integrated with existing KV cache eviction methods. We further analyze the relationship between importance and diversity, and examine redundancy patterns across layers and attention heads.

# ECOKV 论文中文总结

## 1. 核心问题与整体含义（研究动机与背景）

- **背景**：多模态大语言模型（MLLMs）在视觉问答、图像描述、文档理解等任务上表现优异，但输入上下文越来越长，KV 缓存的内存与计算开销随序列长度线性增长，成为推理效率的核心瓶颈。
- **现有方案**：KV 缓存驱逐（KV cache eviction）是一种免训练方法，通过打分函数选择性保留 top-K 键值对，代表性思路包括重要性打分（如 SnapKV 的观察窗口投票、KNorm、VNorm）与多样性打分（如 KeyDiff、MixKV、ManifoldKV）。
- **核心痛点**：
  - 现有多样性度量几乎都基于**余弦相似度**，它对向量做归一化，**丢弃了幅度信息**。
  - Transformer 隐藏表示存在**各向异性（anisotropy）**，导致余弦相似度在各层普遍偏高（论文图 1/图 2 显示 Qwen2-VL 各层平均相似度均 > 0.4，第 0 层接近 1.0），从而**高估冗余、误导驱逐决策**。
  - 欧氏距离虽保留幅度信息，但缺乏方向信息且无界，单一使用效果不佳。
  - 传统方法沿用 SnapKV 的**观察窗口 N=32**，在紧预算下占用大量缓存预算，压缩了动态 token 选择的容量。
- **整体含义**：ECOKV 旨在用「几何感知的互补多样性度量 + 头自适应冗余估计 + 极小观察窗口」三管齐下，提升 MLLM 长上下文推理中 KV 缓存驱逐的效果，并可作为插件无缝集成到现有方法上。

## 2. 方法论

### 核心思想
- 从**互补几何视角**同时利用**欧氏距离（幅度 + 位置）**与**余弦相似度（方向）**刻画 token 多样性，并据此估计每个注意力头的冗余度，自适应地在「多样性」与「重要性」之间加权。

### 关键技术细节

- **欧氏多样性得分**：
  - 计算所有 key 的质心 \(\bar{k} = \frac{1}{T}\sum_i k_i\)，并求每个 key 到质心的欧氏距离 \(d_E(i) = \|k_i - \bar{k}\|_2\)，距离越大表示越独特、非冗余。
  - 用 min-max 归一化（加小常数 ε 保证数值稳定）映射到 [0,1]，得到 \(s_E(i)\)，归一化不改变排序但对后续与余弦得分组合至关重要。

- **复合多样性得分**：
  - \(S_{div}(i) = \alpha \cdot s_E(i) + (1-\alpha) \cdot s_C(i)\)，其中 \(s_C\) 为 MixKV 提出的基于余弦相似度的多样性得分，\(\alpha \in [0,1]\) 平衡幅度感知与方向感知。

- **头自适应冗余估计**：
  - 计算每个头 h 的平均欧氏距离 \(D_h^E = \frac{1}{T}\sum_i d_h^E(i)\)，越大表示越分散（冗余越低）。
  - 通过缩放 sigmoid 映射为幅度感知冗余分：\(r_E = 2 - 2\sigma(D_h^E/\tau)\)，温度取 \(\tau = \sqrt{d_k}\)（因平均距离与 key 维度的平方根成比例）。
  - 与余弦冗余分 \(r_C\)（来自 MixKV）组合：\(\lambda = \beta \cdot r_E + (1-\beta) \cdot r_C\)，其中 \(\beta \in [0,1]\)。冗余高的头获得较大 λ，强调多样性；冗余低的头强调重要性。

- **最终选择分数**：
  - 先将 \(S_{div}\) 归一化并按重要性得分的均值/标准差做尺度对齐得到 \(\tilde{S}_{div}\)，再与重要性得分 \(S_{imp}\)（由 value 向量 ℓ2 范数 + 观察窗口内平均注意力组合）加权：
  - \(S(i) = \lambda \cdot \tilde{S}_{div}(i) + (1-\lambda) \cdot S_{imp}(i)\)，对每个注意力头做 top-K 保留，实现层/头粒度的细粒度自适应驱逐。

- **极小观察窗口**：
  - 将观察窗口从 32 大幅减小到 4 甚至仅保留最近 1 个 token；论文发现近期 token 本身常会被驱逐算法自然保留，固定大窗口反而浪费预算。

- **推荐超参**：α = 0.8、β = 0.6、窗口大小 = 4，可跨模型/基准取得近最优效果，无需逐一搜索。

## 6. 主要结论与发现

- **性能**：ECOKV 在各基准、各压缩率下达到 SOTA，且在预算 256 时已能匹配甚至超越 FullKV；紧预算（64）下相对基线的提升尤为显著（如 LLaVA 上 PyramidKV 集成在 DocVQA 64 预算下 +11.0）。
- **互补性有效**：最优 α/β 组合优于纯欧氏（α=β=0）与纯余弦（α=β=1）配置，证明两种几何度量信息互补。
- **观察窗口可大幅缩小**：窗口从 32 减到 4 或 1 一致带来提升，原因是大窗口挤占动态选择预算，且驱逐算法本身已倾向保留近期 token。
- **重要性与多样性相关性低到中等**：二者排序差异明显，且在**中间层相关性最低**，说明多样性在中间层对 KV 选择贡献最大，仅用重要性会降低保留集的代表性。
- **冗余模式**：各层冗余呈「早期层高 → 中间层低 → 后期层逐渐回升」的 U 型趋势，欧氏与余弦两种冗余估计整体趋势一致但局部有差异。
- **归一化鲁棒**：min-max、winsorized min-max、MAD 三种策略性能相当，说明方法对离群值不敏感。

## 7. 优点

- **问题洞察到位**：准确指出余弦相似度在 MLLM 中的两个根本缺陷（丢失幅度、各向异性导致相似度虚高），并用 PCA 可视化与层间统计提供实证。
- **方法简洁且正交**：欧氏 + 余弦的复合指标、头自适应 λ 估计、极小观察窗口三个模块各自独立可插拔，且能与 SnapKV/PyramidKV/AdaKV/SparseMM 等现有框架无缝结合。
- **工程实用性强**：额外计算开销极小，效率与基线相当，缓存与峰值内存显著低于 FullKV；固定 α=0.8、β=0.6 即可免调参。
- **分析深入**：不仅报告性能，还提供了重要性-多样性相关性、层/头冗余分布、token 选择频率、冗余估计替代方案等分析，附录内容丰富（算法伪代码、超参表、运行时长）。
- **反直觉发现有价值**：挑战了「大观察窗口保护近期 token」的既有惯例，并用选择频率统计和基线对比双重佐证。

## 8. 不足与局限

- **模型覆盖有限**：仅在 LLaVA-NeXT-Mistral-7B 与 Qwen2-VL-7B-Instruct 两个 7B 级模型上验证，未涉及更大规模模型、其他架构或纯文本 LLM 的泛化性。
- **硬件与规模说明不足**：未明确报告 GPU 数量、总训练/评测时长与总能耗，复现成本难以精确估计。
- **超参并非完全免调**：虽然推荐固定 α=0.8、β=0.6，但论文承认最优 α 会随基线方法变化，说明超参仍有一定数据集/方法依赖性。
- **冗余估计的启发式性质**：λ 的设计基于缩放 sigmoid 与经验温度 τ=√d_k，缺乏理论最优性保证；替代方案（标准差法）性能接近，说明该模块的增益来源可能部分可替换。
- **长上下文评估相对单薄**：长上下文仅用 MP-DocVQA 一个数据集，且只在 Qwen2-VL 上评测，对超长上下文（如 >32K）的扩展性验证不足。
- **效率收益有限**：在短输出基准上总推理时间缩短幅度不大（受限于解码时间短），方法主要收益在内存而非延迟。
- **潜在偏差风险**：所有基准以 OCR/文档/图表类视觉问答为主，对纯自然图像推理、视频理解等场景的适用性未验证；相关性分析仅采样 100 个测试用例，统计稳定性有限。
