## 摘要
自回归大语言模型（LLM）解码在每一步都会重新读取不断增长的键值（KV）缓存，因此长上下文注意力受限于图形处理器（GPU）内存带宽。块稀疏注意力会跳过低贡献的 KV 块，但诸如最大相对块阈值（BLASST）之类在当前查询-键（QK）乘积之后才做出决策的选择器仍会读取每个 K 块，而从当前查询做出决策的内存内处理（PIM）过滤器会在关键路径上引入一个串行 PIM 阶段。我们提出 AMEND，一种 GPU-PIM 注意力设计，消除了这两种依赖。AMEND 根据在较早步骤审计的裕度来预测每个块的 BLASST 判定，因此 GPU 只获取预测的存活块，而高带宽内存（HBM）中的近存储体 PIM 单元同时为被省略的补集打分。栈级控制器合并这两种观测，更新预测器，并提前生成下一步的掩码，因此每个被预测丢弃的块都会被重新观测，而不会阻塞当前 token。工作点通过受约束的贝叶斯优化在误丢弃预算下离线选择。在 LongBench 和 RULER 运行中，AMEND 保持了接近基线的任务质量；在批大小为 8 的仿真中，它在 8K-64K 上下文范围内实现了相比密集注意力 $1.40$-$3.63\times$ 的端到端解码加速，以及低 28-66% 的动态解码能耗。

## Abstract
Autoregressive large language model (LLM) decoding re-reads a growing key-value (KV) cache at every step, so long-context attention is bound by graphics processing unit (GPU) memory bandwidth. Block-sparse attention skips low-contribution KV blocks, but a selector that decides after the current query-key (QK) product, such as max-relative block thresholding (BLASST), still reads every K block, and a processing-in-memory (PIM) filter that decides from the current query places a serial PIM stage on the critical path. We present AMEND, a GPU-PIM attention design that removes both dependencies. AMEND predicts each block's BLASST verdict from margins audited at earlier steps, so the GPU fetches only predicted survivors while near-bank PIM units in high-bandwidth memory (HBM) concurrently score the omitted complement. A stack-level controller merges both observations, updates the predictor, and eagerly generates the next step's mask, so every predicted drop is re-observed without blocking the current token. Operating points are selected offline by constrained Bayesian optimization under a false-drop budget. Across LongBench and RULER runs, AMEND preserves near-baseline task quality; in simulation at batch size 8, it achieves $1.40$-$3.63\times$ end-to-end decode speedup and 28-66% lower dynamic decode energy than dense attention across 8K-64K contexts.

- **现有块稀疏注意力的两类瓶颈**：
  - **后 QK 选择器**：如 BLASST，在当前 query–key 乘积之后才能判断哪些块可丢；虽然可跳过 softmax、V 读取和 PV，但仍需先读取全部 K 块并计算 QK。论文指出，在 90% 块稀疏下，K 仍占剩余逻辑 K+V 流量的约 91%。
  - **当前查询 PIM 过滤器**：把选择移到近存储 PIM，但掩码仍依赖当前 query，因此 PIM 阶段串行地位于 query→scores→mask→attention 的关键路径上。
- **整体含义**：论文试图打破“先算 QK 再决定丢弃”和“PIM 过滤器串行阻塞”的依赖，利用历史步骤中已审计的 BLASST margin，在 GPU 读取 K 之前生成存活块掩码；同时让 PIM 并行审计被 GPU 省略的补集，实现非阻塞丢弃。
- **关键观察**：
  - BLASST 判定具有时间持续性：在 Qwen3-1.7B 的 trace 中，89.2% 的 eligible BLASST verdict 在下一步保持不变。
  - BLASST margin 的连续值比二值掩码携带更多信息，可区分“远低于阈值”和“刚好低于阈值”。
  - 预测丢弃会引入“观测空洞”：被丢块不再被观测，预测器若只用幸存块更新，会陷入 selective-labels 问题；因此必须审计每个预测丢弃。

## 2. 方法论

- **核心思想**：AMEND 用早期步骤审计得到的 margin 预测每个 KV 块的 BLASST verdict；GPU 只读取预测幸存块，近存储体 PIM 单元并行计算全局被省略块的 QK；栈级控制器合并两类观测、更新预测器，并提前生成下一步掩码。
- **决策参考：全缓存 BLASST**：
  - 对 token \(t\)、层 \(\ell\)、query head \(h\)、块 \(b\)，块最大值为  
    \(m^\star_{t,\ell,h,b}=\max_{j\in I_b} q^\top k/\sqrt d\)。
  - 排他前缀最大值为 \(p^\star_{t,\ell,h,b}=\max_{b'<b} m^\star_{t,\ell,h,b'}\)，上下文偏移为 \(\eta_t=\log(\mathrm{TSF}/S_t)\)。
  - GQA 归约后的选择 margin：  
    \(\gamma^\star_{t,\ell,g,b}=\max_{h\in G(g)}(m^\star_{t,\ell,h,b}-p^\star_{t,\ell,h,b}-\eta_t)\)。
  - 当 \(\gamma^\star<0\) 且 \(S_t\ge \mathrm{TSF}\) 时，全缓存 BLASST 判定为 DROP，否则 KEEP；块 0 强制保留。
- **预测器状态与操作点**：
  - 每个 cell（层、KV head、块）维护：margin EMA \(\mu\)、二阶矩 \(M_2\)、drop-run age \(a\)、2-bit Schmitt counter \(c\)。
  - 波动率 \(\sigma=\sqrt{\max(M_2-\mu^2,0)}\)。
  - 五维操作点 \(\theta=(r,\delta,\alpha,R,z)\) 离线由 SCBO 选择。
- **因果判定规则**：
  - 基础条件：age \(a\ge r\)，且 \(\mu+z\sigma<-\delta\)，且 cell 满足 base eligible。
  - 2-bit Schmitt counter：\(c^+=\mathrm{clip}(c^-+(2u-1),0,3)\)，仅当 \(u=1\) 且 \(c^+=3\) 时输出预测丢弃 \(\hat D_t=1\)，以抑制孤立翻转。
  - 硬保留：块 0、最后一块、partial tail、最近 \(R\) 个块强制 KEEP；无有效历史默认 KEEP。
- **两级裁剪**：
  - **Cut 1，pre-QK 预测裁剪**：\(P^{keep}_t=1-D^{pre}_t\)，其中 \(D^{pre}_t=\hat D_t\wedge \mathrm{seam\ allows\ drop}\)。GPU 不读取预测丢弃块，PIM 对这些块做 QK 审计。
  - **Cut 2，post-QK survivor BLASST**：\(C^{keep}_t=P^{keep}_t\wedge \mathrm{BLASSTKeep}^{survivor}_t\)，只收缩 V/PV 保留集，不改变 K 读取集。
- **每步五阶段流程**：
  1. **Predict**：控制器在上一 token 末尾用状态 \(S^-_t\) 生成 \(P^{keep}_t\)、物理 union \(U_t\) 和补集 \(A_t\)。
  2. **GPU attention**：GPU 对 \(U_t\) 做 survivor QK、块最大值、survivor BLASST、softmax、PV，输出 \(O_t\)。
  3. **Complement QK**：PIM 与阶段 2 并发，对全局被省略 full block 计算 QK 和块最大值。
  4. **Reconstruct**：控制器按块顺序合并 GPU 与 PIM 最大值，做排他前缀和 GQA 归约，恢复 \(A_t\) 中每个 cell 的全缓存 margin 与 verdict。
  5. **Fold**：控制器将观测写入预测器状态 \(S^-_{t+1}\)，并提前生成下一步掩码 \(P^{keep}_{t+1}\)。
- **执行契约**：
  - 当前输出 \(O_t\) 只依赖 \(Q_t\) 和 \(P^{keep}_t\)，不等待当前审计。
  - 预测丢弃在当前 token 内不可回滚。
  - 每个预测丢弃 full cell 必须被 GPU–PIM 观测分区覆盖。
  - 审计 \(t\) 生成下一步掩码，而不是门控当前输出。
- **补集审计与状态更新**：
  - 观测通道包括 GPU 对 union 内预测丢弃块的最大值，以及 PIM 对全局省略块的 QK 最大值。
  - 对 full block，观测值 \(x\) 为：若 \(P^{keep}=1\)，用 \(\gamma^U\)；若 \(P^{keep}=0\)，用 \(\gamma^\star\)。
  - 状态更新：\(\mu^+=\alpha x+(1-\alpha)\mu^-\)，\(M_2^+=\alpha x^2+(1-\alpha)M_2^-\)，\(\sigma^+=\sqrt{\max(M_2^+-(\mu^+)^2,0)}\)。
  - age 跟随实际 cascade verdict \(C^{keep}_t\)；审计 KEEP 重置 age；审计 DROP 保持 age；counter 只由决策规则写入。
- **系统映射**：
  - GPU 负责 survivor QK、survivor BLASST、softmax、PV。
  - AttAcc 派生的近存储体 GEMV 负责被省略补集的 QK 和块最大值。
  - 栈级控制器负责合并、重建、状态更新、预测和下一步掩码；限制为比较、选择、最大值/前缀归约、GQA 归约、小状态更新、bitmap/地址处理，不含指数、除法或 softmax 数据通路。
  - KV、预测器状态、临时审计值保留在 HBM；GPU survivor QK 加 PIM complement QK 等于全缓存 QK，即 \(QK_{surv}+QK_{omit}=QK_{full}\)。
