## 摘要
事后稀疏注意力通过将每个查询路由到一小组 token 级交互来加速长上下文预填充。然而，硬选择会为每个被省略的块分配零概率：一次路由失误无法恢复，而固定的扩展预算会在简单和模糊查询上花费相同的工作量。我们提出由粗到细的误差感知动态注意力路由（CEDAR），这是一种在保持语言模型冻结的同时保留全局覆盖的由粗到细方法。每个语义块向残差注意力路径贡献一个廉价的键值摘要；随后将估计近似误差较高的块扩展为精确 token 注意力。精确贡献与摘要贡献在单一 softmax 归一化中结合，因此细化是替换而非重复粗粒度证据。我们推导出一个由块内键/值离散度控制的输出误差界，并用其分配可变的细化预算。一项受控的聚类注意力研究表明，在相同的精确块预算下，残差摘要相比硬丢弃将重构误差降低了 98% 以上。在长上下文基准上的实验表明，CEDAR 恢复了硬稀疏路由所损失的大部分质量，同时在 128K 上下文下保持约 3 倍的内核加速。

## Abstract
Post-hoc sparse attention accelerates long-context prefill by routing each query to a small set of token-level interactions. Hard selection, however, assigns zero probability to every omitted chunk: a routing miss cannot be recovered, and a fixed expansion budget spends the same work on easy and ambiguous queries. We introduce Coarse-to-fine Error-aware Dynamic Attention Routing (CEDAR), a coarse-to-fine method that keeps the language model frozen while preserving global coverage. Each semantic chunk contributes a cheap key--value summary to a residual attention path; chunks with high estimated approximation error are then expanded to exact token attention. Exact and summarized contributions are combined in a single softmax normalization, so refinement replaces, rather than duplicates, coarse evidence. We derive an output-error bound governed by within-chunk key/value dispersion and use it to allocate a variable refinement budget. A controlled clustered-attention study shows that residual summaries reduce reconstruction error by more than 98% relative to hard dropping at equal exact-chunk budgets. Experiments on long-context benchmarks demonstrate that CEDAR recovers most of the quality lost by hard sparse routing while maintaining approximately $3\times$ kernel speedup at 128K context.

## 1. 核心问题与整体含义（研究动机与背景）

- **背景**：长上下文语言模型（书籍、代码仓库、多文档证据、长对话）中，标准 softmax 注意力因每个 query 与所有先前 key 交互而代价高昂。稀疏注意力通过只计算被选中的交互子集来降本，但选择必须既准确又廉价。
- **现有方法的不足**：近期动态稀疏方法（MInference、Block-Sparse、Native Sparse Attention 等）多数需要改架构、继续训练或硬件专用实现。DHSA 保持预训练 decoder-only 模型冻结，用 key 状态预测内容感知的可变长度块，但暴露两个失败模式：
  - **硬省略**：未选中块既不贡献概率质量也不贡献 value，一次假阴性路由不可恢复，即便被省略块只是中等相关。
  - **均匀细化**：固定 token 密度对集中和分散的 query 分配相同精确计算预算，简单 query 被过度服务，模糊 query 可能细化不足。
- **核心问题**：能否让每个块都以低成本保持全局可见，同时把精确 token 注意力只留给摘要不足的块？
- **整体含义**：CEDAR 作为 DHSA 的直接后续，保留语义分块作为路由基底，改变未选中块的处理方式与精确工作量的分配方式，实现无需训练、可事后部署、全局覆盖、可变预算的稀疏注意力。

## 2. 方法论

### 核心思想
- 在内容感知的分层路由之上增加一条**残差摘要路径**：每个被省略的块由一个长度校正的键值摘要表示；被选中的块展开为原始 token，其摘要被移除；两类贡献在**同一个 softmax** 中归一化，细化是“替换”而非“重复”粗证据。
- 用块级输出误差界指导**误差感知的自适应细化**，按延迟或误差预算贪心地细化块。

### 关键技术细节与公式

- **语义块摘要**：对块 $C_c$（因果长度 $n_c$）计算均值键 $\bar{k}_c$、均值值 $\bar{v}_c$（式 3），由前缀和线性时间得到，复用 DHSA 已有边界。摘要 logit 为长度校正形式：
  $$\ell^{sum}_{ic} = q_i^\top \bar{k}_c/\tau + \log n_c$$
  $\log n_c$ 项用于恢复 $n_c$ 个被近似 token 的多重性，避免长块被系统性低估。
- **混合精确–摘要注意力**（式 6）：精确 token 走真实 logit，未细化块走摘要 logit，两者共享同一分母归一化。全细化退化为稠密注意力；全不细化退化为长度校正的块注意力。
- **因果性处理**：包含当前 query 的块、可配置的近期窗口与 sink 区域始终强制精确，避免使用未来 token 的部分观测摘要。
- **误差界与优先级**：块内变化用最大/均方根离散度 $r^k_c, r^v_c$ 度量；logit 半径界 $\epsilon_{ic} = \|q_i\|_2 r^k_c / \tau$；实际细化优先级
  $$\pi_{ic} = e^{\ell^{sum}_{ic}}\big[(e^{\epsilon_{ic}}-1)(\|\bar{v}_c\|_2+\rho_i) + e^{\epsilon_{ic}} r^v_c\big]$$
  同时优先重要且内部异质的块。
- **命题 1（重构界）**：混合输出误差由未细化块求和上界，随摘要质量、键值离散度增长，对已细化块为零，且按块可加分解——这正是优先级评分的可计算未归一化对应。
- **复杂度**：边界预测与前缀归约 $O(L)$；块打分 $O(Lm)$ 或按 query 块 $O(B_q m)$；精确注意力 $O(L\bar{K})$；残差路径 $O(Lm)$ 但内存流量远低于 token 注意力；两级块树可降至 $O(L\log m)$。
- **系统实现**：融合在线 softmax（与 FlashAttention 状态更新一致，式 17–19），先流式处理精确 token tile，再处理摘要 tile，用 bitset 跳过已细化块；块级误差感知路由器（64 token 一行块、分段 top-K 或阈值选择、按 profiled 桶取整）；支持 GQA（摘要按 KV head 计算、跨 query head 共享）；前缀归约计算 FP32 统计量；路由器不物化 $L \times m$ 全矩阵；新增零训练参数，仅校准安全乘子 $\alpha$ 与误差阈值 $\eta$。

## 6. 主要结论与发现

- **受控重构**：在相同精确块预算下，残差摘要相比硬丢弃将重构误差降低 **98.5%–99.7%**（$\sigma=0.15$）；优势随块内噪声增大而减弱，与命题 1 一致。
- **质量恢复**：6.25% 密度下，硬 DHSA 的 RULER 为 79.3，CEDAR 恢复到 **87.1**，同时保持 **3.02×** 的 128K 内核加速；12.5% 密度下 CEDAR 的 RULER（89.5）约等于稠密（89.3），LongBench（37.2）还略有提升。
- **效率**：CEDAR 相对 DHSA 在 128K 增加约 **13%** 开销（197.7 ms → 224.0 ms），但仍比稠密 FA2 快约 **3×**。
- **自适应行为**：同一误差阈值下，实际密度从检索任务的 4.8% 到多跳推理的 9.4%，说明固定密度确实次优。
- **消融归因**：最大质量增益来自残差摘要；离散度优先级与自适应预算提供较小的互补增益；每块两个摘要进一步改善重构与 RULER，但损失约 10% 加速。

## 7. 优点

- **理论支撑扎实**：给出由块内键值离散度控制的输出误差界，并把界转化为可计算的优先级评分，方法不是纯启发式。
- **软路由而非硬丢弃**：被省略块通过长度校正摘要保持全局可见，一次路由失误可通过摘要部分挽回，缓解了稀疏注意力的不可逆假阴性问题。
- **统一 softmax、无重复计数**：精确与摘要贡献在同一归一化中结合，细化“替换”摘要，避免双重计入。
- **可变预算分配**：按误差界贪心细化，简单 query 少算、模糊 query 多算，直击“均匀细化”的浪费。
- **部署友好**：模型完全冻结、零新增训练参数、复用 DHSA 边界与表示、兼容 FlashAttention 式在线 softmax 与 GQA，适合事后改造。
- **机制验证与端到端评测分离**：受控实验先隔离验证核心近似，再进入昂贵基准，实验叙事严谨。
- **消融完整**：逐一移除残差摘要、离散度优先级、自适应预算、语义边界，归因清晰。
