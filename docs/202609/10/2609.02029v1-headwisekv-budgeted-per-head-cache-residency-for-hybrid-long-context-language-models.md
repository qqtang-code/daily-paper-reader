## 摘要
长上下文推理在解码期间会保留不断增长的键值（KV）缓存，这会消耗大量 GPU 显存，并可能降低生成吞吐量。这一瓶颈在混合语言模型中依然存在，因为其残余的全局注意力层可能主导依赖于上下文的缓存需求。我们研究如何在总体 KV 驻留预算下分配这一状态。我们提出 HeadWiseKV，一种免训练框架，可压缩混合语言模型的残余全局 KV 缓存，同时保留其原生的局部、循环和线性路径。它为每个物理 KV 头分配静态的多级历史窗口，使缓存需求在服务前即可预测。我们将该分配形式化为一个受限的操作性率失真问题，并提出 SeqCalib 作为 HeadWiseKV 中的核心策略生成算法。SeqCalib 按执行顺序处理各层，并让每个决策以部署时所用的下层策略为条件，从而考虑跨深度的交互。一种分组缓存运行时将所选策略具体化为实际的逐头 KV 驻留，而不是对完整缓存施加掩码。我们在四个混合长上下文模型上评估下游质量，并在 Qwen3.6-27B 上研究物理驻留与服务行为。在所评估的模型上，HeadWiseKV 保持了接近全 KV 的 RULER 和 LoCoMo 质量。在固定模型的系统研究中，它在 112K 上下文长度下将采样峰值设备内存降低了 8.59%，并将已验证成功的最大上下文从 114K 扩展到 161K。

## Abstract
Long-context inference retains a growing key--value (KV) cache during decoding, which consumes substantial GPU memory and can reduce generation throughput. This bottleneck remains in hybrid language models because their residual global-attention layers can dominate context-dependent cache demand. We study how to allocate this state under an aggregate KV-residency budget. We introduce HeadWiseKV, a training-free framework that compresses the residual global KV caches of hybrid language models while preserving their native local, recurrent, and linear paths. It assigns each physical KV head a static, multilevel history window, making cache demand predictable before serving. We formulate this allocation as a restricted operational rate--distortion problem and propose SeqCalib as the core policy-generation algorithm in HeadWiseKV. SeqCalib processes layers in execution order and conditions each decision on the lower-layer policy used at deployment, thereby accounting for interactions across depth. A grouped-cache runtime materializes the selected policy as actual per-head KV residency rather than a mask over a full cache. We evaluate downstream quality across four hybrid long-context models and study physical residency and serving behavior on Qwen3.6-27B. HeadWiseKV retains near-Full-KV RULER and LoCoMo quality across the evaluated models. In the fixed-model systems study, it reduces sampled peak device memory by 8.59\% at a 112K context length and extends the largest verified successful context from 114K to 161K.

# HeadWiseKV 论文总结

## 1. 核心问题与整体含义

- **背景**：长上下文自回归推理中，每个全注意力层都会为所有已缓存 token 保存 K/V 向量，KV cache 随上下文长度与并发数增长，可耗尽设备显存并降低生成吞吐。
- **混合模型的瓶颈转移而非消除**：Gemma 2/3 交错全局注意力与局部滑动窗口；Qwen3-Next/Qwen3.6 交错全/门控注意力与循环 Gated-DeltaNet 块。其残余的全局注意力层仍随 prompt 增长，少量全局层即可决定长请求能否装入显存。
- **两个正交选择**：
  - *策略时机*：prompt-dependent（依赖当前请求、观测注意力或在线驱逐状态）vs. static（服务前固定）。
  - *缓存实现*：逻辑稀疏掩码（不减少已分配 KV cache）vs. 物理驻留/压缩/驱逐（可降低峰值）。
- **现有静态方法的不足**：RazorAttention、DuoAttention 等采用 full/compressed 的**二值头角色划分**，对混合模型中需求各异的残余全局头过于粗糙。
- **跨深度校准问题**：截断早期缓存会改变后续层看到的表示；高层若在 all-full 前缀下校准，部署后输入分布会偏移。
- **目标**：在总 KV 驻留预算下，为每个物理 KV 头分配细粒度、静态、可预测的多级历史窗口，并在运行时真正落地为物理缓存驻留。

## 2. 方法论

### 2.1 核心思想

- **HeadWiseKV**：免训练框架，只压缩混合模型的残余全局注意力 KV 缓存，保留原生局部/循环/线性路径不变。
- 为每个物理 KV 头分配一个静态多级后缀窗口，形成 layer × KV-head 的策略矩阵；缓存需求在服务前即可预测。
- 将分配形式化为**受限操作性率失真问题**，用 **SeqCalib** 逐层生成策略，再由**分组缓存运行时**物化为实际驻留。

### 2.2 结构化驻留模型

- **决策单元**：仅残余全注意力层 `L_F` 参与；GQA 下多个 query head 共享一个物理 KV head，故决策单元为 `(ℓ, h)`，集合 `U = {(ℓ,h)}`。
- **窗口码本**：`W = {w1, ..., wK, full}`，有限窗口表示连续后缀长度；`a_ℓh ∈ W` 为该头保留的历史长度。
- **存储成本**：保留 token 数 `r_C(w) = min(w, C)`（full 为 C）；单头成本 `n_ℓh,C(w; pKV) = r_C(w)(dK·bK + dV·bV)`；总成本 `N_C(a)` 为各头之和。
- **归一化率**：`R_C(a) = N_C(a) / N_C(aF)`，表示可配置全局 KV 头相对 all-full 的标称存储比例（不含权重、工作区、分配器开销）。
- **理想目标**：在 `R_C(a) ≤ β` 约束下最小化与全缓存模型输出的期望失真 `D* = min E_x[δ_C(a,x)]`；搜索空间为 `(K+1)^|U|`，直接优化不可行。

### 2.3 SeqCalib（前缀条件化顺序校准）

- **逐层执行顺序处理**：对层 ℓ，冻结已选定的下层策略 `a_<ℓ`，在该前缀下评估当前层候选窗口。
- **单次 trace + 重放**：先用 full 历史 trace 一次该层的 Q/K/V 及条件 full-history 注意力输出；随后对每个候选后缀，从同一 trace 中限制键位置、重新归一化注意力权重，得到候选输出。
- **评分**：候选窗口注意力输出与条件 full-history 输出的**平均余弦相似度**，在 GQA 组内 query head、采样位置和校准样本上平均。
- **选择规则**：在满足相似度下限 τ 的候选中，选择**成本最低**的窗口（最低成本码本项）；full 总可行，`≺W` 打破同成本平局。
- **理论性质**：层内各头共享同一前缀，冻结后推进，因此是“给定已实现前缀下”的层内最小可行成本，**不保证全局联合最优**。
- **τ 网格与预算选择**：在有序网格 `T = (τ1,...,τG)` 上独立运行，记录每个策略、率、最低头均分 `Φ`、阈值与网格索引；在满足预算 β 的记录中，按字典序：最大化 `Φ` → 最小化率 → 最小化网格索引，得到确定性选择。

### 2.4 运行时实现

- **分组缓存运行时**：加载策略矩阵一次，不再从 prompt/请求历史/在线注意力重算。
- 每个配置 KV head 读写其窗口对应的 cache group；相同窗口的头可共享组配置，但 KV 内容彼此独立。
- GQA query head 组读取共享的物理 KV-head 切片，各头输出拼接后经过模型原有 gating 与输出投影；原生局部/循环层保持原缓存路径。
- 是**真实物理分配**，而非对 all-full 缓存的逻辑掩码；因此可降低 prefill 峰值显存。
