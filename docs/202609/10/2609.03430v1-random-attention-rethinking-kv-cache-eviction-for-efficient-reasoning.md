## 摘要
大语言模型在需要扩展推理的任务上取得了优越性能，但长思维链使 KV 缓存成为严重的内存瓶颈。现有的 KV 缓存压缩方法共享同一种范式：通过某种估计来为每个缓存 token 打分，以判断其之后有多重要，并保留得分最高者。我们表明，这种选择信号几乎没有贡献。Random Attention 保留提示词，并在每个注意力头内均匀随机地驱逐 token，完全不计算任何分数；在四个模型和六个推理任务上，它匹配了此前最强的驱逐方法，同时在 vLLM 部署中实现了比其高 32–43% 的吞吐量。受控实验对此的解释是：1）提示词是缓存中脆弱的部分，而不同选择器之间的大部分差距仅在于其选择信号是否恰好保留了提示词；2）推理轨迹通过两个层面的冗余来保护自身免受驱逐：在文本层面（模型在工作过程中会重述其仍然需要的内容）以及在注意力头之间（每个头都保留自己的轨迹副本），因此一旦提示词安全，随机抽取就能保留足够多模型仍然需要的内容副本，而无需任何分数来挑选它们。我们的代码公开在 https://github.com/SalesforceAIResearch/Random-Attention。

## Abstract
Large language models achieve superior performance on tasks that require extended reasoning, but long chains of thought make the KV cache a severe memory bottleneck. Existing KV cache compression methods share one paradigm: score each cached token by some estimate of how much it will matter later, and keep the top-scoring ones. We show that the selection signal contributes almost nothing. Random Attention keeps the prompt and evicts uniformly at random within each attention head, computing no score at all; across four models and six reasoning tasks it matches the strongest prior evictor while serving 32-43% higher throughput than it in vLLM deployment. Controlled experiments explain this by showing that 1) the prompt is the fragile part of the cache, and most of the gap between selectors is just whether their selection signal happened to keep it; 2) the reasoning trace protects itself against eviction with redundancy at two levels, in the text (the model restates what it still needs as it works) and across attention heads (each keeps its own copy of the trace), so once the prompt is safe, a random draw retains enough copies of what the model still needs, and no score is required to pick them. Our code is publicly available at https://github.com/SalesforceAIResearch/Random-Attention.

## 1. 核心问题与研究动机

- **背景**：推理模型（如 DeepSeek-R1、OpenAI o 系列、Phi-4-reasoning）通过生成数万 token 的思维链解决难题，KV cache 随生成长度线性增长，成为严重内存瓶颈。
- **现有范式**：KV cache 驱逐（eviction）方法普遍采用同一思路——为每个缓存 token 打分，估计其未来重要性，保留最高分者。代表方法包括 StreamingLLM（无分数）、H2O（累积注意力）、SnapKV（近期窗口注意力）、R-KV（注意力+冗余惩罚）、VaSE（value 幅度+随机填充）、TriAttention（位置相关的三角函数统计）。
- **核心质疑**：所有方法都隐含假设"选择分数决定压缩后的准确率"。本文直接检验这一前提，发现**选择信号几乎不贡献任何东西**。
- **整体含义**：将 KV cache 驱逐从"排序问题"重新定位为"保护问题"——决定准确率的是"保护了什么"（prompt），而不是"如何对剩余部分排序"。这既给出一个可直接部署的极简方法，也重新定向了后续驱逐研究应优化的方向。

## 2. 方法论：Random Attention

### 核心思想
- 将缓存内容分为两类：**prompt**（一次性输入、不可恢复）与**推理轨迹**（模型自己生成、不断复述与冗余）。
- 保护前者，对后者在**每个注意力头内独立均匀随机**驱逐，不计算任何重要性分数。

### 关键技术细节
- **设置**：解码期驱逐，每个 KV head 独立决策；持久预算 $K$ + 最近 $r$ 个 token 的 buffer（$r \ll K$，论文取 $r=64$），buffer 不参与评分，每 $r$ 步触发一次驱逐，驱逐是单调的（丢弃即永久丢失）。
- **评分规则**（式 3）：
  - 若位置 $i \leq \ell_p$（prompt 位置）：$s_i = +\infty$（强制保留）；
  - 否则：$s_i = u_i \sim \text{Uniform}(0,1)$，每个 KV head、每次驱逐独立采样。
- **算法流程**（Algorithm 1，每次驱逐事件、每层执行）：
  1. 生成形状 $(B, H_{kv}, S)$ 的 i.i.d. 均匀随机分数；
  2. 将 prompt 区间的分数置为 $+\infty$；
  3. 对每个 KV head 独立取 top-$K$，返回保留位置。
- **成本**：每次驱逐仅一次 `rand` + 一次 `topk`，是"最弱的选择信号"，同时作为**零假设（null hypothesis）**：任何基于信号的选择器若在匹配预算下无法击败它，说明其信号没有提取到有用信息。

## 6. 主要结论与发现

1. **选择信号贡献极小**：Random Attention 在四个模型、六项推理任务上匹配最强先前驱逐器（TriAttention），并在 60 个对比单元中 31 个显著领先、仅 1 个显著落后。
2. **Prompt 是缓存中最脆弱的部分**：
   - 一旦给所有方法相同的"保留 prompt"规则，baseline 之间的大部分差距消失，且各方法增益与其分数原本"丢失了多少 prompt"成正比（SnapKV 增益最大可达 +35.2 分；R-KV 几乎不变，因为它本来就保留大部分 prompt）。
   - 受保护后，三种 baseline 在多数设置下彼此落在 2.2 分以内；无信号策略（recency window）也能接近最佳 baseline。
3. **推理轨迹自我保护，具有两层冗余**：
   - **文本层**：模型在推理过程中会重述仍需要的内容，值很少只存在于单一位置。
   - **跨头层**：每个 KV head 保存自己的 token 副本，驱逐按 head 独立决策；token 只有在所有 head 都丢弃时才真正丢失。
   - Plant-fact 探针显示：单 head 保留事实时几乎无法检索（3%、1%），但 2 个 head 联合可达 60%，3 个 83%，全部 8 个 99%，即**池化具有强超加性**；两个不同事实分布在不同 head 时也相互增益（$R=0.31$ vs 单独 0.10/0.16）。
   - **副本形状不重要**：token 级分散、连续块（≤64 token）对检索/准确率几乎无影响；只有块大小 256 且每 head 仅剩 2–4 块时才下降，关键在"每 head 的块数"而非块长度。
4. **剩余给选择信号的空间**：仅剩"一次性陈述、从不重述、很久之后才需要"的稀有事实（passcode 实验）。此时 Random Attention 检索率为 0，而 R-KV 达 84%、VaSE 34%，SnapKV/TriAttention 几乎为 0。这种 needle-finding 能力与聚合准确率不相关（R-KV 是最佳 needle-finder，却只在表 1 一列领先；TriAttention 是最强 baseline，却几乎无法恢复 passcode）。
5. **效率优势**：vLLM 部署下，Random Attention 在 32k 生成时达 full attention 的 1.58×–2.67× 吞吐，比 TriAttention 高 **32–43%**；单轮驱逐耗时 0.30 ms（仅 compaction），而 TriAttention 为 1.47–1.64 ms；等内存最大 batch 下达 10.0×/8.8×，K=1024 时达 28.8×。
6. **实践启示**：
   - Random Attention 无需校准、调参或评分 pass，是内存预算下服务推理模型的合理默认选择，也是任何新选择信号必须击败的 baseline。
   - 驱逐研究应转向"保护什么"：如何为长 prompt（尤其代码任务）分配预算，以及如何恢复稀有的一次性事实。

## 7. 优点

- **反直觉且简洁的核心发现**：用一个几乎零成本的随机策略作为零假设，直接挑战整个"打分-保留"范式的有效性，结论清晰、可复现、可部署。

- **效率分析深入**（续）：...中的收益远大于评测框架中（评测通常 batch 解码、评分开销被摊薄，而服务场景下每步都要跑评分 pass，随机方法直接省掉这一 pass）。论文对两种协议的差异解释清楚，避免了"实验室吞吐"与"生产吞吐"混淆。
- **对 baseline 的公平性处理诚实**：主动披露 R-KV 的 vLLM 版本差异、TriAttention 在等内存实验中为未融合 PyTorch 实现、AIME/HMMT 的噪声范围等，并在正文中把"随机方法落后的唯一一列"（Qwen3-32B LiveCodeBench）明确标出而非隐藏。
- **可操作性极强**：核心算法只有 `rand` + `topk` 两步，无需校准集、无需超参搜索、无需额外 forward，任何现有 KV cache 管理器（包括 PagedAttention）都能直接接入。
- **负面结果也是贡献**：passcode 实验给出随机策略的清晰失败边界，同时说明"needle-finding"能力与聚合准确率不相关，这为后续研究划定了明确的问题空间。

## 8. 局限与不足（方法层面）

与第 5 节的"实验充分性"不同，这里聚焦方法本身与结论适用性的边界：

- **prompt 保护的实现依赖位置信息**：算法假设 prompt 与生成轨迹有明确的位置分界（$i \leq \ell_p$）。在多轮对话、工具调用、交错式 agent 轨迹中，"prompt"边界模糊，该方法需重新定义"不可恢复内容"的判定规则，论文未给出方案。
- **对长 prompt 的预算分配是未解问题**：主网格中 LiveCodeBench 因 prompt 较长、预算受限，是 Random Attention 唯一显著落后的一列。论文承认"如何为长 prompt 分配预算"是开放问题，但没有提出具体策略。
- **passcode 类场景被明确放弃**：一次性陈述、从不重述、延迟很久才使用的事实，随机驱逐检索率为 0。若实际应用（如 agent 记住工具返回的一次性 ID、用户偏好）依赖此类信息，该方法不适用。
- **跨头冗余假设依赖架构**：实验基于 Qwen3 与 Phi-4-reasoning 的 GQA 配置（每 KV head 服务多个 query head）。在 MQA/MLA（如 DeepSeek 系）或 KV head 数极少的架构下，跨头副本数下降，冗余保护是否仍然成立未被验证。
- **随机性带来的方差未充分刻画**：论文报告了重复采样的标准差，但未系统比较"不同随机种子下同一问题是否正确"的翻转率，也未分析多次采样中随机方法的稳定性（例如 pass@k 与 k 次独立随机 draw 的关系）。
- **理论解释仍是经验性的**：论文用"文本层重述 + 跨头副本"解释随机为何有效，但未给出形式化分析（例如在何种重述概率与头数下，均匀随机的期望保留率足够）。

## 9. 启发与未来方向

- **驱逐研究的重心转移**：从"设计更好的打分函数"转向"定义并保护不可恢复内容"。可能的切入点包括：按 token 来源（用户输入 / 系统提示 / 工具返回 / 模型生成）而非位置来划分缓存，以及为长 prompt 设计预算分配（如按段落重要性、代码结构或检索需求）。
- **稀有一次性事实的恢复**：passcode 实验暴露的问题——"从不重述、很久之后才需要"的信息——是当前所有驱逐器的共同盲区。R-KV 的 needle-finding 能力与聚合准确率不相关，说明这两项目标可能需要不同的机制（例如对特定 span 强制保留，或做少量外置存储/检索）。
- **跨头冗余的显式利用**：plant-fact 探针显示 2 个 head 联合保留即可达 60% 检索率，提示可以选择性地"指定少数 head 保留某段内容"，而非所有 head 独立随机——这可能以极低成本换取对稀有事实的覆盖。
- **新选择信号的评价基准**：Random Attention 作为零假设，为后续工作提供了清晰的准入标准——在匹配预算与保护规则下必须显著优于均匀随机，否则其信号未提取到有用信息。
- **工程方向**：既然评分 pass 可省，KV cache 管理的实现可进一步简化（无需为驱逐单独跑一次 attention 统计），有利于与 PagedAttention、prefix caching、投机解码等系统特性结合。

## 10. 总体评价

本文是一篇"负面结果驱动"的高价值论文：它以近乎零成本的随机策略为探针，系统性地证伪了 KV cache 驱逐领域长期默认的"选择分数决定准确率"假设，并给出一个可部署的极简方法。其贡献不限于方法本身，更在于重新定义了问题——**保护什么** 比 **如何排序** 更重要。实验设计（统一 prompt 保护对照、plant-fact 探针、passcode 边界测试、keep-log 机制分析）与统计处理（配对聚类 bootstrap + 符号检验）均属上乘，且对自身失败案例与 baseline 端口差异保持透明。

主要局限在于适用场景的边界：长 prompt 的预算分配、多轮/agent 轨迹中的"不可恢复内容"判定、以及稀有一次性事实的检索，均未解决；模型族覆盖也偏窄。但这些问题被作者明确标出，反而构成了后续研究的清晰路标。对实践者而言，Random Attention 是内存受限下服务推理模型的合理默认选项；对研究者而言，它是任何新选择信号必须跨越的门槛。
